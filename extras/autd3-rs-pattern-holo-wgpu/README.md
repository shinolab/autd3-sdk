# autd3-rs-pattern-holo-wgpu

GPU `LinAlgBackend` for [`autd3-rs-pattern-holo`](https://crates.io/crates/autd3-rs-pattern-holo), built on [wgpu](https://crates.io/crates/wgpu).

Drop it in place of the default CPU backend when optimizing large hologram problems.
