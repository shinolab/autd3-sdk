# AUTD3 FPGA Firmware

## Structure

```
firmware/fpga/
├── README.md
├── coe/                     # BRAM / ROM initialization data (*.coe)
├── scripts/                 # Vivado batch scripts (Tcl)
│   ├── proj_gen.tcl         #   generate the Vivado project
│   ├── build.tcl            #   synthesis -> implementation -> bitstream -> autd3-fpga.mcs
│   ├── sim.tcl              #   run the simulation testbenches
│   └── configuration.tcl    #   write .mcs to the SPI flash
└── rtl/                     # SystemVerilog sources
    ├── constrs_1/new/       #   timing / pin constraints (*.xdc)
    ├── sources_1/new/       #   design sources
    ├── sources_1/ip/        #   Vivado IP (*.xci)
    └── sim_1/new/           #   simulation testbenches (sim_*.sv)
```

## Build

All Vivado tasks are run from the repository root (`autd3-sdk/`) via xtask.

```bash
cargo xtask fpga project        # generate the Vivado project
cargo xtask fpga build          # synthesis -> implementation -> bitstream -> autd3-fpga.mcs
cargo xtask fpga build --force  # re-run synthesis even if a bitstream exists
cargo xtask fpga flash          # build, then write autd3-fpga.mcs to the SPI flash
cargo xtask fpga clean
```

## Simulation

```bash
cargo xtask fpga sim                   # run every testbench in rtl/sim_1/ and report pass/fail
cargo xtask fpga sim --tb sim_mem_cnt  # run a single testbench (module name)
```

## Code generation

```bash
cargo xtask fpga gen-controller  # regenerate controller.sv
cargo xtask fpga commit-ips      # copy the IP generated by Vivado back into rtl/sources_1/ip
```
