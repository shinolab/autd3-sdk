`constant` は一定の振幅を出力する変調を生成する (つまり変調なし).

## API

<CodeTabs rust={"constant(intensity, &mut dst);"} python={"constant(intensity, dst)"} csharp={"Modulation.Constant(intensity, dst);"} />

| 引数        | 型             | 説明                   |
| ----------- | -------------- | ---------------------- |
| `intensity` | `u8`           | 振幅係数               |
| `dst`       | `&mut Vec<u8>` | 出力バッファ           |

## Example

<CodeTabs rust={"use autd3_rs_modulation::constant;\n\nlet mut dst = Vec::new();\n\nconstant(0xFF, &mut dst);"} python={"from autd3_modulation import constant, modulation_buffer\n\ndst = modulation_buffer()\n\nconstant(0xFF, dst)"} csharp={"using AUTD3;\n\nvar dst = Modulation.ModulationBuffer();\n\nModulation.Constant(0xFF, dst);"} />
