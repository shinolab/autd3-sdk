`DatagramBuilder` は送信するコマンドを積み上げ, `Frames` へ変換する構造体.
`Client::datagram_builder` で得る.

## API

`push` でコマンドを積み, `build` で `Frames` に変換する.
得られた `Frames` は複数の `Frame` に分割し, `Client::send` / `send_checked` で 1 フレームずつ送信する.

<CodeTabs rust={"let mut builder = client.datagram_builder();\nbuilder.push(SetSilencer::default());\nlet frames = builder.build()?;\nfor frame in &frames {\n    client.send_checked(frame).await?;\n}"} python={"builder = client.datagram_builder()\nbuilder.push(SetSilencer())\nframes = builder.build()\nfor frame in frames:\n    await client.send_checked(frame)"} csharp={"var builder = client.DatagramBuilder();\nbuilder.Push(new SetSilencer());\nvar frames = builder.Build();\nforeach (var frame in frames)\n{\n    await client.SendCheckedAsync(frame);\n}"} />

| メソッド            | 説明                                         |
| ------------------- | -------------------------------------------- |
| `push(cmd)`         | 全デバイス共通のコマンドを積む               |
| `push_each(assign)` | デバイスごとに異なるコマンドを積む (下記参照) |
| `build()`           | 積んだコマンドを `Frames` に変換する       |

## push\_each

`push_each` はデバイスを引数にするクロージャを受け取り, デバイスごとに異なるコマンドを割り当てる.
Rust では `FnMut(&Device) -> Option<C>`, Python では `Callable[[Device], Command | None]`, C# では `Func<Device, ICommand?>`.
`None` を返したデバイスには, そのステップで何も割り当てない.

<CodeTabs rust={"let mut builder = client.datagram_builder();\nbuilder.push_each(|device| {\n    Some(if device.idx() % 2 == 0 {\n        Pattern::new(&left)\n    } else {\n        Pattern::new(&right)\n    })\n});\nlet frames = builder.build()?;"} python={"builder = client.datagram_builder()\nbuilder.push_each(lambda device: Pattern(left if device.idx() % 2 == 0 else right))\nframes = builder.build()"} csharp={"var builder = client.DatagramBuilder();\nbuilder.PushEach(device => device.Idx % 2 == 0\n    ? new Pattern(left)\n    : new Pattern(right));\nvar frames = builder.Build();"} />

Rust ではクロージャの返り値はすべて同じ型でなければならない.
型の異なるコマンドを混在させたい場合は, `Command::boxed` で `BoxedCommand` に揃えるか, `push_each`を型ごとに呼ぶ.
Python は動的型付けのため, デバイスごとに異なる型のコマンドをそのまま返せる.

<CodeTabs rust={"let mut builder = client.datagram_builder();\nbuilder.push_each(|device| {\n    Some(if device.idx() % 2 == 0 {\n        Pattern::new(&left).boxed()\n    } else {\n        Modulation::new(SamplingConfig::FREQ_4K, &modulation).boxed()\n    })\n});\nlet frames = builder.build()?;"} />
