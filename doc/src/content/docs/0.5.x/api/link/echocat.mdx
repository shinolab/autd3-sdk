`EchocatLink` は AUTD3 のために書かれた EtherCAT Link.

<Install rust="autd3-rs-link-echocat" python="autd3-link-echocat" csharp="AUTD3.Link.Echocat" />

Ethernet の raw socket を扱うため, Linux/macOS では実行に root 権限 (または `CAP_NET_RAW`) が必要.
Windows では, [npcap](https://nmap.org/npcap/) を「WinPcap API-compatible mode」でインストールする必要がある.

## API

<CodeTabs rust={"EchocatLinkOption {\n    iface,\n    sync0_period,\n    pdu_timeout,\n    state_transition_timeout,\n    dc_static_sync_iterations,\n    dc_start_delay,\n    sync_tolerance,\n    sync_timeout,\n    process_data_watchdog,\n    sleep_strategy,\n};"} python={"echocat.EchocatLinkOption(\n    iface,\n    sync0_period,\n    pdu_timeout,\n    state_transition_timeout,\n    dc_static_sync_iterations,\n    dc_start_delay,\n    sync_tolerance,\n    sync_timeout,\n    process_data_watchdog,\n    spin_margin,\n)"} csharp={"new EchocatLinkOption(\n    iface,\n    sync0Period,\n    pduTimeout,\n    stateTransitionTimeout,\n    dcStaticSyncIterations,\n    dcStartDelay,\n    syncTolerance,\n    syncTimeout,\n    processDataWatchdog,\n    spinMargin\n);"} />

| フィールド                  | 型          | 説明                                                                            |
| --------------------------- | ----------- | ------------------------------------------------------------------------------- |
| `iface`                     | `Interface` | 使用するネットワークインターフェース. `Interface::Auto` で自動選択, `Interface::Name(..)` で名前指定 |
| `sync0_period`              | `Duration`  | SYNC0 信号の周期 (= フレームの送出周期)                             |
| `pdu_timeout`               | `Duration`  | 1 つの PDU の応答を待つタイムアウト                   |
| `state_transition_timeout`  | `Duration`  | EtherCAT 状態遷移 (INIT → PRE-OP → SAFE-OP → OP) を待つタイムアウト             |
| `dc_static_sync_iterations` | `u32`       | DC の静的ドリフト補正で回すフレーム数                                           |
| `dc_start_delay`            | `Duration`  | SYNC0 の開始時刻を現在のバス時刻からどれだけ先に置くか                          |
| `sync_tolerance`            | `Duration`  | 同期完了とみなす許容誤差                                                        |
| `sync_timeout`              | `Duration`  | 同期完了を待つタイムアウト                                                      |
| `process_data_watchdog`     | `Duration`  | サブデバイスがプロセスデータの途絶を検出するまでの時間                          |
| `sleep_strategy`            | `SleepStrategy` | 次のサイクルまでの待ち方                                                    |

`sync0_period` の既定値は Windows で 2 ms, それ以外で 1 ms.

## `SleepStrategy`

RT スレッドが次のサイクルまで待つ方法を選ぶ.

<CodeTabs rust={"SleepStrategy::Sleep;\nSleepStrategy::Spin {\n    margin: Duration::from_micros(100),\n};"} />

| バリアント             | 説明                                                                 |
| ---------------------- | -------------------------------------------------------------------- |
| `Sleep`                | `std::thread::sleep` で待つ.                                         |
| `Spin { margin }`      | デッドラインの `margin` 手前まで sleep し, そこからスピンする                |

デフォルトは`Sleep`.
