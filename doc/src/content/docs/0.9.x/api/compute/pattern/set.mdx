パターンバッファ全体の振幅・位相を一括で書き換える.
`focus` などのパターン関数は位相だけを書くので, 振幅はこれらの関数で設定する.

`pattern_buffer` で確保したバッファの初期値は位相 0・最大振幅である.
C# では `new Emission[n]` の要素は振幅 0 で初期化されることに注意

## set\_intensity

全振動子の振幅を設定する. 位相は変えない.
`Intensity::MIN` を渡すと無出力になる.

<CodeTabs rust={"set_intensity(intensity, &mut dst);"} python={"set_intensity(intensity, dst)"} csharp={"Pattern.SetIntensity(intensity, dst);"} />

## set\_phase

全振動子の位相を設定する. 振幅は変えない.

<CodeTabs rust={"set_phase(phase, &mut dst);"} python={"set_phase(phase, dst)"} csharp={"Pattern.SetPhase(phase, dst);"} />

## set\_phase\_and\_intensity

全振動子の位相と振幅を設定する.

<CodeTabs rust={"set_phase_and_intensity(phase, intensity, &mut dst);"} python={"set_phase_and_intensity(phase, intensity, dst)"} csharp={"Pattern.SetPhaseAndIntensity(phase, intensity, dst);"} />

## add\_phase

全振動子の位相へ一律に加算する (8 bit で折り返す). 振幅は変えない.

<CodeTabs rust={"add_phase(phase, &mut dst);"} python={"add_phase(phase, dst)"} csharp={"Pattern.AddPhase(phase, dst);"} />

| 引数        | 型                     | 説明         |
| ----------- | ---------------------- | ------------ |
| `intensity` | `Intensity`            | 振幅         |
| `phase`     | `Phase`                | 位相         |
| `dst`       | `&mut [[Emission; _]]` | 対象バッファ |

## Example
