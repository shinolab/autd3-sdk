`hermite_gaussian_phase` はエルミート・ガウシアン (HG) ビーム <Math tex="\mathrm{HG}_{mn}" /> を生成する.

<PatternField kind="hermite-gaussian" />

`laguerre_gaussian_phase` と同様に, 振幅は `hermite_gaussian_intensity` で変更する.

## API

<CodeTabs rust={"let option = HermiteGaussianOption {\n    m: 1,\n    n: 0,\n    waist: 10.0 * mm,\n};\nhermite_gaussian_phase(&geometry, target, axis, x_dir, option, wavelength, &mut dst);\nhermite_gaussian_intensity(&geometry, target, axis, x_dir, option, wavelength, &mut dst);"} python={"option = HermiteGaussianOption(m=1, n=0, waist=10.0)\nhermite_gaussian_phase(geometry, target, axis, x_dir, option, wavelength, dst)\nhermite_gaussian_intensity(geometry, target, axis, x_dir, option, wavelength, dst)"} csharp={"var option = new HermiteGaussianOption(m: 1, n: 0, waist: 10.0f * mm);\nPattern.HermiteGaussianPhase(geometry, target, axis, xDir, option, wavelength, dst);\nPattern.HermiteGaussianIntensity(geometry, target, axis, xDir, option, wavelength, dst);"} />

| 引数         | 型                      | 説明                                          |
| ------------ | ----------------------- | --------------------------------------------- |
| `geometry`   | `&Geometry`             | デバイス配置                                  |
| `target`     | `Point3<f32>`           | ビームウエストの中心座標 \[mm]                 |
| `axis`       | `UnitVector3<f32>`      | ビームの伝搬方向 (単位ベクトル)               |
| `x_dir`      | `UnitVector3<f32>`      | 次数 `m` の節面を並べる方向                   |
| `option`     | `HermiteGaussianOption` | モードとウエスト                              |
| `wavelength` | `Length`                | 波長                                          |
| `dst`        | `&mut [[Emission; _]]`  | 出力バッファ                                  |

| フィールド | 型       | 説明                                                  |
| ---------- | -------- | ----------------------------------------------------- |
| `m`        | `u32`    | `x_dir` 方向のモード次数                              |
| `n`        | `u32`    | それに直交する方向のモード次数                        |
| `waist`    | `Length` | ビームウエスト半径 <Math tex="w_0" /> (正値) |
