`laguerre_gaussian_phase` はラゲール・ガウシアン (LG) ビーム <Math tex="\mathrm{LG}_p^l" /> を生成する.

<PatternField kind="laguerre-gaussian" />

位相を変更する `laguerre_gaussian_phase` とは別に振幅のみを書く `laguerre_gaussian_intensity` がある.

## API

<CodeTabs rust={"let option = LaguerreGaussianOption {\n    p: 1,\n    l: 1,\n    waist: 10.0 * mm,\n};\nlaguerre_gaussian_phase(&geometry, target, axis, option, wavelength, &mut dst);\nlaguerre_gaussian_intensity(&geometry, target, axis, option, wavelength, &mut dst);"} python={"option = LaguerreGaussianOption(p=1, l=1, waist=10.0)\nlaguerre_gaussian_phase(geometry, target, axis, option, wavelength, dst)\nlaguerre_gaussian_intensity(geometry, target, axis, option, wavelength, dst)"} csharp={"var option = new LaguerreGaussianOption(p: 1, l: 1, waist: 10.0f * mm);\nPattern.LaguerreGaussianPhase(geometry, target, axis, option, wavelength, dst);\nPattern.LaguerreGaussianIntensity(geometry, target, axis, option, wavelength, dst);"} />

| 引数         | 型                       | 説明                                          |
| ------------ | ------------------------ | --------------------------------------------- |
| `geometry`   | `&Geometry`              | デバイス配置                                  |
| `target`     | `Point3<f32>`            | ビームウエストの中心座標 \[mm]                 |
| `axis`       | `UnitVector3<f32>`       | ビームの伝搬方向 (単位ベクトル)               |
| `option`     | `LaguerreGaussianOption` | モードとウエスト                              |
| `wavelength` | `Length`                 | 波長                                          |
| `dst`        | `&mut [[Emission; _]]`   | 出力バッファ                                  |

| フィールド | 型       | 説明                                                  |
| ---------- | -------- | ----------------------------------------------------- |
| `p`        | `u32`    | 動径方向のモード次数                                  |
| `l`        | `i32`    | 方位角方向のモード次数                                |
| `waist`    | `Length` | ビームウエスト半径 <Math tex="w_0" /> (正値)          |
