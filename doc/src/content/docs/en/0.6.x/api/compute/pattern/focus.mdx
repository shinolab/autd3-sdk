`focus` generates a single focal point.

<PatternField />

## API

<CodeTabs rust={"focus(&geometry, target, wavelength, &option, &mut dst);"} python={"focus(geometry, target, wavelength, option, dst)"} csharp={"Pattern.Focus(geometry, target, wavelength, option, dst);"} />

| Parameter    | Type            | Description                                |
| ------------ | --------------- | ------------------------------------------ |
| `geometry`   | `&Geometry`     | Device layout                              |
| `target`     | `Point3<f32>`   | Focal point coordinates \[mm]               |
| `wavelength` | `Length`        | Wavelength                                 |
| `option`     | `&FocusOption`  | Additional options (see below)             |
| `dst`        | `&mut [[Emission; _]]` | Output buffer                       |

## FocusOption

<CodeTabs rust={"FocusOption {\n    intensity,\n    phase_offset,\n}"} python={"FocusOption(\n    intensity,\n    phase_offset,\n)"} csharp={"new FocusOption(\n    intensity,\n    phaseOffset\n)"} />

| Field          | Type        | Default          | Description                        |
| -------------- | ----------- | ---------------- | ---------------------------------- |
| `intensity`    | `Intensity` | `Intensity::MAX` | Amplitude of all transducers       |
| `phase_offset` | `Phase`     | `Phase::ZERO`    | Phase added uniformly to all transducers |
