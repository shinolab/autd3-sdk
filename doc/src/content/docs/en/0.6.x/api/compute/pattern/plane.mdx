`plane` generates a plane wave propagating in the specified direction.

<PatternField kind="plane" />

## API

<CodeTabs rust={"plane(&geometry, direction, wavelength, &option, &mut dst);"} python={"plane(geometry, direction, wavelength, option, dst)"} csharp={"Pattern.Plane(geometry, direction, wavelength, option, dst);"} />

| Parameter    | Type                   | Description                          |
| ------------ | ---------------------- | ----------------------------------- |
| `geometry`   | `&Geometry`            | Device layout                       |
| `direction`  | `UnitVector3<f32>`     | Propagation direction of the plane wave (unit vector) |
| `wavelength` | `Length`               | Wavelength                          |
| `option`     | `&PlaneOption`         | Additional options (see below)      |
| `dst`        | `&mut [[Emission; _]]` | Output buffer                       |

## PlaneOption

<CodeTabs rust={"PlaneOption {\n    intensity,\n    phase_offset,\n}"} python={"PlaneOption(\n    intensity,\n    phase_offset,\n)"} csharp={"new PlaneOption(\n    intensity,\n    phaseOffset\n)"} />

| Field          | Type        | Default          | Description                  |
| -------------- | ----------- | ---------------- | ---------------------------- |
| `intensity`    | `Intensity` | `Intensity::MAX` | Amplitude of all transducers |
| `phase_offset` | `Phase`     | `Phase::ZERO`    | Phase added uniformly to all transducers |
