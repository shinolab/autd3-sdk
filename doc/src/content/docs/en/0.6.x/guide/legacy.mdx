This SDK is incompatible with the old autd3 SDK, and its communication protocol is a new design.
Therefore, the regular `Client` cannot drive devices running the legacy firmware.

`LegacyClient` is a compatibility client for driving devices running the legacy firmware **v12.1.0**.

:::caution
Only v12.1.0 (CPU version major = `0xA5`) is supported.
If the firmware can be updated, use the current `Client`.
:::

## Enabling

In Rust, it is enabled by the `legacy` feature of `autd3-rs` (disabled by default).

```toml
autd3-rs = { version = "0.4", features = ["legacy"] }
```

The Python and C# bindings require no extra setup.
They are available as `autd3.LegacyClient` and the `AUTD3.Legacy` namespace respectively.

## Usage

User code has the same shape as with the current SDK.
Only replace `Client` with `LegacyClient` and `ClientConfig` with `LegacyClientConfig`.
All the current [Links](/autd3-sdk/en/0.6.x/api/link/) can be used as they are.

<CodeTabs rust={"let client = LegacyClient::open(\n    &geometry,\n    EchocatLinkOption::default(),\n    LegacyClientConfig::default(),\n)\n.await?;"} python={"client = await LegacyClient.open(\n    geometry,\n    echocat.EchocatLinkOption(),\n    LegacyClientConfig(),\n)"} csharp={"using var client = await LegacyClient.OpenAsync(\n    geometry,\n    new EchocatLinkOption(),\n    new LegacyClientConfig()\n);"} />

`LegacyClientConfig` only holds `timeout_cycles` (default 2000) and the RT thread tuning (`rt_priority` / `rt_policy` / `rt_affinity`).
The latter have the same types and the same defaults as the current `ClientConfig` (TimeCritical on Windows, unset elsewhere).

Reading the firmware version is also the same as with the current client.

<CodeTabs rust={"for (i, version) in client.read_firmware_version().await?.iter().enumerate() {\n    println!(\"device[{i}] firmware version: {version}\");\n}"} python={"for i, version in enumerate(await client.read_firmware_version()):\n    print(f\"device[{i}] firmware version: {version}\")"} csharp={"var versions = await client.ReadFirmwareVersionAsync();\nfor (var i = 0; i < versions.Count; i++)\n{\n    Console.WriteLine($\"device[{i}] firmware version: {versions[i]}\");\n}"} />

Assembling commands is the same as well (the type is `LegacyDatagramBuilder` instead of `DatagramBuilder`).
The compute helpers for [Emission patterns](/autd3-sdk/en/0.6.x/api/compute/pattern/focus/) and [AM waveforms](/autd3-sdk/en/0.6.x/api/compute/modulation/sine/) are shared too.

<CodeTabs rust={"let mut builder = client.datagram_builder();\nbuilder\n    .push(SetSilencer::default())\n    .push(Pattern::new(&emissions))\n    .push(Modulation::new(SamplingConfig::FREQ_4K, &modulation));\nlet frames = builder.build()?;\nfor frame in &frames {\n    client.send_checked(frame).await?;\n}"} python={"builder = client.datagram_builder()\nbuilder.push(SetSilencer())\nbuilder.push(Pattern(emissions))\nbuilder.push(Modulation(SamplingConfig.FREQ_4K, mod_buf))\nframes = builder.build()\nfor i in range(len(frames)):\n    await client.send_checked(frames[i])"} csharp={"using var builder = client.DatagramBuilder();\nbuilder\n    .Push(new SetSilencer())\n    .Push(new Pattern(emissions))\n    .Push(new Modulation(SamplingConfig.Freq4k, modulation));\nusing var frames = builder.Build();\nforeach (var frame in frames)\n{\n    await client.SendCheckedAsync(frame);\n}"} />

[`push_each`](/autd3-sdk/en/0.6.x/api/basics/datagram-builder/), which assigns a command per device, works the same way too.

Shutdown is the same as well.

<CodeTabs rust={"client.stop().await?;\nclient.close().await?;"} python={"await client.stop()\nawait client.close()"} csharp={"await client.StopAsync();\nawait client.CloseAsync();"} />

## Differences from the current `Client`

| Item                    | `Client`                                   | `LegacyClient`                              |
| ----------------------- | ------------------------------------------ | ------------------------------------------- |
| Send model              | Pipelined / stop-and-wait                  | Stop-and-wait only                          |
| Reading error details   | `read_error_detail()`                      | Not supported (only the ack error code)     |
| Reading telemetry counters | `read_telemetry()`                      | Not supported                               |

The pipelined send of the current client cannot be used with the legacy firmware.
Throughput is therefore substantially lower than with the current client.

## Supported Commands

The following commands are available.

* [`Clear`](/autd3-sdk/en/0.6.x/api/command/clear/)
* [`ForceFan`](/autd3-sdk/en/0.6.x/api/command/force-fan/)
* [`SetSilencer`](/autd3-sdk/en/0.6.x/api/command/silencer/)
* [`Pattern`](/autd3-sdk/en/0.6.x/api/command/pattern/)
* [`Modulation`](/autd3-sdk/en/0.6.x/api/command/modulation/)
* [`ChangeModulationBank`](/autd3-sdk/en/0.6.x/api/command/lowlevel/change-modulation-bank/)
* [`FociStm`](/autd3-sdk/en/0.6.x/api/command/foci-stm/)
* [`PatternStm`](/autd3-sdk/en/0.6.x/api/command/pattern-stm/)
* [`SetOutputMask`](/autd3-sdk/en/0.6.x/api/command/output-mask/)
* [`SetPhaseCorrection`](/autd3-sdk/en/0.6.x/api/command/phase-correction/)
* [`SetPulseWidthTable`](/autd3-sdk/en/0.6.x/api/command/set-pulse-width-table/)
* [`SetGpioOut`](/autd3-sdk/en/0.6.x/api/command/gpio/)
* [`EmulateGpioIn`](/autd3-sdk/en/0.6.x/hardware/gpio/)

The following are unavailable.

* [`WritePatternBuffer`](/autd3-sdk/en/0.6.x/api/command/lowlevel/write-pattern-buffer/)
* [`WriteModulationBuffer`](/autd3-sdk/en/0.6.x/api/command/lowlevel/write-modulation-buffer/)
* [`WriteFociBuffer`](/autd3-sdk/en/0.6.x/api/command/lowlevel/write-foci-buffer/)
* [`WritePatternCompressed`](/autd3-sdk/en/0.6.x/api/command/lowlevel/write-pattern-compressed/)
* [`ConfigPattern`](/autd3-sdk/en/0.6.x/api/command/lowlevel/config-pattern/)
* [`ConfigModulation`](/autd3-sdk/en/0.6.x/api/command/lowlevel/config-modulation/)
* [`ConfigFociStm`](/autd3-sdk/en/0.6.x/api/command/lowlevel/config-foci-stm/)
* [`ChangePatternBank`](/autd3-sdk/en/0.6.x/api/command/lowlevel/change-pattern-bank/) (see below)

### Switching the Pattern Bank

Instead of `ChangePatternBank`, use the legacy-specific `LegacyChangePatternBank`.
Choose `pattern` / `foci_stm` / `pattern_stm` according to what is being switched.

<CodeTabs rust={"let mut builder = client.datagram_builder();\nbuilder.push(Pattern::with_bank(PatternBank::B1, &emissions));\nfor frame in &builder.build()? {\n    client.send_checked(frame).await?;\n}\n\nlet mut builder = client.datagram_builder();\nbuilder.push(LegacyChangePatternBank::pattern(PatternBank::B0));\nfor frame in &builder.build()? {\n    client.send_checked(frame).await?;\n}"} python={"builder = client.datagram_builder()\nbuilder.push(Pattern(emissions, PatternBank.B1))\nframes = builder.build()\nfor i in range(len(frames)):\n    await client.send_checked(frames[i])\n\nbuilder = client.datagram_builder()\nbuilder.push(LegacyChangePatternBank.pattern(PatternBank.B0))\nframes = builder.build()\nfor i in range(len(frames)):\n    await client.send_checked(frames[i])"} csharp={"using (var bankBuilder = client.DatagramBuilder())\n{\n    bankBuilder.Push(new Pattern(PatternBank.B1, emissions));\n    using var bankFrames = bankBuilder.Build();\n    foreach (var frame in bankFrames)\n    {\n        await client.SendCheckedAsync(frame);\n    }\n}\n\nusing (var bankBuilder = client.DatagramBuilder())\n{\n    bankBuilder.Push(LegacyChangePatternBank.Pattern(PatternBank.B0));\n    using var bankFrames = bankBuilder.Build();\n    foreach (var frame in bankFrames)\n    {\n        await client.SendCheckedAsync(frame);\n    }\n}"} />
