`ActivateModulationBank` is a low-level command that activates the Modulation bank to be played.

## API

<CodeTabs rust={"ActivateModulationBank {\n    bank,\n    transition_mode,\n};"} python={"ActivateModulationBank(\n    bank=bank,\n    transition_mode=transition_mode,\n)"} csharp={"new ActivateModulationBank(\n    bank: bank,\n    transitionMode: transitionMode\n);"} />

| Field             | Type             | Description             |
| ----------------- | ---------------- | ----------------------- |
| `bank`            | `ModulationBank` | Destination bank        |
| `transition_mode` | `TransitionMode` | Behavior on switching   |

## TransitionMode

|            |              |
| -------------------- | --------------------------        |
| `Immediate`          | Immediate                         |
| `SyncIdx`            | When the playback index next becomes 0 |
| `SysTime(SysTime)`   | At the specified device time      |
| `Gpio(GpioIn)`       | Trigger on the specified GPIO input pin |
| `Ext`                | Extended mode (automatically switches to the next bank when playback within the bank finishes) |
| `Later`              | Does not transition (only writes to the bank) |

`SysTime` rejects a time earlier than "now + margin" with a `MISS_TRANSITION_TIME` error, because the FPGA may miss a transition whose time is too close.
The margin defaults to 10 ms and can be changed with `sys_time_transition_margin` of [SetCpuConfig](/autd3-sdk/en/0.11.x/api/command/cpu-config/).

`Later` means "only write to the bank, do not transition".
Specifying it as the `transition_mode` of `Modulation` / `FociStm` / `PatternStm` writes and configures the bank without sending the trailing bank change.
Specifying it on `ActivateModulationBank` / `ActivatePatternBank` themselves, which are the transition commands, is an encode-time error.

See [GPIO pins](/autd3-sdk/en/0.11.x/hardware/gpio/) for details on `Gpio(GpioIn)`.

When switching to the same bank, the `TransitionMode` and `LoopBehavior` settings have no effect.
For details on bank operation see the [bank switching tutorial](/autd3-sdk/en/0.11.x/getting-started/tutorial/bank/).
