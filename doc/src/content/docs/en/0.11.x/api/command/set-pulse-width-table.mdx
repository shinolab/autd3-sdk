`SetPulseWidthTable` is a command that sets the conversion table from intensity (0–255) to the PWM pulse width.

## API

<CodeTabs rust={"SetPulseWidthTable { table: &table };"} python={"SetPulseWidthTable(table)"} csharp={"new SetPulseWidthTable(table);"} />

| Field   | Type                    | Description                                              |
| ------- | ----------------------- | ------------------------------------------------------- |
| `table` | `&[u16; PWE_TABLE_SIZE]` | Pulse width per intensity index (0–255) (256 elements) |

The default command sets an arcsin-shaped table.
This is a table that makes the output sound pressure (theoretically) linear with respect to intensity, and it is the same table the device holds at boot.

<CodeTabs rust={"SetPulseWidthTable::default();"} python={"SetPulseWidthTable()"} csharp={"new SetPulseWidthTable();"} />

`empty_table` returns a table whose entries are all 0.

<CodeTabs rust={"let table = SetPulseWidthTable::empty_table();"} python={"table = SetPulseWidthTable.empty_table()"} csharp={"var table = SetPulseWidthTable.EmptyTable();"} />
