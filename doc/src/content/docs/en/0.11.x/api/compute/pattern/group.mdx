Selects, per transducer, which pattern's emission is output.
The transducers are split by assigning keys (an enum, for example) with `TransducerGroups`. Every transducer belongs to one of the keys.

There are two composing APIs.

* `group_compute` — receives each key together with its `TransducerMask`, computes, and composes the results.
* `group` — composes precomputed buffers selected by key. Use it to reuse results or to compute groups in parallel.

:::note
If you only need to switch per device, send a command per device with [`each`](/autd3-sdk/en/0.11.x/api/basics/client/#each) instead of these.
:::

| Parameter  | Type                                                                 | Description                                              |
| ---------- | -------------------------------------------------------------------- | -------------------------------------------------------- |
| `geometry` | `&Geometry`                                                          | Geometry                                                 |
| `groups`   | `&TransducerGroups<K>`                                               | Key of each transducer                                   |
| `compute`     | `FnMut(K, TransducerMask, &mut [Vec<Phase>], &mut [Vec<Intensity>]) -> Result<(), E>` | Computes into the scratch buffers (phases and intensities) for a key and its mask |
| `phases`      | `&mut [Vec<Phase>]`                                                                    | Phase output buffer                                                              |
| `intensities` | `&mut [Vec<Intensity>]`                                                                | Intensity output buffer                                                          |

`compute` is called once per key (in order of first appearance), and only the transducers of that key are written into `phases` / `intensities`.
The scratch buffers are reset to phase 0 and the maximum intensity for each key.

## group

| Parameter  | Type                                        | Description                              |
| ---------- | ------------------------------------------- | ---------------------------------------- |
| `geometry` | `&Geometry`                                 | Geometry                                 |
| `groups`   | `&TransducerGroups<K>`                      | Key of each transducer                   |
| `source`   | `FnMut(K) -> impl AsRef<[Vec<T>]>`          | Returns the source buffer for a key      |
| `dst`      | `&mut [Vec<T>]`                             | Output buffer                            |

`T` is `Phase` or `Intensity`; call it once for each of the phase and intensity buffers.

## TransducerGroups

`TransducerGroups::new(&geometry, |device, tr| ...)` returns a key from a device and transducer index, and keeps the key of each transducer.
A transducer cannot be left without a group. To silence some transducers, assign them a key of their own and write `Intensity::MIN` for it (in Python, a key function that returns `None` raises `ValueError`).
Keys are `Copy + Eq` types in Rust, any non-null type (such as an `enum` or a `string`) in C#, and hashable values in Python.
`mask(key)` returns a `TransducerMask` for [Holo](/autd3-sdk/en/0.11.x/api/compute/holo/) that enables only the transducers with `key`. For a key that no transducer is assigned, Rust returns `None`, C# returns `null`, and Python raises `KeyError`.
