`SysTime` is a type representing the time of the devices.
It is used with [`TransitionMode::SysTime`](/autd3-sdk/en/0.11.x/getting-started/tutorial/loop/), [`GpioOut::SysTimeEq`](/autd3-sdk/en/0.11.x/api/command/gpio/), and the like.

Each device has its own clock, and output switching and the like happen on this time.
This time is a 64-bit counter in ns units, counted from the moment the `Client` opens.
It does not correspond to the host clock (date and time).
The current time of the devices is obtained with `device_time_now()` of the `Client`.

## Construction

`SysTime` is constructed from the current time of the devices or raw ns.

<CodeTabs rust={"let opened = SysTime::ZERO;\nlet now = client.device_time_now()?;\nlet raw = SysTime::from_nanos(1_000_000_000);\nlet ns: u64 = now.sys_time();"} python={"opened = SysTime.ZERO\nnow = client.device_time_now()\nraw = SysTime.from_nanos(1_000_000_000)\nns = now.sys_time"} csharp={"var opened = SysTime.Zero;\nvar now = client.DeviceTimeNow();\nvar raw = SysTime.FromNanos(1_000_000_000);\nulong ns = now.Nanos;"} />

| Operation               | Description                                                    |
| ----------------------- | ------------------------------------------------------------- |
| `ZERO`                  | The moment the `Client` opened                                |
| `Client::device_time_now()` | Current time of the devices (C#: `DeviceTimeNow()`)       |
| `from_nanos(ns)`        | Construct from ns elapsed since the open                      |
| `sys_time()`            | ns elapsed since the open                                     |

## Arithmetic

`SysTime` defines operations that add and subtract time differences.

<CodeTabs rust={"let future = client.device_time_now()? + Duration::from_millis(100);\nlet past = future - Duration::from_millis(50);\nlet elapsed: Duration = future - past;\nlet is_after: bool = future > past; // true"} python={"future = client.device_time_now() + Duration.from_millis(100)\npast = future - Duration.from_millis(50)\nelapsed = future - past\nis_after = future > past"} csharp={"var future = client.DeviceTimeNow() + TimeSpan.FromMilliseconds(100);\nvar past = future - TimeSpan.FromMilliseconds(50);\nTimeSpan elapsed = future - past;\nbool isAfter = future > past; // true"} />

| Operation                     | Result       | Description                              |
| ----------------------------- | ------------ | ---------------------------------------- |
| `SysTime + Duration`        | `SysTime`  | Add the specified duration               |
| `SysTime - Duration`        | `SysTime`  | Subtract the specified duration          |
| `SysTime - SysTime`       | `Duration`   | Difference between two times (0 if it would be negative) |
| Comparison (`<` / `>` / `==`, etc.) | `bool` | Comparison                               |
