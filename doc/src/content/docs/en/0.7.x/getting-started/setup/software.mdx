The AUTD3 SDK is implemented in Rust and also provides bindings for Python / C#.
A package for [Unity](#unity) is also provided.
The packages provided for each language are as follows.

## Unity

The Unity package is distributed via the npm registry ([npmjs](https://www.npmjs.com/package/com.shinolab.autd3-sdk)).

The supported Unity version is 6 (6000.x) or later.

* [com.shinolab.autd3-sdk](https://www.npmjs.com/package/com.shinolab.autd3-sdk): Client
* [com.shinolab.autd3-sdk.core](https://www.npmjs.com/package/com.shinolab.autd3-sdk.core): Core layer
* [com.shinolab.autd3-sdk.pattern](https://www.npmjs.com/package/com.shinolab.autd3-sdk.pattern): Pattern computation (single focal point, etc.)
* [com.shinolab.autd3-sdk.pattern.holo](https://www.npmjs.com/package/com.shinolab.autd3-sdk.pattern.holo): Multi-focus optimization
* [com.shinolab.autd3-sdk.modulation](https://www.npmjs.com/package/com.shinolab.autd3-sdk.modulation): AM modulation computation
* [com.shinolab.autd3-sdk.link.echocat](https://www.npmjs.com/package/com.shinolab.autd3-sdk.link.echocat): AUTD3 dedicated EtherCAT Link
* [com.shinolab.autd3-sdk.link.ethercrab](https://www.npmjs.com/package/com.shinolab.autd3-sdk.link.ethercrab): [EtherCrab](https://github.com/ethercrab-rs/ethercrab)-based Link
* [com.shinolab.autd3-sdk.link.remote](https://www.npmjs.com/package/com.shinolab.autd3-sdk.link.remote): Link for remote connections
* [com.shinolab.autd3-sdk.link.twincat](https://www.npmjs.com/package/com.shinolab.autd3-sdk.link.twincat): TwinCAT-based Link
* [com.shinolab.autd3-sdk.link.nop](https://www.npmjs.com/package/com.shinolab.autd3-sdk.link.nop): Link that does nothing (for testing)

### Installation

Add the scoped registry and the required packages to the Unity project's `Packages/manifest.json`.

```json
{
  "scopedRegistries": [
    { 
        "name": "npmjs",
        "url": "https://registry.npmjs.org", 
        "scopes": ["com.shinolab"]
    }
  ],
  "dependencies": {
    "com.shinolab.autd3-sdk": "0.7.0",
    "com.shinolab.autd3-sdk.pattern": "0.7.0",
    "com.shinolab.autd3-sdk.modulation": "0.7.0",
    "com.shinolab.autd3-sdk.link.echocat": "0.7.0"
  }
}
```

To do this from the GUI, add the following registry under **Edit → Project Settings → Package Manager → Scoped Registries**.

* Name: `npmjs`
* URL: `https://registry.npmjs.org`
* Scope(s): `com.shinolab`

Then add the required packages from **Window → Package Manager → My registries → npmjs**.

:::note
The Unity version of the API is left-handed and uses meters as its unit.
A device emits along its local -z direction.
:::
