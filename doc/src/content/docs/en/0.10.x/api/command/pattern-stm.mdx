`PatternStm` provides an STM feature that switches arbitrary sound fields (the phase and intensity of each transducer) by a hardware timer.
Unlike [FociStm](/autd3-sdk/en/0.10.x/api/command/foci-stm/), it can handle arbitrary Patterns, but the amount of data to transfer is large (i.e. the latency is high).

## API

<CodeTabs rust={"PatternStm::new(freq, &patterns, intensities, option);"} python={"PatternStm(freq, patterns, intensities, option)"} csharp={"new PatternStm(freq, patterns, intensities, option);"} />

| Parameter  | Type                                  | Description                                          |
| ---------- | ------------------------------------- | --------------------------------------------------- |
| `freq`     | `impl Into<StmConfig>`                | Playback rate (`Freq` / `Duration` / `SamplingConfig`) |
| `phases`      | `&[Vec<Vec<Phase>>]`     | Phases of each sample (at least 2 samples)                  |
| `intensities` | `impl Into<StmIntensity>` | Intensities for every sample (a uniform value, one buffer shared by all indices, or one buffer per index) |
| `option`   | `PatternStmOption`                    | Options such as phase depth, loop, and transition |

Passing a `Freq` / `Duration` to `freq` represents "the frequency/period for one full cycle over all samples".
A sampling frequency can also be specified.
A `Duration` that is not divisible by the number of samples is an error (use `Nearest` to round it).

`intensities` accepts the following three types.

* `Intensity`: to use the same value for every device, every transducer and every index
* `&[Vec<Intensity>]`: to use values that differ per transducer but are shared by all indices
* `&[Vec<Vec<Intensity>>]`: to use a different value for every index

## PatternStmOption

<CodeTabs rust={"PatternStmOption {\n    bank,\n    phase_depth,\n    loop_behavior,\n    transition_mode,\n    ..Default::default()\n}"} python={"PatternStmOption(\n    bank,\n    phase_depth,\n    loop_behavior,\n    transition_mode,\n)"} csharp={"new PatternStmOption\n{\n    Bank = bank,\n    PhaseDepth = phaseDepth,\n    LoopBehavior = loopBehavior,\n    TransitionMode = transitionMode,\n}"} />

| Field             | Type             | Default                              | Description                  |
| ----------------- | ---------------- | ------------------------------------ | ---------------------------- |
| `bank`            | `PatternBank`    | `PatternBank::B0`                    | Bank to write to / play back |
| `phase_depth`     | `PhaseDepth`     | `PhaseDepth::Bits8`                  | Bit depth of the phase       |
| `loop_behavior`   | `LoopBehavior`   | `LoopBehavior::Infinite`             | Loop count                   |
| `transition_mode` | `TransitionMode` | `TransitionMode::Immediate`          | Transition timing on bank switching |

For the behavior of `loop_behavior` and `transition_mode`, see [playback control](/autd3-sdk/en/0.10.x/api/command/lowlevel/activate-pattern-bank/).

## Transfer Format

| `intensities`                                 | `PhaseDepth::Bits8`                        | `PhaseDepth::Bits4`                        |
| --------------------------------------------- | ------------------------------------------ | ------------------------------------------ |
| `Intensity`                                   | `WritePatternPhase` (5 indices/frame)      | `WritePatternPhase` (11 indices/frame)     |
| `&[Vec<Intensity>]` / `&[Vec<Vec<Intensity>>]` | `WritePatternBuffer` (2 indices/frame)     | Error                                      |

`Bits4` quantizes the phase to its upper 4 bits.

## Equivalent Low-Level Commands

`PatternStm` internally expands into the three commands [WritePatternPhase](/autd3-sdk/en/0.10.x/api/command/lowlevel/write-pattern-phase/) or [WritePatternBuffer](/autd3-sdk/en/0.10.x/api/command/lowlevel/write-pattern-buffer/) (each index) + [ConfigPattern](/autd3-sdk/en/0.10.x/api/command/lowlevel/config-pattern/) + [ActivatePatternBank](/autd3-sdk/en/0.10.x/api/command/lowlevel/activate-pattern-bank/).
The following is equivalent to `PatternStm::new(freq, &phases, intensities, option)` when `intensities` is a uniform value.
When `intensities` holds per-transducer values, `WritePatternBuffer` is used for each index instead of `WritePatternPhase`.
