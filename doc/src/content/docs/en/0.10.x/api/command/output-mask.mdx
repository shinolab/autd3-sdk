`SetOutputMask` is a command that toggles output enable/disable per transducer.

## API

<CodeTabs rust={"SetOutputMask { masks: &masks };"} python={"SetOutputMask(masks)"} csharp={"new SetOutputMask(masks);"} />

| Field   | Type           | Description                                                    |
| ------- | -------------- | ------------------------------------------------------------- |
| `masks` | `&[Vec<bool>]` | Output mask per device (output when `true`). |

`Geometry::output_mask_buffer` allocates the masks for all devices.
Every entry starts at `true` (all transducers output).

## Example
