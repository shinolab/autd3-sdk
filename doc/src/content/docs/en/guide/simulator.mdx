`Simulator` is a sound field simulator that visualizes the AUTD3 output sound field in a browser.
Even without real hardware, you can check the sound field generated from the data sent by the client.

## Launching

`Simulator` is bundled with the GUI console `autd3-console`.

Obtain `autd3-console` as described in [Console](/autd3-sdk/en/guide/console/), launch it, and open the "Simulator" tab at the top.

## Connecting

The client must run on the same host as the Simulator.

The Simulator listens on port 44336 by default. Change the port with "UDP port" in the Simulator tab of the console.

To connect from the client, set `iface` of [`TransportOption`](/autd3-sdk/en/api/basics/transport-option/) to `Addr` with `[::1]:44336`.

<CodeTabs
  rust={'let option = TransportOption {\n    iface: Interface::Addr("[::1]:44336".parse()?),\n    ..Default::default()\n};'}
  python={'option = TransportOption(iface=Interface.Addr("[::1]:44336"))'}
  csharp={'var option = new TransportOption { Iface = Interface.Addr("[::1]:44336") };'}
/>

## Geometry

Set the number and placement of devices in the Simulator window (the Geometry tab).
Before opening the client, make the number and placement of devices in the Geometry tab match the client's geometry.

The Simulator always starts with one device at the origin. To reuse a geometry next time, save it with "Save to file" and load it with "Load from file".
