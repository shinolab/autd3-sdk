`Simulator` is a sound field simulator that visualizes the AUTD3 output sound field in a browser.
Even without real hardware, you can check the sound field generated from the data sent by the client.

## Launching

`Simulator` is bundled with the GUI console `autd3-console`.

Obtain `autd3-console` as described in [Console](/autd3-sdk/en/guide/console/), launch it, and open the "Simulator" tab at the top.
The tab's "Geometry JSON" is the geometry file (one device at the origin when empty).

## Connecting

`Simulator` emulates a chain of AUTD3 devices on the host (`::1`) and listens over the same UDP as real devices.
The listening address is fixed at `[::1]:44336`, so the client runs on the same host as the Simulator.

The default [`TransportOption`](/autd3-sdk/en/api/connection/) (`iface` set to `Auto`) connects to the Simulator when it is running, and to real devices otherwise.
No address needs to be given.

:::caution
With `Auto`, forgetting to launch the Simulator connects to the real devices, which then emit ultrasound.
To connect to nothing but the Simulator, set `iface` to `Simulator`. Opening fails when the Simulator is not running.
:::

<CodeTabs
  rust={'let option = TransportOption {\n    iface: Interface::Simulator,\n    ..Default::default()\n};'}
  python={'option = TransportOption(iface=Interface.Simulator)'}
  csharp={'var option = new TransportOption { Iface = Interface.Simulator };'}
/>

Conversely, to reach real devices while the Simulator keeps running, name the NIC with `Name(..)` in `iface`.

The Simulator serves every device in one process, so its replies may be late. If sends end in `Timeout`, widen `ack_timeout` of `ClientConfig` (10 ms by default) and `reply_timeout` of `TransportOption` (1 ms by default).

The layout of the emulated devices is given on the Simulator side.
When launching the Simulator by itself, pass a `Geometry` JSON (the output of `Geometry::to_json`) to `--geometry <file>` (one device at the origin when omitted).
Opening fails if the number of devices differs from the client's geometry.
Only one Simulator can run on a host at a time.
