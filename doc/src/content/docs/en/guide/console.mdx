`autd3-console` is a GUI tool that gathers firmware flashing, the simulator and the server in one place.

## Obtaining it

It is distributed via GitHub Releases (`console-v*`).
Open [console-v0.12.0](https://github.com/shinolab/autd3-sdk/releases/tag/console-v0.12.0) and run the install command shown there.

If you do not use the installer, download the archive from the same release (`console-<target>.tar.xz` / `.zip`),
extract it, and run `autd3-console`.

### macOS

The macOS binaries are not signed or notarized with an Apple Developer ID, so Gatekeeper blocks them
with "cannot be opened because the developer cannot be verified".
Remove the quarantine attribute after installing to run it:

```console
xattr -d com.apple.quarantine ~/.autd3/bin/autd3-console
```

If you are running an extracted archive, apply it to the extracted directory instead:

```console
xattr -dr com.apple.quarantine <extracted directory>
```

## Bundled commands

Commands that can be run directly without the GUI are also bundled.

| Command | Purpose |
| --- | --- |
| `autd3-console` | The GUI itself |
| `autd3-firmware-writer` | Flashing the [firmware](/autd3-sdk/en/getting-started/setup/firmware/) (JTAG) |
| `autd3-firmware-ota` | Updating the [firmware](/autd3-sdk/en/getting-started/setup/firmware/#ota-over-an-ethernet-cable) (OTA) |
| `autd3-simulator` | The [simulator](/autd3-sdk/en/guide/simulator/) |
| `autd3-server` | The [server](/autd3-sdk/en/guide/server/) |

## Tabs

Tabs are shown along the top once it starts.

| Tab | Contents |
| --- | --- |
| Simulator | Launching the [simulator](/autd3-sdk/en/guide/simulator/) |
| Server | Launching the [server](/autd3-sdk/en/guide/server/) and showing the state of the devices |
| Firmware | [Updating the firmware](/autd3-sdk/en/getting-started/setup/firmware/) (JTAG / OTA) |

## Updates

It checks for a newer release at startup.
If it was installed with the installer it can update itself; if you are running an extracted archive it opens the Releases page instead.
