This SDK is incompatible with the old autd3 SDK, and its communication protocol is a new design.
Therefore, the regular `Client` cannot drive devices running the legacy firmware.

`LegacyClient` is a compatibility client for driving devices running the legacy firmware **v12.1.0**.

:::caution
Only v12.1.0 (CPU version major = `0xA5`) is supported.
If the firmware can be updated, use the current `Client`.
:::

## Enabling

In Rust, it is enabled by the `legacy` feature of `autd3-rs` (disabled by default).

```toml
autd3-rs = { version = "0.4", features = ["legacy"] }
```

The Python and C# bindings require no extra setup.
They are available as `autd3.LegacyClient` and the `AUTD3.Legacy` namespace respectively.

## Usage

User code has the same shape as with the current SDK.
Only replace `Client` with `LegacyClient` and `ClientConfig` with `LegacyClientConfig`.
All the current [Links](/autd3-sdk/en/api/link/ethercrab/) can be used as they are.

## Differences from the current `Client`

| Item                    | `Client`                                   | `LegacyClient`                              |
| ----------------------- | ------------------------------------------ | ------------------------------------------- |
| Send model              | Pipelined / stop-and-wait                  | Stop-and-wait only                          |
| Reading error details   | `read_error_detail()`                      | Not supported (only the ack error code)     |
| Reading telemetry counters | `read_telemetry()`                      | Not supported                               |

The pipelined send of the current client cannot be used with the legacy firmware.
Throughput is therefore substantially lower than with the current client.

## Supported Commands

The following commands are available.

- [`Clear`](/autd3-sdk/en/api/command/clear/)
- [`ForceFan`](/autd3-sdk/en/api/command/force-fan/)
- [`SetSilencer`](/autd3-sdk/en/api/command/silencer/)
- [`Pattern`](/autd3-sdk/en/api/command/pattern/)
- [`Modulation`](/autd3-sdk/en/api/command/modulation/)
- [`ChangeModulationBank`](/autd3-sdk/en/api/command/lowlevel/change-modulation-bank/)
- [`FociStm`](/autd3-sdk/en/api/command/foci-stm/)
- [`PatternStm`](/autd3-sdk/en/api/command/pattern-stm/)
- [`SetOutputMask`](/autd3-sdk/en/api/command/output-mask/)
- [`SetPhaseCorrection`](/autd3-sdk/en/api/command/phase-correction/)
- [`SetPulseWidthTable`](/autd3-sdk/en/api/command/set-pulse-width-table/)
- [`SetGpioOut`](/autd3-sdk/en/api/command/gpio/)
- [`EmulateGpioIn`](/autd3-sdk/en/hardware/gpio/)

The following are unavailable.

- [`WritePatternBuffer`](/autd3-sdk/en/api/command/lowlevel/write-pattern-buffer/)
- [`WriteModulationBuffer`](/autd3-sdk/en/api/command/lowlevel/write-modulation-buffer/)
- [`WriteFociBuffer`](/autd3-sdk/en/api/command/lowlevel/write-foci-buffer/)
- [`WritePatternCompressed`](/autd3-sdk/en/api/command/lowlevel/write-pattern-compressed/)
- [`ConfigPattern`](/autd3-sdk/en/api/command/lowlevel/config-pattern/)
- [`ConfigModulation`](/autd3-sdk/en/api/command/lowlevel/config-modulation/)
- [`ConfigFociStm`](/autd3-sdk/en/api/command/lowlevel/config-foci-stm/)
- [`ChangePatternBank`](/autd3-sdk/en/api/command/lowlevel/change-pattern-bank/) (see below)
