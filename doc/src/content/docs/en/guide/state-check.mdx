## Obtaining the State

`StateChecker::check` returns the state `DeviceStatus` at the time of the call.
`DeviceStatus` holds the following.

- `devices`: the state of each device (`DeviceState`). `Ready` when normal, `Lost` when disconnected, etc.
- `all_ready`: whether all devices are in the `Ready` state.
- `any_lost`: whether any device is in the `Lost` state.

See [Connection](/autd3-sdk/en/api/connection/#state-monitoring) for the meaning of each state. A device is `Ready` when it follows the time of ID 0 and its sync pulse is running, `Syncing` while it is still following or its sync pulse is not running yet, and `Lost` when its replies stop or it reboots; there is no automatic recovery from `Lost` (reopen the client).
