This section explains how to drive a single device.

## Installing the required software

This tutorial uses [echocat](/autd3-sdk/en/api/link/echocat/).
If you are on Windows, install [Npcap](https://npcap.com/) in "**WinPcap API-compatible Mode**".

The following is an example that generates a focal point 150 mm directly above the center of the array with a single AUTD3 device and applies a 200 Hz sine-wave AM.

<Fragment slot="rust" >
First, create an appropriate project and add the autd3 library as a dependency.
Also add the autd3-rs-link-echocat library, which handles communication with the device.
An asynchronous runtime is also required, so add tokio as well.

```
cargo new --bin autd3-sample && cd autd3-sample
cargo add autd3-rs
cargo add autd3-rs-link-echocat
cargo add tokio --features full
```
Next, edit the `src/main.rs` file to look like the following.

<Code code={excerpt(focusRust)} lang="rust" />

Then, run it.
```
cargo run --release
```

On Linux and macOS, administrator privileges may be required to use echocat. In that case, use:
```
cargo build --release && sudo ./target/release/autd3_sample
```

<Fragment slot="python" >
First, create an appropriate directory, prepare a virtual environment, and add the autd3 library.
Also add autd3-link-echocat for communication with the device, autd3-pattern for focus computation, and autd3-modulation for AM modulation.

```
mkdir autd3-sample && cd autd3-sample
python3 -m venv .venv
source .venv/bin/activate
pip install autd3 autd3-pattern autd3-modulation autd3-link-echocat
```

```
sudo .venv/bin/python3 main.py
```
