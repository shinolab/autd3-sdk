This section explains how to drive a single device.

## Preparation

This tutorial connects the host NIC directly to the device over [UDP](/autd3-sdk/en/api/connection/).
Complete the [host network setup](/autd3-sdk/en/getting-started/setup/network/) (allowing inbound traffic in the firewall and so on) beforehand.
No IP address needs to be configured on the host NIC, and no administrator privileges are required.

:::note
Without hardware, pass the `TransportOption` of the [device emulator](/autd3-sdk/en/api/connection/device-emulator/) or the [Simulator](/autd3-sdk/en/guide/simulator/) instead of `TransportOption::default()`; the same code runs unchanged.
:::

The following is an example that generates a focal point 150 mm directly above the center of the array with a single AUTD3 device and applies a 200 Hz sine-wave AM.

<Fragment slot="rust" >
First, create an appropriate project and add the `autd3-rs` library as a dependency.
For focus computation and AM modulation, also add `autd3-rs-pattern` and `autd3-rs-modulation`.
The `autd3-rs` API is asynchronous but runtime-agnostic. 
Here tokio is added because the example waits for Ctrl+C.

```
cargo new --bin autd3-sample && cd autd3-sample
cargo add autd3-rs
cargo add autd3-rs-pattern
cargo add autd3-rs-modulation
cargo add tokio --features full
```
