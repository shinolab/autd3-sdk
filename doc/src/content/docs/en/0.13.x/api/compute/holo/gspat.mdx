gspat is an algorithm that speeds up [gs](/autd3-sdk/en/0.13.x/api/compute/holo/gs/).
The algorithm is based on the paper by Plasencia et al. ([Plasencia et al., 2020](https://doi.org/10.1145/3386569.3392492)).

## API

<CodeTabs rust={"gspat(\n    &NalgebraBackend,\n    &geometry,\n    &foci,\n    wavelength,\n    &option,\n    &mut phases,\n    &mut intensities,\n)?;"} python={"gspat(geometry, foci, wavelength, option, phases, intensities)"} csharp={"Holo.Gspat(geometry, foci, wavelength, option, phases, intensities);"} />

| Parameter    | Type                   | Description               |
| ------------ | ---------------------- | ------------------------- |
| `geometry`   | `&Geometry`            | Device layout             |
| `foci`       | `&[AmplitudeTarget]`      | Sequence of focal points (position and target amplitude) |
| `wavelength` | `Length`               | Wavelength                |
| `option`     | `&GspatOption`         | Additional options (see below) |
| `phases`      | `&mut [Vec<Phase>]`     | Phase output buffer       |
| `intensities` | `&mut [Vec<Intensity>]` | Intensity output buffer   |

The parameters are the same as [gs](/autd3-sdk/en/0.13.x/api/compute/holo/gs/).

## GspatOption

<CodeTabs rust={"GspatOption {\n    repeat,\n    constraint,\n    directivity,\n    mask,\n}"} python={"GspatOption(\n    repeat,\n    constraint,\n    directivity,\n    mask,\n)"} csharp={"new GspatOption\n{\n    Repeat = repeat,\n    Constraint = constraint,\n    Directivity = directivity,\n    Mask = mask,\n}"} />

| Field         | Type                 | Default                   |
|---------------|----------------------|---------------------------|
| `repeat`      | `NonZeroUsize`       | `100`                     |
| `constraint`  | `IntensityConstraint` | `Clamp(MIN, MAX)`         |
| `directivity` | `Directivity`        | `Sphere`                  |
| `mask`        | `TransducerMask`     | `AllEnabled`              |

The options are the same as [gs](/autd3-sdk/en/0.13.x/api/compute/holo/gs/).
