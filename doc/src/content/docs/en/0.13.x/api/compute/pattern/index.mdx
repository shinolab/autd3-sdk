Representative sound field computation utilities such as a single focal point, a plane wave, a Bessel beam, a Laguerre-Gaussian beam, and a Hermite-Gaussian beam.

<Install rust="autd3-rs-pattern" python="autd3-pattern" csharp="AUTD3.Pattern" />

## Function List

* [focus](/autd3-sdk/en/0.13.x/api/compute/pattern/focus/) — single focal point
* [plane](/autd3-sdk/en/0.13.x/api/compute/pattern/plane/) — plane wave
* [bessel](/autd3-sdk/en/0.13.x/api/compute/pattern/bessel/) — Bessel beam
* [laguerre\_gaussian\_phase / laguerre\_gaussian\_intensity](/autd3-sdk/en/0.13.x/api/compute/pattern/laguerre-gaussian/) — phase and intensity of a Laguerre-Gaussian beam
* [hermite\_gaussian\_phase / hermite\_gaussian\_intensity](/autd3-sdk/en/0.13.x/api/compute/pattern/hermite-gaussian/) — phase and intensity of a Hermite-Gaussian beam

`focus` / `plane` / `bessel` / `laguerre_gaussian_phase` / `hermite_gaussian_phase` also have a `*_transducer` variant that returns the phase of a single transducer element (for example, `focus_transducer`).
`laguerre_gaussian_intensity` / `hermite_gaussian_intensity` have no per-transducer variant.

## Wavelength

The phase computation requires the wavelength <Math tex="\lambda = c / f" />.
The wavelength can be obtained from the sound speed <Math tex="c" /> via `autd3_rs_pattern::wavelength(sound_speed)` (Python: `autd3_pattern.wavelength`, C#: `Pattern.Wavelength`).
At a sound speed of 340 m/s (the speed of sound in air at a room temperature of about 15°C), <Math tex="\lambda = 8.5\,\mathrm{mm}" />.
