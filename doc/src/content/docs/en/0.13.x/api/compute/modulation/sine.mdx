`sine` generates a sine-wave amplitude modulation.

<ModulationPlot fixed="freq = 200 Hz (clamp = true)" />

## API

<CodeTabs rust={"sine(freq, &option, sampling_config, &mut dst)?;"} python={"sine(freq, option, sampling_config, dst)"} csharp={"Modulation.Sine(freq, option, samplingConfig, dst);"} />

| Parameter | Type           | Description                                  |
| --------- | -------------- | -------------------------------------------- |
| `freq`    | `Freq` etc.      | modulation frequency                       |
| `option`  | `&SineOption`  | additional options (see below)               |
| `config`  | `SamplingConfig` | sampling configuration (see [Modulation](/autd3-sdk/en/0.13.x/api/compute/modulation/#samplingconfig)) |
| `dst`     | `&mut Vec<u8>` | output buffer                                |

The value of each sample <Math tex="i" /> is given by the following equation, for amplitude <Math tex="A" /> (`amplitude`), offset <Math tex="b" /> (`offset`), and phase <Math tex="\theta" /> (`phase`).

<MathBlock tex="m_i = \frac{A}{2}\sin\!\left(2\pi f t_i + \theta\right) + b" />

`freq` is specified as a `Freq` (`150 * Hz` or `150.0 * Hz`). `150 * Hz` and `150.0 * Hz` represent the same frequency.

## SineOption

<CodeTabs rust={"SineOption {\n    amplitude,\n    offset,\n    phase,\n    clamp,\n    ..Default::default()\n}"} python={"SineOption(\n    amplitude,\n    offset,\n    phase,\n    clamp,\n)"} csharp={"new SineOption\n{\n    Amplitude = amplitude,\n    Offset = offset,\n    Phase = phase,\n    Clamp = clamp,\n}"} />

| Field             | Type             | Default                 | Description                                              |
| ----------------- | ---------------- | ----------------------- | -------------------------------------------------------- |
| `amplitude`       | `u8`             | `0xFF`                  | amplitude of the sine wave                               |
| `offset`          | `u8`             | `0x80`                  | DC offset                                                |
| `phase`           | `Angle`          | `Angle::ZERO`           | phase                                                    |
| `clamp`           | `bool`           | `false`                 | whether to clamp out-of-range values to \[0, 255]         |

If the combination of `amplitude` and `offset` causes the waveform to fall outside the \[0, 255] range, an error occurs when `clamp` is `false`.
Choose values that stay within range, or set `clamp` to `true`.

## Constraints

Due to the [constraints of SamplingConfig](/autd3-sdk/en/0.13.x/api/basics/sampling-config/), the specified frequency may not be a representable frequency.
`freq` must be a frequency that fits an integer number of samples in a period; otherwise an error is returned.
