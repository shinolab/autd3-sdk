`ConfigModulation` is a low-level command that configures the playback parameters of the Modulation bank.
The settings are only written; send [ActivateModulationBank](/autd3-sdk/en/0.13.x/api/command/lowlevel/activate-modulation-bank/) to activate them.

## API

<CodeTabs rust={"ConfigModulation {\n    bank,\n    config,\n    size,\n    loop_behavior,\n};"} python={"ConfigModulation(\n    bank=bank,\n    config=config,\n    size=size,\n    loop_behavior=loop_behavior,\n)"} csharp={"new ConfigModulation(\n    bank: bank,\n    config: config,\n    size: size,\n    loopBehavior: loopBehavior\n);"} />

| Field      | Type             | Description                                        |
| ---------- | ---------------- | -------------------------------------------------- |
| `bank`     | `ModulationBank` | Target bank                                        |
| `config`   | `SamplingConfig` | Playback sampling frequency                        |
| `size`     | `usize`          | Number of samples                                  |
| `loop_behavior` | `LoopBehavior` | Playback loop count (`Infinite` / `Finite`)       |

The minimum `size` is 2.
