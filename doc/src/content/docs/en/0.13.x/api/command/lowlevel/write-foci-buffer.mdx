`WriteFociBuffer` is a low-level command that writes a focal point sequence for Foci STM into a bank.

## API

<CodeTabs rust={"WriteFociBuffer {\n    bank,\n    start_index,\n    points,\n};"} python={"WriteFociBuffer(\n    bank=bank,\n    start_index=start_index,\n    points=points,\n)"} csharp={"new WriteFociBuffer(\n    bank: bank,\n    startIndex: startIndex,\n    points: points\n);"} />

| Field          | Type                  | Description                        |
| -------------- | --------------------- | ---------------------------------- |
| `bank`         | `PatternBank`         | Destination bank                   |
| `start_index` | `usize`               | Start index for writing within the bank |
| `points`       | `&[ControlPoints]`    | Sequence of focal point samples    |

`ControlPoints` is one sample holding a sequence of focal points (`ControlPoint`) and an amplitude. Every sample must have the same number of foci.
For details see [FociStm](/autd3-sdk/en/0.13.x/api/command/foci-stm/#controlpoint--controlpoints).

`WriteFociBuffer` writes only what fits in one frame.
The limit (in `ControlPoints`) depends on the number of foci and is given by `WriteFociBuffer::max_len(num_foci)`; exceeding it is an error when sending.

## Example

An example of playing a focal point sequence as Foci STM via `WriteFociBuffer` → `ConfigFociStm` → `ActivatePatternBank` (equivalent to the high-level [FociStm](/autd3-sdk/en/0.13.x/api/command/foci-stm/)). The 200 points do not fit in one frame, so they are written in pieces.
