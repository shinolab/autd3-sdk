`WritePatternBuffer` is a low-level command that writes Patterns (the phase and intensity of each transducer) to consecutive indices of the specified bank, starting at `start_index`.
One frame holds up to `WritePatternBuffer::MAX_LEN` (2) Patterns.
To write more, send them in several commands.

## API

<CodeTabs rust={"WritePatternBuffer::new(bank, start_index, patterns, intensities);"} python={"WritePatternBuffer(\n    bank=bank,\n    start_index=start_index,\n    patterns=patterns,\n    intensities=intensities,\n)"} csharp={"new WritePatternBuffer(\n    bank: bank,\n    startIndex: startIndex,\n    patterns: patterns,\n    intensities: intensities\n);"} />

| Field       | Type                             | Description                        |
| ----------- | -------------------------------- | ---------------------------------- |
| `bank`      | `PatternBank`                    | Destination bank                   |
| `start_index` | `usize`                        | First destination index within the bank |
| `patterns`    | `&[Vec<Vec<Phase>>]`           | Per-device phases of each index    |
| `intensities` | `StmIntensity`                 | Intensity (same as [PatternStm](/autd3-sdk/en/0.13.x/api/command/pattern-stm/)) |

## Example
