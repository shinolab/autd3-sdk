`FociStm` provides an STM feature that switches single- and multi-focus sound fields by a hardware timer.
Unlike [`PatternStm`](/autd3-sdk/en/0.13.x/api/command/pattern-stm/), it can only handle focal points, but the amount of data to transfer is small and the latency is low.

## API

<CodeTabs rust={"FociStm::new(config, &points, option);"} python={"FociStm(config, points, option)"} csharp={"new FociStm(config, points, option);"} />

| Parameter | Type                     | Description                                          |
| --------- | ------------------------ | --------------------------------------------------- |
| `config`  | `SamplingConfig`         | Sampling configuration per sample                     |
| `points`  | `&[ControlPoints]`       | Sequence of focal point samples (at least 2 samples)        |
| `option`  | `FociStmOption`          | Options such as sound speed, loop, and transition   |

`config` is the sampling configuration per sample. To derive it from "the frequency of one full cycle over all samples", multiply that frequency by the number of samples (e.g. 200 samples at 1 Hz is 200 Hz).

## ControlPoint / ControlPoints

A single sample is represented by `ControlPoints`. The length of `points` is the number of focal points emitted simultaneously (1 to 8), and it must be the same for every sample (otherwise sending fails with an error).

* `ControlPoint { point, phase_offset }` — focal point coordinate \[mm] and phase offset.
* `ControlPoints { points: Vec<ControlPoint>, intensity }` — a sequence of focal points and an amplitude.

## FociStmOption

<CodeTabs rust={"FociStmOption {\n    bank,\n    sound_speed,\n    loop_behavior,\n    transition_mode,\n    ..Default::default()\n}"} python={"FociStmOption(\n    bank,\n    sound_speed,\n    loop_behavior,\n    transition_mode,\n)"} csharp={"new FociStmOption\n{\n    Bank = bank,\n    SoundSpeed = soundSpeed,\n    LoopBehavior = loopBehavior,\n    TransitionMode = transitionMode,\n}"} />

| Field             | Type             | Default                     | Description                            |
| ----------------- | ---------------- | --------------------------- | -------------------------------------- |
| `bank`            | `PatternBank`    | `PatternBank::B0`           | Bank to write to / play back           |
| `sound_speed`     | `Velocity`       | `340 m/s`                   | Sound speed used for focus computation |
| `loop_behavior`   | `LoopBehavior`   | `LoopBehavior::Infinite`    | Loop count                             |
| `transition_mode` | `TransitionMode` | `TransitionMode::Immediate` | Transition timing on bank switching    |

For the behavior of `loop_behavior` and `transition_mode`, see [playback control](/autd3-sdk/en/0.13.x/api/command/lowlevel/activate-pattern-bank/).

## Equivalent Low-Level Commands

`FociStm` is equivalent to the three commands [WriteFociBuffer](/autd3-sdk/en/0.13.x/api/command/lowlevel/write-foci-buffer/) + [ConfigFociStm](/autd3-sdk/en/0.13.x/api/command/lowlevel/config-foci-stm/) + [ActivatePatternBank](/autd3-sdk/en/0.13.x/api/command/lowlevel/activate-pattern-bank/).
The following is equivalent to `FociStm::new(config, &points, option)`.
