Composite commands such as `Pattern` / `Modulation` expand internally into the following low-level commands.

| Category      | Pattern family                                                             | Modulation family                                                                |
| ------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Buffer write  | [WritePatternBuffer](/autd3-sdk/en/0.3.x/api/command/lowlevel/write-pattern-buffer/) | [WriteModulationBuffer](/autd3-sdk/en/0.3.x/api/command/lowlevel/write-modulation-buffer/) |
| Bank config   | [ConfigPattern](/autd3-sdk/en/0.3.x/api/command/lowlevel/config-pattern/)           | [ConfigModulation](/autd3-sdk/en/0.3.x/api/command/lowlevel/config-modulation/)           |
| Bank switch   | [ChangePatternBank](/autd3-sdk/en/0.3.x/api/command/lowlevel/change-pattern-bank/)   | [ChangeModulationBank](/autd3-sdk/en/0.3.x/api/command/lowlevel/change-modulation-bank/)   |

This section also includes [WriteFociBuffer](/autd3-sdk/en/0.3.x/api/command/lowlevel/write-foci-buffer/), which writes a focal point sequence for Foci STM, and its configuration [ConfigFociStm](/autd3-sdk/en/0.3.x/api/command/lowlevel/config-foci-stm/).

For writing to the Pattern buffer, there is also [WritePatternCompressed](/autd3-sdk/en/0.3.x/api/command/lowlevel/write-pattern-compressed/), which sends only the phase in compressed form and writes multiple Patterns into a single frame.
The intensity is fixed at maximum, but it is effective when reducing the transmission volume for high-frequency updates.

For the concept of bank switching see the [bank switching tutorial](/autd3-sdk/en/0.3.x/getting-started/tutorial/bank/), and for loops and transitions see the [loop and transition tutorial](/autd3-sdk/en/0.3.x/getting-started/tutorial/loop/).
