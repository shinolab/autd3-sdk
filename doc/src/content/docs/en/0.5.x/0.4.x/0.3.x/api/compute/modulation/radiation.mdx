`radiation_pressure` applies radiation pressure correction to a modulation waveform. It corrects a waveform computed by `sine` or similar.

Acoustic radiation pressure is proportional to the square of the sound pressure.
Since `sine` and similar functions specify the amplitude of the sound pressure, taking the square root of each sample is necessary when the radiation pressure should match the target waveform.
`radiation_pressure` performs this correction.

Each sample <Math tex="m" /> is rewritten by the following equation.

<MathBlock tex="m' = \mathrm{round}\!\left(255 \sqrt{\tfrac{m}{255}}\right)" />

## API

<CodeTabs rust={"radiation_pressure(&src, &mut dst);"} python={"radiation_pressure(src, dst)"} csharp={"Modulation.RadiationPressure(src, dst);"} />

### radiation\_pressure

| Parameter | Type           | Description                    |
| ----- | -------------- | ------------------------------ |
| `src` | `&[u8]`        | modulation waveform before correction |
| `dst` | `&mut Vec<u8>` | buffer to write the corrected waveform |

There is also `radiation_pressure_inplace`, which rewrites in place.
