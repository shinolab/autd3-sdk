`FociStm` provides an STM feature that switches single- and multi-focus sound fields by a hardware timer.
Unlike [`PatternStm`](/autd3-sdk/en/0.5.x/0.4.x/api/command/pattern-stm/), it can only handle focal points, but its data transfer volume is small, so its latency is low.

## API

<CodeTabs rust={"FociStm::new(freq, &points, option);"} python={"FociStm(freq, points, option)"} csharp={"new FociStm(freq, points, option);"} />

| Parameter | Type                     | Description                                          |
| --------- | ------------------------ | --------------------------------------------------- |
| `freq`    | `impl Into<StmConfig>`   | Playback rate (`Freq` / `Duration` / `SamplingConfig`) |
| `points`  | `&[ControlPoints<N>]`    | Sequence of focal point samples (at least 2 samples)        |
| `option`  | `FociStmOption`          | Options such as sound speed, loop, and transition   |

Passing a `Freq` / `Duration` to `freq` represents "the frequency/period for one full cycle over all samples".
A sampling frequency can also be specified.

## ControlPoint / ControlPoints

A single sample is represented by `ControlPoints<N>`. `N` is the number of focal points emitted simultaneously (up to 8).

* `ControlPoint { point, phase_offset }` — focal point coordinate \[mm] and phase offset.
* `ControlPoints<N> { points: [ControlPoint; N], intensity }` — `N` focal points and an amplitude.

## FociStmOption

<CodeTabs rust={"FociStmOption {\n    bank,\n    sound_speed,\n    loop_behavior,\n    transition_mode,\n}"} python={"FociStmOption(\n    bank,\n    sound_speed,\n    loop_behavior,\n    transition_mode,\n)"} csharp={"new FociStmOption(\n    bank,\n    soundSpeed,\n    loopBehavior,\n    transitionMode\n)"} />

| Field             | Type             | Default                     | Description                            |
| ----------------- | ---------------- | --------------------------- | -------------------------------------- |
| `bank`            | `PatternBank`    | `PatternBank::B0`           | Bank to write to / play back           |
| `sound_speed`     | `Velocity`       | `340 m/s`                   | Sound speed used for focus computation |
| `loop_behavior`   | `LoopBehavior`   | `LoopBehavior::Infinite`    | Loop count                             |
| `transition_mode` | `TransitionMode` | `TransitionMode::Immediate` | Transition timing on bank switching    |

For the behavior of `loop_behavior` and `transition_mode`, see [playback control](/autd3-sdk/en/0.5.x/0.4.x/api/command/lowlevel/change-pattern-bank/).

## Helper Functions

Helper functions are provided to generate typical trajectories.

### circle

<CodeTabs rust={"circle(center, radius, num_points, normal, intensity, &mut dst);"} python={"circle(center, radius, num_points, normal, intensity, dst)"} csharp={"Stm.Circle(center, radius, numPoints, normal, intensity, dst);"} />

| Parameter    | Type                         | Description                          |
| ------------ | ---------------------------- | ------------------------------------ |
| `center`     | `Point3<f32>`                | Center of the circle \[mm]            |
| `radius`     | `Length`                     | Radius of the circle                 |
| `num_points` | `usize`                      | Number of points to generate         |
| `normal`     | `UnitVector3<f32>`           | Normal of the circle plane (unit vector) |
| `intensity`  | `Intensity`                  | Amplitude of each point              |
| `dst`        | `&mut Vec<ControlPoints<1>>` | Output buffer                        |

Places `num_points` points at equal intervals on a circle whose normal is `normal`.

### line

<CodeTabs rust={"line(start, end, num_points, intensity, &mut dst);"} python={"line(start, end, num_points, intensity, dst)"} csharp={"Stm.Line(start, end, numPoints, intensity, dst);"} />

| Parameter    | Type                         | Description                  |
| ------------ | ---------------------------- | ---------------------------- |
| `start`      | `Point3<f32>`                | Start point \[mm]             |
| `end`        | `Point3<f32>`                | End point \[mm]               |
| `num_points` | `usize`                      | Number of points to generate |
| `intensity`  | `Intensity`                  | Amplitude of each point      |
| `dst`        | `&mut Vec<ControlPoints<1>>` | Output buffer                |

Places `num_points` points at equal intervals along a line including the start and end points.

## Equivalent Low-Level Commands

`FociStm` is equivalent to the three commands [WriteFociBuffer](/autd3-sdk/en/0.5.x/0.4.x/api/command/lowlevel/write-foci-buffer/) + [ConfigFociStm](/autd3-sdk/en/0.5.x/0.4.x/api/command/lowlevel/config-foci-stm/) + [ChangePatternBank](/autd3-sdk/en/0.5.x/0.4.x/api/command/lowlevel/change-pattern-bank/). When the data fits in a single frame it is fused and sent as one frame; otherwise it expands into the three commands above.
The following is equivalent to `FociStm::new(freq, &points, option)`.

<CodeTabs rust={"WriteFociBuffer {\n    bank: option.bank,\n    index_offset: 0,\n    points: &points,\n};\nConfigFociStm {\n    bank: option.bank,\n    config: StmConfig::new(freq).into_sampling_config(points.len()),\n    size: points.len(),\n    num_foci: N, // N is the number of foci in the points\n    sound_speed: option.sound_speed,\n    loop_behavior: option.loop_behavior,\n};\nChangePatternBank {\n    bank: option.bank,\n    transition_mode: option.transition_mode,\n};"} python={"WriteFociBuffer(\n    bank=option.bank,\n    index_offset=0,\n    points=points,\n)\nConfigFociStm(\n    bank=option.bank,\n    config=StmConfig(freq).into_sampling_config(len(points)),\n    size=len(points),\n    num_foci=num_foci,\n    sound_speed=option.sound_speed,\n    loop_behavior=option.loop_behavior,\n)\nChangePatternBank(\n    bank=option.bank,\n    transition_mode=option.transition_mode,\n)"} csharp={"new WriteFociBuffer(\n    bank: option.Bank,\n    indexOffset: 0,\n    points: points\n);\nnew ConfigFociStm(\n    bank: option.Bank,\n    config: new StmConfig(freq).IntoSamplingConfig(points.Length),\n    size: (uint)points.Length,\n    numFoci: numFoci,\n    soundSpeed: option.SoundSpeed,\n    loopBehavior: option.LoopBehavior\n);\nnew ChangePatternBank(\n    bank: option.Bank,\n    transitionMode: option.TransitionMode\n);"} />
