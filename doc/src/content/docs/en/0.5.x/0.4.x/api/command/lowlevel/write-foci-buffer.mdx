`WriteFociBuffer` is a low-level command that writes a focal point sequence for Foci STM into a bank.

## API

<CodeTabs rust={"WriteFociBuffer {\n    bank,\n    index_offset,\n    points,\n};"} python={"WriteFociBuffer(\n    bank=bank,\n    index_offset=index_offset,\n    points=points,\n)"} csharp={"new WriteFociBuffer(\n    bank: bank,\n    indexOffset: indexOffset,\n    points: points\n);"} />

| Field          | Type                  | Description                        |
| -------------- | --------------------- | ---------------------------------- |
| `bank`         | `PatternBank`         | Destination bank                   |
| `index_offset` | `usize`               | Start index for writing within the bank |
| `points`       | `&[ControlPoints<N>]` | Sequence of focal point samples    |

`ControlPoints<N>` is one sample holding `N` focal points (`ControlPoint`) and an amplitude.
For details see [FociStm](/autd3-sdk/en/0.5.x/0.4.x/api/command/foci-stm/#controlpoint--controlpoints).
