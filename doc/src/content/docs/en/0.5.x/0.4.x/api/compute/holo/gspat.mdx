gspat is an algorithm that speeds up [gs](/autd3-sdk/en/0.5.x/0.4.x/api/compute/holo/gs/).
The algorithm is based on the paper by Plasencia et al. ([Plasencia et al., 2020](https://doi.org/10.1145/3386569.3392492)).

## API

<CodeTabs rust={"gspat(&geometry, &foci, wavelength, &option, &mut dst)?;"} python={"gspat(geometry, foci, wavelength, option, dst)"} csharp={"Holo.Gspat(geometry, foci, wavelength, option, dst);"} />

| Parameter    | Type                   | Description               |
| ------------ | ---------------------- | ------------------------- |
| `geometry`   | `&Geometry`            | Device layout             |
| `foci`       | `&[ControlPoint]`      | Sequence of focal points (position and target amplitude) |
| `wavelength` | `Length`               | Wavelength                |
| `option`     | `&GspatOption`         | Additional options (see below) |
| `dst`        | `&mut [[Emission; _]]` | Output buffer             |

The parameters are the same as [gs](/autd3-sdk/en/0.5.x/0.4.x/api/compute/holo/gs/).

## GspatOption

<CodeTabs rust={"GspatOption {\n    repeat,\n    constraint,\n    directivity,\n    backend,\n    mask,\n}"} python={"GspatOption(\n    repeat,\n    constraint,\n    directivity,\n    backend,\n    mask,\n)"} csharp={"new GspatOption(\n    repeat,\n    constraint,\n    directivity,\n    backend,\n    mask\n)"} />

| Field         | Type                 | Default                   |
|---------------|----------------------|---------------------------|
| `repeat`      | `NonZeroUsize`       | `100`                     |
| `constraint`  | `EmissionConstraint` | `Clamp(MIN, MAX)`         |
| `directivity` | `Directivity`        | `Sphere`                  |
| `backend`     | `impl LinAlgBackend` | `NalgebraBackend`         |
| `mask`        | `TransducerMask`     | `AllEnabled`              |

The options are the same as [gs](/autd3-sdk/en/0.5.x/0.4.x/api/compute/holo/gs/).
