The steps for getting started with AUTD3 are described in the following order.

* [Hardware](/autd3-sdk/en/0.5.x/0.3.x/getting-started/setup/hardware/): Connect the AUTD3 device to the PC.
* [Firmware](/autd3-sdk/en/0.5.x/0.3.x/getting-started/setup/firmware/): Update the device firmware to a compatible version.
* [Software](/autd3-sdk/en/0.5.x/0.3.x/getting-started/setup/software/): Add the SDK library as a dependency.
