`WritePatternCompressed` is the compressed version of [`WritePatternBuffer`](/autd3-sdk/en/0.5.x/0.3.x/api/command/lowlevel/write-pattern-buffer/).
It is a low-level command that writes multiple Patterns into a single frame by sending only the phase information.
The intensity is fixed at the maximum (255).

## API

<CodeTabs rust={"WritePatternCompressed {\n    bank,\n    index,\n    format,\n    patterns,\n};"} python={"WritePatternCompressed(\n    bank=bank,\n    index=index,\n    format=format,\n    patterns=patterns,\n)"} csharp={"new WritePatternCompressed(\n    bank: bank,\n    index: compressedIndex,\n    format: format,\n    patterns: patterns\n);"} />

| Field      | Type                                              | Description                                |
| ---------- | ------------------------------------------------- | ------------------------------------------ |
| `bank`     | `PatternBank`                                     | Destination bank                           |
| `index`    | `usize`                                           | Start index for writing within the bank    |
| `format`   | `PatternCompression`                              | Compression format (see below)             |
| `patterns` | `[Option<&[Vec<Emission>]>; 4]`     | Sequence of Patterns to write              |

## PatternCompression

| Variant     | Patterns per frame | Description                           |
| ----------- | ------------------ | ------------------------------------- |
| `PhaseFull` | 2                  | Sends the phase at full resolution (8 bit) |
| `PhaseHalf` | 4                  | Sends the phase at half resolution (4 bit) |
