`DcSysTime` is a type representing a time on the **EtherCAT distributed clock (Distributed Clock, DC)**.
It is used with [`TransitionMode::SysTime`](/autd3-sdk/en/0.5.x/getting-started/tutorial/loop/), [`GpioOut::SysTimeEq`](/autd3-sdk/en/0.5.x/api/command/gpio/), and the like.

In EtherCAT, there is a clock synchronized across all slaves (the distributed clock), and each device operates in sync with it.
This time is a 64-bit counter in ns units, counted from 2000-01-01 00:00:00 (UTC).

## Construction

`DcSysTime` is constructed from the current time, a UTC datetime, or raw ns.

<CodeTabs rust={"let epoch = DcSysTime::ZERO;\nlet now = DcSysTime::now();\nlet at = DcSysTime::from_utc(Utc.with_ymd_and_hms(2025, 1, 1, 0, 0, 0).unwrap()).unwrap();\nlet raw = DcSysTime::from_nanos(1_000_000_000);\nlet ns: u64 = now.sys_time();\nlet utc = now.to_utc();"} python={"epoch = DcSysTime.ZERO\nnow = DcSysTime.now()\nraw = DcSysTime.from_nanos(1_000_000_000)\nns = now.sys_time"} csharp={"var epoch = DcSysTime.Zero; \nvar now = DcSysTime.Now();\nvar at = DcSysTime.FromUtc(new DateTime(2025, 1, 1, 0, 0, 0, DateTimeKind.Utc));\nvar raw = DcSysTime.FromNanos(1_000_000_000);\nulong ns = now.SysTime;\nDateTime utc = now.ToUtc();"} />

| Operation               | Description                                                    |
| ----------------------- | ------------------------------------------------------------- |
| `ZERO`                  | Epoch (2000-01-01 00:00:00 UTC)                               |
| `now()`                 | Current time of the host                                      |
| `from_nanos(ns)`        | Construct from ns elapsed since the epoch                     |
| `from_utc(utc)`         | Construct from a UTC datetime                                 |
| `sys_time()`            | ns elapsed since the epoch                                    |
| `to_utc()`              | Convert to a UTC datetime                                     |

:::note
The Python version does not have `from_utc` / `to_utc`.
:::

## Arithmetic

`DcSysTime` defines operations that add and subtract time differences.

<CodeTabs rust={"let future = DcSysTime::now() + Duration::from_millis(100);\nlet past = future - Duration::from_millis(50);\nlet elapsed: Duration = future - past;\nlet is_after: bool = future > past; // true"} python={"future = DcSysTime.now() + Duration.from_millis(100)\npast = future - Duration.from_millis(50)"} csharp={"var future = DcSysTime.Now() + TimeSpan.FromMilliseconds(100);\nvar past = future - TimeSpan.FromMilliseconds(50);\nbool isAfter = future > past; // true"} />

| Operation                     | Result       | Description                              |
| ----------------------------- | ------------ | ---------------------------------------- |
| `DcSysTime + Duration`        | `DcSysTime`  | Add the specified duration               |
| `DcSysTime - Duration`        | `DcSysTime`  | Subtract the specified duration          |
| `DcSysTime - DcSysTime`       | `Duration`   | Difference between two times (Rust only) |
| Comparison (`<` / `>` / `==`, etc.) | `bool` | Comparison (Rust / C# only)              |

Rust uses `core::time::Duration` for `Duration`, C# uses `TimeSpan`, and Python uses `autd3.Duration`.
Python provides only addition and subtraction (applying a time difference via `+` / `-`); it does not have computing a time difference or comparison.
