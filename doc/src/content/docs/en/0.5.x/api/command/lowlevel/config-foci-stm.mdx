`ConfigFociStm` is a low-level command that configures the playback parameters of the Foci STM bank.

## API

<CodeTabs rust={"ConfigFociStm {\n    bank,\n    config,\n    size,\n    num_foci,\n    sound_speed,\n    loop_behavior,\n};"} python={"ConfigFociStm(\n    bank=bank,\n    config=config,\n    size=size,\n    num_foci=num_foci,\n    sound_speed=sound_speed,\n    loop_behavior=loop_behavior,\n)"} csharp={"new ConfigFociStm(\n    bank: bank,\n    config: config,\n    size: size,\n    numFoci: numFoci,\n    soundSpeed: soundSpeed,\n    loopBehavior: loopBehavior\n);"} />

| Field           | Type             | Description                                        |
| --------------- | ---------------- | -------------------------------------------------- |
| `bank`          | `PatternBank`    | Target bank                                        |
| `config`        | `SamplingConfig` | Playback sampling frequency                        |
| `size`          | `usize`          | Number of STM samples (at least 2)                 |
| `num_foci`      | `u8`             | Number of focal points per sample (the N of `ControlPoints<N>`) |
| `sound_speed`   | `Velocity`       | Sound speed used for focal point computation       |
| `loop_behavior` | `LoopBehavior`   | Playback loop count (`Infinite` / `Finite`)        |

The minimum `size` is 2.
To emit a single focal point statically, use [Pattern](/autd3-sdk/en/0.5.x/api/command/pattern/) instead of an STM.

For the timing at which `loop_behavior` and the transition take effect see [ChangePatternBank](/autd3-sdk/en/0.5.x/api/command/lowlevel/change-pattern-bank/).
