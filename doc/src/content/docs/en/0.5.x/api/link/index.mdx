`Link` is an abstraction of the physical communication path with AUTD3 devices.

## Link List

* [TwinCAT](/autd3-sdk/en/0.5.x/api/link/twincat/) — Link that uses Beckhoff TwinCAT 3
* [echocat](/autd3-sdk/en/0.5.x/api/link/echocat/) — EtherCAT Link dedicated to AUTD3
* [EtherCrab](/autd3-sdk/en/0.5.x/api/link/ethercrab/) — Link based on EtherCrab
* [SOEM](/autd3-sdk/en/0.5.x/api/link/soem/) — Link based on SOEM ([GPL-3.0-only](/autd3-sdk/en/0.5.x/misc/license/))
* [Remote](/autd3-sdk/en/0.5.x/api/link/remote/) — Link for remote connections

## Usage

A Link is constructed by passing a Link Option to `Client::open`. The Option specifies the connection target, synchronization parameters, and so on.

The send/receive interface seen from the `Client` is common across Link implementations.
Therefore, swapping the link does not require changing the higher-level code.
