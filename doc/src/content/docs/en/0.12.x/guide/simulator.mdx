`Simulator` is a sound field simulator that visualizes the AUTD3 output sound field in a browser.
Even without real hardware, you can check the sound field generated from the data sent by the client.

## Launching

`Simulator` is bundled with the GUI console `autd3-console`.

Obtain `autd3-console` as described in [Console](/autd3-sdk/en/0.12.x/guide/console/), launch it, and open the "Simulator" tab at the top.

## Connecting

The client must run on the same host as the Simulator.

The Simulator listens on port 44336 by default (and on the next port, 44337, for control). Change the port with "UDP port" in the Simulator tab of the console.

The default [`UdpOption`](/autd3-sdk/en/0.12.x/api/basics/transport-option/) (`iface` set to `Auto`) connects to the Simulator on the default port when no real devices are attached.
If both the Simulator and real devices are found, opening fails; set `iface` to `Simulator(..)` with the Simulator's port, or specify the NIC of the real devices with `Name(..)`.
