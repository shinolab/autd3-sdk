`hermite_gaussian_phase` generates a Hermite-Gaussian (HG) beam <Math tex="\mathrm{HG}_{mn}" />.

<PatternField kind="hermite-gaussian" />

As with `laguerre_gaussian_phase`, the amplitude is changed with `hermite_gaussian_intensity`.

## API

<CodeTabs rust={"let option = HermiteGaussianOption {\n    m: 1,\n    n: 0,\n    waist: 10.0 * mm,\n};\nhermite_gaussian_phase(&geometry, target, axis, x_dir, option, wavelength, &mut phases);\nhermite_gaussian_intensity(&geometry, target, axis, x_dir, option, wavelength, &mut intensities);"} python={"option = HermiteGaussianOption(m=1, n=0, waist=10.0 * mm)\nhermite_gaussian_phase(geometry, target, axis, x_dir, option, wavelength, phases)\nhermite_gaussian_intensity(geometry, target, axis, x_dir, option, wavelength, intensities)"} csharp={"var option = new HermiteGaussianOption(m: 1, n: 0, waist: 10.0f * mm);\nPattern.HermiteGaussianPhase(geometry, target, axis, xDir, option, wavelength, phases);\nPattern.HermiteGaussianIntensity(geometry, target, axis, xDir, option, wavelength, intensities);"} />

| Parameter    | Type                    | Description                                   |
| ------------ | ----------------------- | --------------------------------------------- |
| `geometry`   | `&Geometry`             | Device layout                                 |
| `target`     | `Point3<f32>`           | Center of the beam waist \[mm]                 |
| `axis`       | `UnitVector3<f32>`      | Propagation direction (unit vector)           |
| `x_dir`      | `UnitVector3<f32>`      | Direction along which the `m` nodes line up   |
| `option`     | `HermiteGaussianOption` | Mode and waist                                |
| `wavelength` | `Length`                | Wavelength                                    |
| `dst`        | `&mut [Vec<Phase>]` / `&mut [Vec<Intensity>]` | Output buffer (phases for `*_phase`, intensities for `*_intensity`) |

| Field   | Type     | Description                                             |
| ------- | -------- | ------------------------------------------------------- |
| `m`     | `u32`    | Mode index along `x_dir`                                |
| `n`     | `u32`    | Mode index along the orthogonal direction               |
| `waist` | `Length` | Beam waist radius <Math tex="w_0" /> (positive) |

`waist` must be a positive finite length. Otherwise Rust panics when computing, Python raises `ValueError`, and C# throws `Autd3Exception` (`InvalidArgument`).
