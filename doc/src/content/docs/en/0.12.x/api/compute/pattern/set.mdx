These functions rewrite a whole phase buffer or intensity buffer at once.
Pattern functions such as `focus` write only to the phase buffer, so set the intensity with `set_intensity`.

Buffers allocated with `phase_buffer` / `intensity_buffer` start at phase 0 and the maximum intensity.
Note that, in C#, the elements of `new Intensity[n]` start at intensity 0.

## set\_intensity

Sets the intensity of every transducer in an intensity buffer.
Passing `Intensity::MIN` produces no output.

<CodeTabs rust={"set_intensity(intensity, &mut intensities);"} python={"set_intensity(intensity, intensities)"} csharp={"Pattern.SetIntensity(intensity, intensities);"} />

## set\_phase

Sets the phase of every transducer in a phase buffer.

<CodeTabs rust={"set_phase(phase, &mut phases);"} python={"set_phase(phase, phases)"} csharp={"Pattern.SetPhase(phase, phases);"} />

## add\_phase

Adds a phase uniformly to every transducer in a phase buffer (wrapping at 8 bits).

<CodeTabs rust={"add_phase(phase, &mut phases);"} python={"add_phase(phase, phases)"} csharp={"Pattern.AddPhase(phase, phases);"} />

| Parameter   | Type                   | Description   |
| ----------- | ---------------------- | ------------- |
| `intensity` | `Intensity`            | Intensity     |
| `phase`     | `Phase`                | Phase         |
| `dst`       | `&mut [Vec<Intensity>]` / `&mut [Vec<Phase>]` | Target buffer (intensities for `set_intensity`, phases for `set_phase` / `add_phase`) |
