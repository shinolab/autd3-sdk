Modulation is an amplitude modulation (AM) feature that modulates the output amplitude of each transducer over time.
It applies a coefficient sequence common to all transducers while sampling it at a fixed period, thereby varying the intensity of the sound field produced by the Pattern over time.

<Install rust="autd3-rs-modulation" python="autd3-modulation" csharp="AUTD3.Modulation" />

Each sample is an 8 bit amplitude coefficient <Math tex="0 \le m \le 255" />, which is multiplied by the transducer output amplitude and then divided by 255.

## SamplingConfig

Each sample in the buffer is applied in order at the period of the `SamplingConfig` passed to `Modulation::new`.
The `sampling_config` held by the Option of a waveform computation function determines the length of the waveform (number of samples), and it must match the `SamplingConfig` passed to `Modulation::new`.
For example, with `SamplingConfig::FREQ_4K` (4 kHz, sampling period 250 µs), one period of a 200 Hz sine wave is 20 samples.

## samples\_per\_period

`samples_per_period(divider, freq)` returns how many samples one period of a waveform of frequency `freq` takes at the sampling with division ratio `divider`.
It returns `None` when the sampling frequency is not divisible by `freq` (one period cannot be represented by an integer number of samples) or when `freq` is 0.
For example, it returns 20 for 200 Hz at division ratio 10 (4 kHz).

| Parameter | Type         | Description                    |
| --------- | ------------ | ------------------------------ |
| `divider` | `NonZeroU16` | Division ratio of the sampling |
| `freq`    | `Freq<u32>`  | Frequency of the waveform (integer frequencies only) |

The return value is `Option<u32>`.
Python takes `divider` as an `int` and returns `None` for `0`. Passing a floating-point frequency such as `200.0 * Hz` raises `ValueError`.
C# provides `Modulation.SamplesPerPeriod(ushort divider, Freq freq)`, which returns `uint?` and throws `Autd3Exception` (`InvalidArgument`) for a floating-point frequency.
