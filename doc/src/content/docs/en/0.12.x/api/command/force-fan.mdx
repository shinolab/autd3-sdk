`ForceFan` is a command that forcibly turns the cooling fan on.

:::caution
It cannot be forcibly turned off.
:::

## API

<CodeTabs rust={"ForceFan { value };"} python={"ForceFan(value)"} csharp={"new ForceFan(value);"} />

| Field   | Type   | Default | Description                  |
| ------- | ------ | ------- | ---------------------------- |
| `value` | `bool` | `false` | Force the fan on when `true` |
