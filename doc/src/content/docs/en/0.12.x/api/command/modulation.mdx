`Modulation` is a command that sends AM waveform data (`&[u8]`) to the device.

## API

<CodeTabs>
  <Fragment slot="rust">
    <Code code={"Modulation::new(config, &data);\n\nModulation::with_bank(bank, config, &data);\n\nModulation {\n    bank,\n    config,\n    data: &data,\n    loop_behavior,\n    transition_mode,\n};"} lang="rust" />

    `Modulation::new` sets the destination bank to `ModulationBank::B0`, the loop to `Infinite`, and the transition to `Immediate`.
    To write to another bank, use `Modulation::with_bank(bank, config, data)`.
    To also change the loop count or transition timing, construct it by specifying the fields directly.
  </Fragment>

  <Fragment slot="python">
    <Code code={"Modulation(config, data)\n\nModulation(config, data, bank=bank)\n\nModulation(\n    bank=bank,\n    config=config,\n    data=data,\n    loop_behavior=loop_behavior,\n    transition_mode=transition_mode,\n)"} lang="python" />

    `Modulation` sets the destination bank to `ModulationBank.B0`, the loop to `Infinite`, and the transition to `Immediate` by default.
    To write to another bank, use `Modulation(config, data, bank=bank)`.
    To also change the loop count or transition timing, pass the `loop_behavior` / `transition_mode` arguments.
  </Fragment>

  <Fragment slot="csharp">
    <Code code={"new Modulation(config, data);\n\nnew Modulation(bank, config, data);\n\nnew Modulation(\n    bank: bank,\n    config: config,\n    data: data,\n    loopBehavior: loopBehavior,\n    transitionMode: transitionMode\n);"} lang="csharp" />

    `new Modulation(config, data)` sets the destination bank to `ModulationBank.B0`, the loop to `Infinite`, and the transition to `Immediate`.
    To write to another bank, use `new Modulation(bank, config, data)`.
    To also change the loop count or transition timing, pass the `loopBehavior` / `transitionMode` arguments.
  </Fragment>
</CodeTabs>

| Field             | Type             | Default                     | Description                  |
| ----------------- | ---------------- | --------------------------- | ---------------------------- |
| `bank`            | `ModulationBank` | `ModulationBank::B0`        | Bank to write to / play back |
| `config`          | `SamplingConfig` | —                           | Playback sampling frequency  |
| `data`            | `&[u8]`          | —                           | AM waveform sample sequence (at least 2 samples) |
| `loop_behavior`   | `LoopBehavior`   | `LoopBehavior::Infinite`    | Playback loop count          |
| `transition_mode` | `TransitionMode` | `TransitionMode::Immediate` | Transition behavior on bank switching |

`config` is specified with [`SamplingConfig`](/autd3-sdk/en/0.12.x/api/basics/sampling-config/).
`data` is written to a buffer allocated by `modulation_buffer()`.
For the behavior of `loop_behavior` / `transition_mode`, see [ActivateModulationBank](/autd3-sdk/en/0.12.x/api/command/lowlevel/activate-modulation-bank/).

Several [helper functions](/autd3-sdk/en/0.12.x/api/compute/modulation/) are provided for computing modulation.

## Equivalent Low-Level Commands

`Modulation` is equivalent to the three commands [WriteModulationBuffer](/autd3-sdk/en/0.12.x/api/command/lowlevel/write-modulation-buffer/) + [ConfigModulation](/autd3-sdk/en/0.12.x/api/command/lowlevel/config-modulation/) + [ActivateModulationBank](/autd3-sdk/en/0.12.x/api/command/lowlevel/activate-modulation-bank/), and is sent expanded in that order.
The following is equivalent to `Modulation { bank, config, data, loop_behavior, transition_mode }`
