`vortex` generates an acoustic vortex. See ([Marzo et al., 2015](https://doi.org/10.1038/ncomms9661)) for details.

<PatternField kind="vortex" />

The phase is the focal phase <Math tex="\phi_i" /> plus the azimuth scaled by the topological charge <Math tex="m" />.

<MathBlock tex="\phi_i^\mathrm{vortex} = \phi_i + m \theta_i, \quad \theta_i = \mathrm{atan2}((\bp_i - \boldsymbol{t}) \cdot \bv, (\bp_i - \boldsymbol{t}) \cdot \bu)" />

<Math tex="m = 0" /> is equivalent to `focus`.

## API

<CodeTabs rust={"vortex(\n    &geometry, target, axis, order, wavelength, &option, &mut dst,\n);"} python={"vortex(geometry, target, axis, order, wavelength, option, dst)"} csharp={"Pattern.Vortex(geometry, target, axis, order, wavelength, option, dst);"} />

| Parameter    | Type                   | Description                                       |
| ------------ | ---------------------- | ------------------------------------------------- |
| `geometry`   | `&Geometry`            | Device layout                                     |
| `target`     | `Point3<f32>`          | Coordinates of the vortex core \[mm]               |
| `axis`       | `UnitVector3<f32>`     | Axis of the vortex through `target` (unit vector) |
| `order`      | `i32`                  | Topological charge (negative reverses the swirl)  |
| `wavelength` | `Length`               | Wavelength                                        |
| `option`     | `&VortexOption`        | Additional options (see below)                    |
| `dst`        | `&mut [[Emission; _]]` | Output buffer                                     |

## VortexOption

<CodeTabs rust={"VortexOption {\n    intensity,\n    phase_offset,\n    ..Default::default()\n}"} python={"VortexOption(\n    intensity,\n    phase_offset,\n)"} csharp={"new VortexOption(\n    intensity,\n    phaseOffset\n)"} />

| Field          | Type        | Default          | Description                              |
| -------------- | ----------- | ---------------- | ---------------------------------------- |
| `intensity`    | `Intensity` | `Intensity::MAX` | Amplitude of all transducers             |
| `phase_offset` | `Phase`     | `Phase::ZERO`    | Phase added uniformly to all transducers |
