`twin_trap` generates a twin trap for acoustic levitation. See ([Marzo et al., 2015](https://doi.org/10.1038/ncomms9661)) for details.

<PatternField kind="twin-trap" />

The phase is the same focal phase <Math tex="\phi_i" /> as `focus`, plus a term decided by which
side of the plane through target <Math tex="\boldsymbol{t}" /> with normal <Math tex="\boldsymbol{n}" /> the transducer position <Math tex="\bp_i" /> sits on.

<MathBlock tex="\phi_i^\mathrm{twin} = \phi_i + \begin{cases} \pi & ((\bp_i - \boldsymbol{t}) \cdot \boldsymbol{n} \geq 0) \\ 0 & (\text{otherwise}) \end{cases}" />

## API

<CodeTabs rust={"twin_trap(&geometry, target, normal, wavelength, &option, &mut dst);"} python={"twin_trap(geometry, target, normal, wavelength, option, dst)"} csharp={"Pattern.TwinTrap(geometry, target, normal, wavelength, option, dst);"} />

| Parameter    | Type                   | Description                                                  |
| ------------ | ---------------------- | ------------------------------------------------------------ |
| `geometry`   | `&Geometry`            | Device layout                                                |
| `target`     | `Point3<f32>`          | Coordinates of the trap \[mm]                                 |
| `normal`     | `UnitVector3<f32>`     | Normal of the splitting plane through `target` (unit vector) |
| `wavelength` | `Length`               | Wavelength                                                   |
| `option`     | `&TwinTrapOption`      | Additional options (see below)                               |
| `dst`        | `&mut [[Emission; _]]` | Output buffer                                                |

## TwinTrapOption

<CodeTabs rust={"TwinTrapOption {\n    intensity,\n    phase_offset,\n    ..Default::default()\n}"} python={"TwinTrapOption(\n    intensity,\n    phase_offset,\n)"} csharp={"new TwinTrapOption(\n    intensity,\n    phaseOffset\n)"} />

| Field          | Type        | Default          | Description                              |
| -------------- | ----------- | ---------------- | ---------------------------------------- |
| `intensity`    | `Intensity` | `Intensity::MAX` | Amplitude of all transducers             |
| `phase_offset` | `Phase`     | `Phase::ZERO`    | Phase added uniformly to all transducers |
