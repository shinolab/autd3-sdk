`SetPhaseCorrection` is a command that sets the phase offset added to each transducer.
The offset set here is added to all subsequent output phases.

## API

<CodeTabs rust={"SetPhaseCorrection { phases };"} python={"SetPhaseCorrection(phases)"} csharp={"new SetPhaseCorrection(phases);"} />

| Field    | Type            | Description                                    |
| -------- | --------------- | --------------------------------------------- |
| `phases` | `Vec<Vec<Phase>>` | Phase offset table per device. |
