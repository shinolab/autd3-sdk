`Synchronize` is a command that reinitializes the synchronization clock the FPGA uses to generate PWM and aligns the output phase across the devices.
It must be called once after `open`.

## API

<CodeTabs rust={"Synchronize;"} python={"Synchronize()"} csharp={"new Synchronize();"} />
