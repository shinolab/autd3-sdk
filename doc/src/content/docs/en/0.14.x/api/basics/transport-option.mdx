## API

<CodeTabs rust={"TransportOption {\n    iface,\n    send_buffer_bytes,\n    sync_on_open,\n    heartbeat_interval,\n    ..Default::default()\n};"} python={"TransportOption(\n    iface=iface,\n    send_buffer_bytes=send_buffer_bytes,\n    sync_on_open=sync_on_open,\n    heartbeat_interval=heartbeat_interval,\n)"} csharp={"new TransportOption\n{\n    Iface = iface,\n    SendBufferBytes = sendBufferBytes,\n    SyncOnOpen = syncOnOpen,\n    HeartbeatInterval = heartbeatInterval,\n};"} />

| Field                 | Type                   | Default | Description                                                                                   |
| --------------------- | ---------------------- | ------- | --------------------------------------------------------------------------------------------- |
| `iface`               | `Interface`            | `Auto`  | Destination                                                                                   |
| `send_buffer_bytes`         | `Option<NonZeroUsize>` | 8192    | Size of the socket send buffer \[B]. `None` leaves the OS default                              |
| `sync_on_open`        | `bool`                 | `true`  | When `false`, open does not wait for the devices to synchronize with one another |
| `heartbeat_interval`  | `Option<Duration>`     | `None`  | When set, keep sending liveness checks at this interval (see [Failsafe](/autd3-sdk/en/0.14.x/guide/failsafe/#communication-loss-failsafe-and-liveness-check)) |

Changing anything other than `iface` and `heartbeat_interval` is generally not recommended.

## Interface

<CodeTabs rust={"Interface::Auto;\nInterface::Name(\"eth0\".to_string());\nInterface::Addr(\"[::1]:44336\".parse()?);"} python={"Interface.Auto\nInterface.Name(\"eth0\")\nInterface.Addr(\"[::1]:44336\")"} csharp={"_ = Interface.Auto;\n_ = Interface.Name(\"eth0\");\n_ = Interface.Addr(\"[::1]:44336\");"} />

| Value       | Destination                                                                                             |
| ----------- | ------------------------------------------------------------------------------------------------------- |
| `Auto`      | The first network interface on which devices reply                                                      |
| `Name(..)`  | The real devices connected to the network interface with the given name                                 |
| `Addr(..)`  | The given IPv6 address and port. Connect to the [Simulator](/autd3-sdk/en/0.14.x/guide/simulator/) with `[::1]:44336` |
