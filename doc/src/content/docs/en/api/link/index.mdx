`Link` is an abstraction of the physical communication path with AUTD3 devices.

## Link List

- [TwinCAT](/autd3-sdk/en/api/link/twincat/) — Link that uses Beckhoff TwinCAT 3 on Windows as the EtherCAT master
- [echocat](/autd3-sdk/en/api/link/echocat/) — EtherCAT Link dedicated to AUTD3. The host itself becomes the EtherCAT master
- [Remote](/autd3-sdk/en/api/link/remote/) — Link that connects over TCP to another host. Used to reach the [Appliance](/autd3-sdk/en/getting-started/appliance/) and the [Simulator](/autd3-sdk/en/guide/simulator/)

## Usage

A Link is constructed by passing a Link Option to `Client::open`. The Option specifies the connection target, synchronization parameters, and so on.

The send/receive interface seen from the `Client` is common across Link implementations.
Therefore, swapping the link does not require changing the higher-level code.
