`TwinCATLink` is a Link implementation that uses [TwinCAT](https://www.beckhoff.com/) on Windows as the EtherCAT master.

<Install rust="autd3-rs-link-twincat" python="autd3-link-twincat" csharp="AUTD3.Link.TwinCAT" />

Use it in a Windows environment where TwinCAT is already set up.
For the TwinCAT setup procedure, see [Installing TwinCAT](/autd3-sdk/en/getting-started/twincat/).

There are two configurations: one that connects to a local TwinCAT, and one that connects to a remote TwinCAT server via ADS.

## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| Parameter    | Type       | Description                                |
| ------------ | ---------- | ------------------------------------------ |
| `addr`       | `IpAddr`   | IP address of the remote TwinCAT server    |
| `ams_net_id` | `AmsNetId` | AMS Net ID of the remote TwinCAT server    |

To specify timeouts, use `*_with_timeouts`.
The default is no timeout.
