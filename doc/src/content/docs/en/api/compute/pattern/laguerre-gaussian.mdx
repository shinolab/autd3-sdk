`laguerre_gaussian_phase` generates a Laguerre-Gaussian (LG) beam <Math tex="\mathrm{LG}_p^l" />.

<PatternField kind="laguerre-gaussian" />

Besides `laguerre_gaussian_phase`, which writes only the phase, there is `laguerre_gaussian_intensity`, which writes only the amplitude.

## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| Parameter    | Type                     | Description                            |
| ------------ | ------------------------ | -------------------------------------- |
| `geometry`   | `&Geometry`              | Device layout                          |
| `target`     | `Point3<f32>`            | Center of the beam waist [mm]          |
| `axis`       | `UnitVector3<f32>`       | Propagation direction (unit vector)    |
| `option`     | `LaguerreGaussianOption` | Mode and waist                         |
| `wavelength` | `Length`                 | Wavelength                             |
| `dst`        | `&mut [[Emission; _]]`   | Output buffer                          |

| Field   | Type     | Description                                             |
| ------- | -------- | ------------------------------------------------------- |
| `p`     | `u32`    | Radial mode index                                       |
| `l`     | `i32`    | Azimuthal mode index                                    |
| `waist` | `Length` | Beam waist radius <Math tex="w_0" /> (positive) |
