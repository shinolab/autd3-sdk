These functions rewrite the intensity and phase of a whole pattern buffer at once.
Pattern functions such as `focus` write only the phase, so set the intensity with these functions.

A buffer allocated with `pattern_buffer` starts at phase 0 and the maximum intensity.
Note that, in C#, the elements of `new Emission[n]` start at intensity 0.

## set_intensity

Sets the intensity of every transducer. The phase is left unchanged.
Passing `Intensity::MIN` produces no output.
