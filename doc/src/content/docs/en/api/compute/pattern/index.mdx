Representative sound field computation utilities such as a single focal point, a plane wave, a Bessel beam, and the trapping fields used for acoustic levitation.

<Install rust="autd3-rs-pattern" python="autd3-pattern" csharp="AUTD3.Pattern" />

## Function List

- [focus](/autd3-sdk/en/api/compute/pattern/focus/) — single focal point
- [plane](/autd3-sdk/en/api/compute/pattern/plane/) — plane wave
- [bessel](/autd3-sdk/en/api/compute/pattern/bessel/) — Bessel beam
- [twin_trap](/autd3-sdk/en/api/compute/pattern/twin-trap/) — twin trap
- [vortex](/autd3-sdk/en/api/compute/pattern/vortex/) — acoustic vortex
- [set_intensity / set_phase / add_phase](/autd3-sdk/en/api/compute/pattern/set/) — set the intensity and phase of a whole buffer
- [group](/autd3-sdk/en/api/compute/pattern/group/) — select a pattern per transducer

`focus` / `plane` / `bessel` / `twin_trap` / `vortex` also have a `*_device` variant that computes for only a single device, and a `*_transducer` variant that returns the phase of a single transducer element (for example, `focus_device` / `focus_transducer`).
`set_intensity` / `set_phase` / `set_phase_and_intensity` / `add_phase` have a `*_device` variant but no `*_transducer` variant.
These variants are available in Rust and C#, but not in Python.

Pattern functions write only the phase and leave the intensity untouched.
A buffer allocated with `pattern_buffer` starts at phase 0 and the maximum intensity; use `set_intensity` to change the intensity.

## Wavelength

The phase computation requires the wavelength <Math tex="\lambda = c / f" />.
The wavelength can be obtained from the sound speed <Math tex="c" /> via `autd3_rs_pattern::wavelength(sound_speed)`.
At a sound speed of 340 m/s (the speed of sound in air at a room temperature of about 15°C), <Math tex="\lambda = 8.5\,\mathrm{mm}" />.
