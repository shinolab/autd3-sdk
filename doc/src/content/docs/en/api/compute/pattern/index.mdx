Representative sound field computation utilities such as a single focal point, a plane wave, a Bessel beam, a Laguerre-Gaussian beam (acoustic vortex), and a Hermite-Gaussian beam (the trapping field used for acoustic levitation).

<Install rust="autd3-rs-pattern" python="autd3-pattern" csharp="AUTD3.Pattern" />

## Function List

- [focus](/autd3-sdk/en/api/compute/pattern/focus/) — single focal point
- [plane](/autd3-sdk/en/api/compute/pattern/plane/) — plane wave
- [bessel](/autd3-sdk/en/api/compute/pattern/bessel/) — Bessel beam
- [laguerre_gaussian_phase / laguerre_gaussian_intensity](/autd3-sdk/en/api/compute/pattern/laguerre-gaussian/) — phase and intensity of a Laguerre-Gaussian beam
- [hermite_gaussian_phase / hermite_gaussian_intensity](/autd3-sdk/en/api/compute/pattern/hermite-gaussian/) — phase and intensity of a Hermite-Gaussian beam
- [set_intensity / set_phase / add_phase](/autd3-sdk/en/api/compute/pattern/set/) — set the intensity and phase of a whole buffer
- [group / group_compute](/autd3-sdk/en/api/compute/pattern/group/) — select a pattern per transducer

`focus` / `plane` / `bessel` / `laguerre_gaussian_phase` / `hermite_gaussian_phase` also have a `*_device` variant that computes for only a single device, and a `*_transducer` variant that returns the phase of a single transducer element (for example, `focus_device` / `focus_transducer`).
`laguerre_gaussian_intensity` / `hermite_gaussian_intensity` have only a `*_device` variant (there is no per-transducer variant, because normalizing the intensity needs the surrounding transducers).
`group` also has `group_device` for a single device.

For a Geometry-level function, if the number of devices of `dst` does not match `geometry`, Rust panics, Python raises `ValueError`, and C# throws `Autd3Exception` (`InvalidArgument`).

The `dst` of a `*_device` variant is a buffer for one device: `&mut [Phase]` / `&mut [Intensity]` in Rust, a `uint8` numpy array whose length is the number of transducers of that device in Python, and a `Phase[]` / `Intensity[]` of length `NumTransducers` in C#.

## Wavelength

The phase computation requires the wavelength <Math tex="\lambda = c / f" />.
The wavelength can be obtained from the sound speed <Math tex="c" /> via `autd3_rs_pattern::wavelength(sound_speed)` (Python: `autd3_pattern.wavelength`, C#: `Pattern.Wavelength`).
At a sound speed of 340 m/s (the speed of sound in air at a room temperature of about 15°C), <Math tex="\lambda = 8.5\,\mathrm{mm}" />.
