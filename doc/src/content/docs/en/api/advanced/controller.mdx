`Controller` / `Driver` are provided in Rust only.
:::

`Controller` and `Driver` are the parts that let you drive the internals of [`Client`](/autd3-sdk/en/api/basics/client/) yourself.

`Client` owns one I/O thread that receives the replies.
Use `Controller` / `Driver` when you want to run the send/receive loop on your own thread or the like instead of that thread.

## Open

`Controller::open` returns a tuple of `Controller` and `Driver`.
It takes the same arguments as `Client::open`.

## Driver

`Driver` has the following methods.

| Method            | Return value                     | Description                                                              |
| ----------------- | -------------------------------- | ------------------------------------------------------------------------ |
| `run(self)`       | `Result<(), Error>`              | Repeats `poll` and `wait` until the `Controller` is closed. Blocking.    |
| `poll(&mut self)` | `Result<Option<Instant>, Error>` | Processes the replies that have arrived and the work that is due, and returns the deadline for the next call. Non-blocking. |
| `wait(&mut self, deadline)` | `Result<(), Error>`    | Blocks the thread until a reply arrives or `deadline` is reached         |

### poll / wait

`run` is the same as the following loop.
Call `poll` and `wait` directly when you want to put your own work inside the loop.

<CodeTabs rust={excerpt(sample, "poll")} />

The return value of `poll` means the following.

- `Ok(Some(deadline))`: the deadline by which `poll` should be called next
- `Ok(None)`: the `Controller` has been closed (`close` or drop)
- `Err(..)`: a communication error

- Waiting for the socket send buffer to drain
