When multiple devices are passed to `Geometry::new`, device numbers (`idx`) are assigned in order from the first.

## API

Provides retrieval of information about the whole layout and access to each `Device`.

<CodeTabs rust={excerpt(sample, "access")} python={excerpt(pySample, "access")} csharp={excerpt(csSample, "access")} />

| Method                 | Returns                      | Description                          |
| ---------------------- | ---------------------------- | ------------------------------------ |
| `num_devices()`        | `usize`                      | Number of devices                    |
| `num_transducers()`    | `usize`                      | Total number of transducers across all devices |
| `center()`             | `Point3<f32>`                | Center coordinate of the whole array |
| `phase_buffer()`       | `Vec<Vec<Phase>>`            | Allocate a phase buffer for Pattern computation (starts at 0) |
| `intensity_buffer()`   | `Vec<Vec<Intensity>>`        | Allocate an intensity buffer for Pattern computation (starts at the maximum) |
| `output_mask_buffer()` | `Vec<Vec<bool>>`             | Allocate an output mask buffer for `SetOutputMask` (starts at `true`) |
| `iter()` / `&geometry` | `Iterator<Item = &Device>`   | Iterate over each `Device`           |
| `geometry[i]`          | `&Device`                    | Get the `i`-th `Device`              |
| `to_json()`            | `Result<String, LayoutError>` | Convert the layout to a JSON string  |
| `from_json(&str)`      | `Result<Geometry, LayoutError>` | Construct `Geometry` from a JSON string   |

## Device

Represents a single device.
It is obtained via `geometry[i]` or by iterating over `&geometry`.
The position of each transducer and the device's rotation can be retrieved. All transducers of a device share one normal direction, returned by `axial_direction()`.

<CodeTabs rust={excerpt(sample, "device")} python={excerpt(pySample, "device")} csharp={excerpt(csSample, "device")} />

| Method               | Returns                 | Description                                   |
| -------------------- | ----------------------- | --------------------------------------------- |
| `idx()`              | `usize`                 | Device number within the `Geometry`           |
| `num_transducers()`  | `usize`                 | Number of transducers                         |
| `center()`           | `Point3<f32>`           | Device center coordinate                      |
| `rotation()`         | `UnitQuaternion<f32>`   | Device rotation                               |
| `x_direction()`      | `UnitVector3<f32>`      | Local x-axis direction                        |
| `y_direction()`      | `UnitVector3<f32>`      | Local y-axis direction                        |
| `axial_direction()`  | `UnitVector3<f32>`      | Axial direction (ultrasound emission direction) |
| `positions()`        | `&[Point3<f32>]`        | Positions of all transducers                  |
| `position(i)`        | `Point3<f32>`           | Position of the `i`-th transducer             |

## Coordinate Helpers

There are helpers to build coordinates.
The argument type is `Length`, so a unit can be specified, as in `150 * mm` (see [Units and Value Types](/autd3-sdk/en/api/basics/units/)).

| Function            | Returns (Rust)  | Description                                  |
| ------------------- | --------------- | -------------------------------------------- |
| `point(x, y, z)`    | `Point3<f32>`   | An absolute-coordinate point                 |
| `offset(x, y, z)`   | `Vector3<f32>`  | A relative displacement vector               |
