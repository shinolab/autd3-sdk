## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| Field                 | Type                   | Default | Description                                                                                   |
| --------------------- | ---------------------- | ------- | --------------------------------------------------------------------------------------------- |
| `iface`               | `Interface`            | `Auto`  | Destination                                                                                   |
| `open_timeout`        | `Duration`             | 40 s    | Upper bound on the time the open waits |
| `send_buffer_bytes`         | `Option<NonZeroUsize>` | 8192    | Size of the socket send buffer [B]. `None` leaves the OS default                              |
| `sync_on_open`        | `bool`                 | `true`  | When `false`, open does not wait for the devices to synchronize with one another |

Changing anything other than `iface` is generally not recommended.
`Client` neither bounds the wait for replies, judges a device lost, nor sends liveness checks: the user does (see [Client](/autd3-sdk/en/api/basics/client/#api) / [Failsafe](/autd3-sdk/en/guide/failsafe/#communication-loss-failsafe-and-liveness-check)).

:::caution[Windows timer resolution]
The library does not change the timer resolution of Windows (`timeBeginPeriod`).
At the default timer resolution in Windows (typically 15.6 ms), the bound you put on waiting for the replies and the interval of your liveness checks may be rounded to that granularity.
If needed, call `timeBeginPeriod(1)` in your process yourself.
:::

## Interface

<CodeTabs rust={excerpt(sample, "iface")} python={excerpt(pySample, "iface")} csharp={excerpt(csSample, "iface")} />

| Value       | Destination                                                                                             |
| ----------- | ------------------------------------------------------------------------------------------------------- |
| `Auto`      | The first network interface on which devices reply                                                      |
| `Name(..)`  | The real devices connected to the network interface with the given name                                 |
| `Addr(..)`  | The given IPv6 address and port. Connect to the [Simulator](/autd3-sdk/en/guide/simulator/) with `[::1]:44336` |
