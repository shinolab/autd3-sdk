`SetPhaseCorrection` is a command that sets the phase offset added to each transducer.
The offset set here is added to all subsequent output phases.

## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| Field    | Type            | Description                                    |
| -------- | --------------- | --------------------------------------------- |
| `phases` | `&[Vec<Phase>]` | Phase offset table per device. |
