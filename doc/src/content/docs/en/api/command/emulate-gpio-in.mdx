`EmulateGpioIn` is a command that asserts the four [GPIO input terminals](/autd3-sdk/en/hardware/gpio/) of the devices from software.
The effective value the FPGA sees is the logical OR of the physical terminal input and `EmulateGpioIn`.

## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| Field    | Type        | Default         | Description                                            |
| -------- | ----------- | --------------- | ------------------------------------------------------ |
| `values` | `[bool; 4]` | all `false`     | Whether to assert each of inputs 0..3 (`true` asserts) |
