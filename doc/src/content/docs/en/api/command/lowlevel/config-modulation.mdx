`ConfigModulation` is a low-level command that configures the playback parameters of the Modulation bank.
The settings are only written; they take effect on playback when [ActivateModulationBank](/autd3-sdk/en/api/command/lowlevel/activate-modulation-bank/) is sent.
To change the settings of the bank being played, follow it with a `ActivateModulationBank` that points to the same bank.

## API

<CodeTabs rust={excerpt(sample, "config")} python={excerpt(pySample, "config")} csharp={excerpt(csSample, "config")} />

| Field      | Type             | Description                                        |
| ---------- | ---------------- | -------------------------------------------------- |
| `bank`     | `ModulationBank` | Target bank                                        |
| `config`   | `SamplingConfig` | Playback sampling frequency                        |
| `size`     | `usize`          | Number of samples                                  |
| `loop_behavior` | `LoopBehavior` | Playback loop count (`Infinite` / `Finite`)       |

The minimum `size` is 2.
To emit a constant modulation, repeat the same value twice.

For the timing at which `loop_behavior` and the transition take effect see [ActivateModulationBank](/autd3-sdk/en/api/command/lowlevel/activate-modulation-bank/).
