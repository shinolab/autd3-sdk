`ConfigModulation` is a low-level command that configures the playback parameters of the Modulation bank.

## API

<CodeTabs rust={excerpt(sample, "config")} python={excerpt(pySample, "config")} csharp={excerpt(csSample, "config")} />

| Field      | Type             | Description                                        |
| ---------- | ---------------- | -------------------------------------------------- |
| `bank`     | `ModulationBank` | Target bank                                        |
| `config`   | `SamplingConfig` | Playback sampling frequency                        |
| `size`     | `usize`          | Number of samples (must match `data.len()`)        |
| `loop_behavior` | `LoopBehavior` | Playback loop count (`Infinite` / `Finite`)       |

For the timing at which `loop_behavior` and the transition take effect see [ChangeModulationBank](/autd3-sdk/en/api/command/lowlevel/change-modulation-bank/).
