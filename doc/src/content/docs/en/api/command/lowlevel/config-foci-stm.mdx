`ConfigFociStm` is a low-level command that configures the playback parameters of the Foci STM bank.
The settings are only written; send [ActivatePatternBank](/autd3-sdk/en/api/command/lowlevel/activate-pattern-bank/) to activate them.

## API

<CodeTabs rust={excerpt(sample, "config")} python={excerpt(pySample, "config")} csharp={excerpt(csSample, "config")} />

| Field           | Type             | Description                                        |
| --------------- | ---------------- | -------------------------------------------------- |
| `bank`          | `PatternBank`    | Target bank                                        |
| `config`        | `SamplingConfig` | Playback sampling frequency                        |
| `size`          | `usize`          | Number of STM samples                              |
| `num_foci`      | `u8`             | Number of focal points per sample (the length of `ControlPoints::points`) |
| `sound_speed`   | `Velocity`       | Sound speed used for focal point computation       |
| `loop_behavior` | `LoopBehavior`   | Playback loop count (`Infinite` / `Finite`)        |

The minimum `size` is 2.
