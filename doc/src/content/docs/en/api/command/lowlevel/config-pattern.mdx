`ConfigPattern` is a low-level command that configures the playback parameters of the Pattern bank.

## API

<CodeTabs rust={excerpt(sample, "config")} python={excerpt(pySample, "config")} csharp={excerpt(csSample, "config")} />

| Field       | Type              | Description                                        |
| ----------- | ----------------- | ------------------------------------------------- |
| `bank`      | `PatternBank`     | Target bank                                       |
| `config`    | `SamplingConfig`  | Playback sampling frequency                       |
| `size`      | `usize`           | Number of samples in the bank. `1` for a static Pattern |
| `loop_behavior` | `LoopBehavior` | Playback loop count (`Infinite` / `Finite`)      |


`loop_behavior` only takes effect when switching to a bank different from the current one via [ChangePatternBank](/autd3-sdk/en/api/command/lowlevel/change-pattern-bank/).

`size = 1` (a static Pattern) is valid only with `loop_behavior = Infinite`.
Use `size` of 2 or more when a finite loop is needed.
