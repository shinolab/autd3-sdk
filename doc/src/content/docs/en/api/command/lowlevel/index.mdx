Composite commands such as `Pattern` / `Modulation` are equivalent to a combination of the following low-level commands.
A composite command is expanded into these low-level commands when it is sent.

| Category      | Pattern family                                                             | Modulation family                                                                |
| ------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Buffer write  | [WritePatternBuffer](/autd3-sdk/en/api/command/lowlevel/write-pattern-buffer/) | [WriteModulationBuffer](/autd3-sdk/en/api/command/lowlevel/write-modulation-buffer/) |
| Bank config   | [ConfigPattern](/autd3-sdk/en/api/command/lowlevel/config-pattern/)           | [ConfigModulation](/autd3-sdk/en/api/command/lowlevel/config-modulation/)           |
| Bank switch   | [ActivatePatternBank](/autd3-sdk/en/api/command/lowlevel/activate-pattern-bank/)   | [ActivateModulationBank](/autd3-sdk/en/api/command/lowlevel/activate-modulation-bank/)   |

This section also includes [WriteFociBuffer](/autd3-sdk/en/api/command/lowlevel/write-foci-buffer/), which writes a focal point sequence for Foci STM, and its configuration [ConfigFociStm](/autd3-sdk/en/api/command/lowlevel/config-foci-stm/).

For writing to the Pattern buffer, there is also [WritePatternPhase](/autd3-sdk/en/api/command/lowlevel/write-pattern-phase/), which sends only the phase and writes multiple Patterns into a single frame.
The intensity is a single value shared by every transducer and Pattern, but it is effective when reducing the transmission volume for high-frequency updates.

For the concept of bank switching see the [bank switching tutorial](/autd3-sdk/en/getting-started/tutorial/bank/), and for loops and transitions see the [loop and transition tutorial](/autd3-sdk/en/getting-started/tutorial/loop/).
