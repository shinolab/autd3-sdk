`WritePatternBuffer` is a low-level command that writes a Pattern (the `Emission` of each transducer) to the specified bank and index.

## API

<CodeTabs rust={excerpt(sample, "write")} python={excerpt(pySample, "write")} csharp={excerpt(csSample, "write")} />

| Field       | Type                             | Description                        |
| ----------- | -------------------------------- | ---------------------------------- |
| `bank`      | `PatternBank`                    | Destination bank                   |
| `index`     | `u16`                            | Destination index for writing within the bank |
| `emissions` | `&[Vec<Emission>]` | Per-device emission pattern        |
