`WritePatternBuffer` is a low-level command that writes a Pattern (the phase and intensity of each transducer) to the specified bank and index.
On the wire the phases are sent first, followed by the intensities, and the device CPU interleaves them per transducer when writing the FPGA memory.

## API

<CodeTabs rust={excerpt(sample, "write")} python={excerpt(pySample, "write")} csharp={excerpt(csSample, "write")} />

| Field       | Type                             | Description                        |
| ----------- | -------------------------------- | ---------------------------------- |
| `bank`      | `PatternBank`                    | Destination bank                   |
| `index`     | `u16`                            | Destination index for writing within the bank |
| `phases`      | `&[Vec<Phase>]`     | Per-device phases                  |
| `intensities` | `PatternIntensity`  | Intensity (a uniform `Intensity`, or a per-device `&[Vec<Intensity>]` buffer) |
