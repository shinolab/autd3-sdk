`WriteModulationBuffer` is a low-level command that writes an AM waveform (`&[u8]`) to the specified bank and offset.

## API

<CodeTabs rust={excerpt(sample, "write")} python={excerpt(pySample, "write")} csharp={excerpt(csSample, "write")} />

| Field      | Type             | Description                        |
| ---------- | ---------------- | ---------------------------------- |
| `bank`     | `ModulationBank` | Destination bank                   |
| `offset`   | `usize`          | Start offset for writing within the bank |
| `data`     | `&[u8]`          | Sequence of AM waveform samples    |
