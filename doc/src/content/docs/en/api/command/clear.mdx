`Clear` is a command that returns the device banks and various settings to the state right after startup.
All settings such as Silencer / Pattern / Modulation are reinitialized.

## Synchronize / Nop

Other commands without a payload are `Synchronize` and `Nop` (`Synchronize` / `Nop` in Rust, `Synchronize()` / `Nop()` in Python, and `new Synchronize()` / `new Nop()` in C#).

- `Synchronize` reinitializes the synchronization clock the FPGA uses to generate PWM and aligns the output phase across the devices. It is sent after `Clear` when the `Client` opens, and `resynchronize_on_recovery` of `ClientConfig` sends it again by default to a device recovered automatically from `Lost` (see [Client](/autd3-sdk/en/api/basics/client/#clientconfig)).
- `Nop` changes nothing and always returns success.
