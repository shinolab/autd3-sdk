`SetOutputMask` is a command that toggles output enable/disable per transducer.

## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| Field   | Type           | Description                                                    |
| ------- | -------------- | ------------------------------------------------------------- |
| `masks` | `&[Vec<bool>]` | Output mask per device (output when `true`). |

`Geometry::output_mask_buffer` allocates the masks for all devices.
Every entry starts at `true` (all transducers output).

If the number of devices or the number of transducers of each device does not match `geometry`, it is an error when the command is encoded (at send time) (the same in Python / C#).
