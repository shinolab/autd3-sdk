`ReleaseFailsafe` is a command that resumes the output stopped by the failsafe (loss of communication with the host, loss of the PTP lock, or the CPU watchdog).
See [SetCpuConfig](/autd3-sdk/en/api/command/cpu-config/) for the failsafe conditions and defaults.

The output from before the stop resumes as it was.
It does nothing to devices that are not stopped by the failsafe.
A device whose firing condition still holds (for example, one that is still without the PTP lock) rejects it with an error (`ERR_FAILSAFE_CONDITION_ACTIVE`) and stays stopped.
Whether the output is stopped can be checked with `is_failsafe_active()` (C#: `IsFailsafeActive`) of the `FpgaState` returned by `read_fpga_state()`.

[Clear](/autd3-sdk/en/api/command/clear/) also releases it, but it resets every state to the defaults.
It is not sent automatically to a device recovered from `Lost` by `recover()`; send it yourself to resume the output (see [State Monitoring](/autd3-sdk/en/guide/state-check/#recovery-from-lost)).
