`SetFpgaConfig` is a command that changes the settings held by the FPGA.

## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

### FpgaConfig

| Field             | Type   | Default | Description |
| ----------------- | ------ | ------- | ----------- |
| `sync_phase_lock` | `bool` | `true`  | Fine adjustment that phase-locks the FPGA clock to the sync pulse shared between devices. (enabled by default) |
