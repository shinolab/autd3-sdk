`bessel` generates a Bessel beam.
The algorithm is based on the paper by Hasegawa et al. ([Hasegawa et al., 2017](https://doi.org/10.1063/1.4985159)).

<PatternField kind="bessel" />

## API

<CodeTabs rust={"bessel(&geometry, apex, direction, theta, wavelength, &option, &mut dst);"} python={"bessel(geometry, apex, direction, theta, wavelength, option, dst)"} csharp={"Pattern.Bessel(geometry, apex, direction, theta, wavelength, option, dst);"} />

| Parameter    | Type                   | Description                          |
| ------------ | ---------------------- | ----------------------------------- |
| `geometry`   | `&Geometry`            | Device layout                       |
| `apex`       | `Point3<f32>`          | Coordinates of the apex of the virtual cone that generates the beam \[mm] |
| `direction`  | `UnitVector3<f32>`     | Direction of the beam (unit vector) |
| `theta`      | `Angle`                | Half-apex angle of the cone (e.g. `18.0 * deg`) |
| `wavelength` | `Length`               | Wavelength                          |
| `option`     | `&BesselOption`        | Additional options (see below)      |
| `dst`        | `&mut [[Emission; _]]` | Output buffer                       |

## BesselOption

<CodeTabs rust={"BesselOption {\n    intensity,\n    phase_offset,\n}"} python={"BesselOption(\n    intensity,\n    phase_offset,\n)"} csharp={"new BesselOption(\n    intensity,\n    phaseOffset\n)"} />

| Field          | Type        | Default          | Description                  |
| -------------- | ----------- | ---------------- | ---------------------------- |
| `intensity`    | `Intensity` | `Intensity::MAX` | Amplitude of all transducers |
| `phase_offset` | `Phase`     | `Phase::ZERO`    | Phase added uniformly to all transducers |
