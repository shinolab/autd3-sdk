`Pattern` is a command that sends the `Emission` of each transducer to the device.

## API

<CodeTabs>
  <Fragment slot="rust">
    <Code code={"Pattern::new(&emissions);\n\nPattern::with_bank(bank, &emissions);\n\nPattern {\n    bank,\n    emissions: &emissions,\n};"} lang="rust" />

    `Pattern::new` sets the destination bank to `PatternBank::B0`.
    To write to another bank, use `Pattern::with_bank(bank, emissions)`.
  </Fragment>

  <Fragment slot="python">
    <Code code={"Pattern(emissions)\n\nPattern(\n    bank=bank,\n    emissions=emissions,\n)"} lang="python" />

    `Pattern` sets the destination bank to `PatternBank.B0` by default.
    To specify another bank, pass the `bank` argument.
  </Fragment>

  <Fragment slot="csharp">
    <Code code={"new Pattern(emissions);\n\nnew Pattern(bank, emissions);"} lang="csharp" />

    `new Pattern(emissions)` sets the destination bank to `PatternBank.B0`.
    To write to another bank, use `new Pattern(bank, emissions)`.
  </Fragment>
</CodeTabs>

| Field             | Type                             | Default                     | Description                      |
| ----------------- | -------------------------------- | --------------------------- | -------------------------------- |
| `bank`            | `PatternBank`                    | `PatternBank::B0`           | Bank to write to / play back     |
| `emissions`       | `&[Vec<Emission>]` | —                           | Emission pattern per device      |

Several [helper functions](/autd3-sdk/en/0.4.x/api/compute/pattern/) are provided for computing patterns.

## Equivalent Low-Level Commands

`Pattern` is equivalent to the three commands [WritePatternBuffer](/autd3-sdk/en/0.4.x/api/command/lowlevel/write-pattern-buffer/) + [ConfigPattern](/autd3-sdk/en/0.4.x/api/command/lowlevel/config-pattern/) + [ChangePatternBank](/autd3-sdk/en/0.4.x/api/command/lowlevel/change-pattern-bank/), which are fused into a single frame.
The following is equivalent to `Pattern { bank, emissions }`.

<CodeTabs rust={"WritePatternBuffer {\n    bank,\n    index: 0,\n    emissions,\n};\nConfigPattern {\n    bank,\n    config: SamplingConfig::new(NonZeroU16::MAX),\n    size: 1,\n    loop_behavior: LoopBehavior::Infinite,\n};\nChangePatternBank {\n    bank,\n    transition_mode: TransitionMode::Immediate,\n};"} python={"WritePatternBuffer(\n    bank=bank,\n    index=0,\n    emissions=emissions,\n)\nConfigPattern(\n    bank=bank,\n    config=SamplingConfig(0xFFFF),\n    size=1,\n    loop_behavior=LoopBehavior.Infinite,\n)\nChangePatternBank(\n    bank=bank,\n    transition_mode=TransitionMode.Immediate\n)"} csharp={"new WritePatternBuffer(\n    bank: bank,\n    index: 0,\n    emissions: emissions\n);\nnew ConfigPattern(\n    bank: bank,\n    config: new SamplingConfig(ushort.MaxValue),\n    size: 1,\n    loopBehavior: LoopBehavior.Infinite\n);\nnew ChangePatternBank(\n    bank: bank,\n    transitionMode: TransitionMode.Immediate\n);"} />
