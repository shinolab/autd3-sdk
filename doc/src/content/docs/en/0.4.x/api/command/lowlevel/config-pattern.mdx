`ConfigPattern` is a low-level command that configures the playback parameters of the Pattern bank.

## API

<CodeTabs rust={"ConfigPattern {\n    bank,\n    config,\n    size,\n    loop_behavior,\n};"} python={"ConfigPattern(\n    bank=bank,\n    config=config,\n    size=size,\n    loop_behavior=loop_behavior,\n)"} csharp={"new ConfigPattern(\n    bank: bank,\n    config: config,\n    size: size,\n    loopBehavior: loopBehavior\n);"} />

| Field       | Type              | Description                                        |
| ----------- | ----------------- | ------------------------------------------------- |
| `bank`      | `PatternBank`     | Target bank                                       |
| `config`    | `SamplingConfig`  | Playback sampling frequency                       |
| `size`      | `usize`           | Number of samples in the bank. `1` for a static Pattern |
| `loop_behavior` | `LoopBehavior` | Playback loop count (`Infinite` / `Finite`)      |

`loop_behavior` only takes effect when switching to a bank different from the current one via [ChangePatternBank](/autd3-sdk/en/0.4.x/api/command/lowlevel/change-pattern-bank/).

`size = 1` (a static Pattern) is valid only with `loop_behavior = Infinite`.
Use `size` of 2 or more when a finite loop is needed.

## Example
