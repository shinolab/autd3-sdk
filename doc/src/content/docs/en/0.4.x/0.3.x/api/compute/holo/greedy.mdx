greedy is a combinatorial optimization that greedily selects the phase of each transducer one at a time from a set of discrete candidates.
The algorithm is based on the paper by Suzuki et al. ([Suzuki et al., 2021](https://doi.org/10.1109/TOH.2021.3076489)).

## API

<CodeTabs rust={"greedy(&geometry, &foci, wavelength, &option, &mut dst)?;"} python={"greedy(geometry, foci, wavelength, option, dst)"} csharp={"Holo.Greedy(geometry, foci, wavelength, option, dst);"} />

| Parameter    | Type                   | Description               |
| ------------ | ---------------------- | ------------------------- |
| `geometry`   | `&Geometry`            | Device layout             |
| `foci`       | `&[ControlPoint]`      | Sequence of focal points (position and target amplitude) |
| `wavelength` | `Length`               | Wavelength                |
| `option`     | `&GreedyOption`        | Additional options (see below) |
| `dst`        | `&mut [[Emission; _]]` | Output buffer             |

For the common elements (`ControlPoint` / `TransducerMask`, etc.), see the [Holo overview](/autd3-sdk/en/0.4.x/0.3.x/api/compute/holo/).

## GreedyOption

<CodeTabs rust={"GreedyOption {\n    phase_quantization_levels,\n    constraint,\n    directivity,\n    objective_func,\n    mask,\n}"} python={"GreedyOption(\n    phase_quantization_levels,\n    constraint,\n    directivity,\n    mask,\n)"} csharp={"new GreedyOption(\n    phaseQuantizationLevels,\n    constraint,\n    directivity,\n    mask\n)"} />

| Field                       | Type                              | Default              |
|-----------------------------|-----------------------------------|----------------------|
| `phase_quantization_levels` | `NonZeroU8`                       | `16`                 |
| `constraint`                | `EmissionConstraint`              | `Uniform(MAX)`       |
| `directivity`               | `Directivity`                     | `Sphere`             |
| `objective_func`            | `fn(Complex<f32>, Amplitude) -> f32` | `abs_objective_func` |
| `mask`                      | `TransducerMask`                  | `AllEnabled`         |

* `phase_quantization_levels` — the number of divisions of the phase candidates. The larger it is, the higher the phase resolution.
* `objective_func` — the objective function that evaluates each candidate. The default `abs_objective_func` returns the absolute value of the difference between the magnitude of the synthesized sound pressure and the target amplitude.
  * Configurable only in the Rust version. In other languages, the default objective function is used.
* For the meaning of `constraint` / `directivity` / `mask`, see the [Holo overview](/autd3-sdk/en/0.4.x/0.3.x/api/compute/holo/).
