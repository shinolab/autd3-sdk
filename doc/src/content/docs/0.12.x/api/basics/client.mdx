`Client` はコマンドの送信・状態の読み出しを行う中心的なオブジェクト.

<Install rust="autd3-rs" python="autd3" csharp="AUTD3" />

<CodeTabs rust={"let client = Client::open(&geometry, &udp, option).await?;"} python={"client = await Client.open(geometry, udp, option)"} csharp={"var client = await Client.OpenAsync(geometry, udp, option);"} />

| 引数       | 型                | 説明                                                         |
| ---------- | ----------------- | ------------------------------------------------------------ |
| `geometry` | `&Geometry`       | デバイスの物理配置                                           |
| `link`     | `impl Into<Link>` | 接続先. [`UdpOption`](/autd3-sdk/0.12.x/api/basics/transport-option/) か `ServerLink` |
| `config`   | `ClientConfig`    | 下記参照                                                     |

`UdpOption` を渡すと実機 (または [Simulator](/autd3-sdk/0.12.x/guide/simulator/)) へ直接つなぐ.
`ServerLink` を渡すと同じホストで動いている [Server](/autd3-sdk/0.12.x/guide/server/) を経由してつなぐ.

<CodeTabs rust={"let link = ServerLink { port, timeout };\nlet client = Client::open(&geometry, &link, ClientConfig::default()).await?;"} python={"link = ServerLink(port=port, timeout=timeout)\nclient = await Client.open(geometry, link, ClientConfig())"} csharp={"var link = new ServerLink { Port = port, Timeout = timeout };\nvar client = await Client.OpenAsync(geometry, link, new ClientConfig());"} />

デバイスの稼働状態を継続的に監視したい場合は `Client::state_checker` で取った `StateChecker` を駆動する ([状態監視](/autd3-sdk/0.12.x/guide/state-check/) 参照).

## API

<CodeTabs rust={"let num_devices = client.num_devices();\nlet geometry = client.geometry();\n\nlet config = client.config();\nclient.set_config(ClientConfig {\n    ack_timeout: Duration::from_millis(20),\n    ..ClientConfig::default()\n})?;\n\nlet firmware = client.read_firmware_version().await?;\nlet fpga_state = client.read_fpga_state().await?;\n\nclient.send(Nop).await?;\nlet done = client.send_streaming(Nop).await?;\nlet resp = client.send_frame(frame).await?.await?;\n\nclient.silent_stop().await?;\nclient.close().await?;"} python={"num_devices = client.num_devices()\ngeometry = client.geometry()\n\nconfig = client.config()\nclient.set_config(ClientConfig(ack_timeout=Duration.from_millis(20)))\n\nfirmware = await client.read_firmware_version()\nfpga_state = await client.read_fpga_state()\n\nawait client.send(Nop())\ndone = await client.send_streaming(Nop())\nresp = await (await client.send_frame(frame))\n\nawait client.silent_stop()\nawait client.close()"} csharp={"var numDevices = client.NumDevices;\nvar geometry = client.Geometry;\n\nvar config = client.Config;\nclient.SetConfig(new ClientConfig { AckTimeout = TimeSpan.FromMilliseconds(20) });\n\nvar firmware = await client.ReadFirmwareVersionAsync();\nvar fpgaState = await client.ReadFpgaStateAsync();\n\nawait client.SendAsync(new Nop());\nvar done = await client.SendStreamingAsync(new Nop());\nvar resp = await await client.SendFrameAsync(frame);\n\nawait client.SilentStopAsync();\nawait client.CloseAsync();"} />

| `num_devices()`           | —     | `usize`                                | 接続中のデバイス台数                                       |

| `read_fpga_state()`       | ✓     | `Result<Vec<FpgaState>, Error>`       | 各デバイスの FPGA 状態                                     |

| `device_time_now()`       | —     | `Result<SysTime, Error>`              | 現在のデバイスの時刻 ([SysTime](/autd3-sdk/0.12.x/api/basics/sys-time/) 参照). 時刻を載せた返信をまだ受けていなければ `DeviceTimeUnknown` |
| `config()`                | —     | `ClientConfig`                        | 現在の [ClientConfig](#clientconfig)                        |
| `set_config(config)`      | —     | `Result<(), Error>`                   | ClientConfig を更新する |

| `send_streaming(cmd)`     | ✓     | `Result<StreamFuture, Error>`         | `send`のstream版                                           |
| `send_frame(frame)`       | ✓     | `Result<ResponseFuture, Error>`       | フレームを 1 つ送る                                        |
| `send_frame_at(frame, exec)` | ✓  | `Result<ResponseFuture, Error>`       | 処理時刻を指定してフレームを 1 つ送る ([処理時刻の上書き](#処理時刻の上書き) 参照) |

`silent_stop()` は, 振幅を一気に落としてノイズが出るのを避けるため, まず [Silencer](/autd3-sdk/0.12.x/api/command/silencer/) を設定してから全振動子の振幅を 0 にする.
Silencer の設定は上書きされたままになるので, 別の設定で出力を再開する場合は `SetSilencer` を送り直すこと.

## 読み出し結果の型

`read_firmware_version()` / `read_fpga_state()` / `read_telemetry()` はデバイス番号順に 1 台 1 要素の配列を返す.
`Lost` のデバイスがある間は `DeviceLost` で失敗する.

Python のメソッド・フィールド名は Rust と同じ (フィールドはプロパティ).
C# は PascalCase のプロパティになる (`is_thermal_asserted()` → `IsThermalAsserted`, `fifo_drop` → `FifoDrop` など).

### FirmwareVersion

| メンバ                  | 型               | 説明                                                   |
| ----------------------- | ---------------- | ------------------------------------------------------ |
| `cpu`                   | `Version`        | CPU ファームウェアのバージョン                         |
| `fpga`                  | `Version`        | FPGA ファームウェアのバージョン (読めなければ `0.0.0`) |
| `is_emulator()`         | `bool`           | デバイスエミュレータか                                 |
| `is_supported()`        | `bool`           | CPU と FPGA の両方がこの SDK のサポートする系列か      |
| `SUPPORTED_SERIES`      | `(u8, u8)`       | サポートする系列 (major, minor) (C#: `SupportedSeries`) |

`Version` は `major` / `minor` / `patch` (`u8`) と `is_unknown()` (`0.0.0` か) を持つ.

### FpgaState

| メソッド                  | 型               | 説明                                     |
| ------------------------- | ---------------- | ---------------------------------------- |
| `raw()`                   | `u8`             | 状態レジスタの生の値                     |
| `is_thermal_asserted()`   | `bool`           | 温度センサが閾値を超えているか           |
| `current_mod_bank()`      | `ModulationBank` | 現在の Modulation bank                   |
| `current_pattern_bank()`  | `PatternBank`    | 現在の Pattern bank (Pattern と STM で共有) |
| `is_pattern_mode()`       | `bool`           | Pattern を出力しているか                 |
| `is_stm_mode()`           | `bool`           | STM を出力しているか                     |
| `is_pattern_stopped()`    | `bool`           | Pattern / STM の再生が止まっているか |
| `is_mod_stopped()`        | `bool`           | Modulation の再生が止まっているか |
| `is_transition_pending()` | `bool`           | bank の切り替えが発効待ちか              |
| `is_failsafe_active()`    | `bool`           | フェイルセーフで出力が止まっているか     |

### Telemetry

CPU の診断カウンタ. `Clear` で `boot_failure` 以外は 0 に戻る (`Client` は開くときに `Clear` を送る).
読み出してもクリアされない.

| フィールド            | 型    | 説明                                                   |
| --------------------- | ----- | ------------------------------------------------------ |
| `fifo_drop`           | `u32` | 受信 FIFO が満杯で捨てたフレーム数                     |
| `dedup`               | `u32` | 重複として捨てたフレーム数                             |
| `seq_mismatch`        | `u32` | シーケンス番号が合わず無視したフレーム数               |
| `dispatch_error`      | `u32` | 処理がエラーになった回数                               |
| `processed`           | `u32` | 処理したフレーム数                                     |
| `send_failure`        | `u32` | NIC が送信を断った回数                                 |
| `failsafe`            | `u16` | ホストとの通信途絶によるフェイルセーフの発火回数       |
| `ptp_unlock_failsafe` | `u16` | PTP ロック喪失によるフェイルセーフの発火回数           |
| `sync_resync`         | `u8`  | 同期入力のハード再同期回数 (`Synchronize` で 0 に戻る) |
| `boot_failure`        | `u8`  | 起動時に失敗した手順の数 (`Clear` で消えない)          |
| `cpu_watchdog`        | `u8`  | CPU ウォッチドッグの発火回数 (FPGA の再構成まで消えない) |

`u32` のフィールドは桁あふれで 0 に戻り, `u16` / `u8` のフィールドは上限で止まる.

### BusStats

`bus_stats()` はホスト側の送受信の統計を返す. 値は `Client` を開いてからの累計で, 読むたびに最新の値になる.

| メソッド                     | 型    | 説明                                         |
| ---------------------------- | ----- | -------------------------------------------- |
| `frames()`                   | `u64` | 送ったフレーム数                             |
| `resets()`                   | `u64` | 送った `Reset` の数                          |
| `heartbeats()`               | `u64` | 送った Heartbeat の数                        |
| `missed_heartbeat_replies()` | `u64` | `reply_timeout` までに返らなかった Heartbeat の返信の数 |
| `recoveries()`               | `u64` | `Lost` から自動復帰したデバイスの数          |
| `acked_frames()`             | `u64` | 返信を受けたフレーム数                       |
| `worst_ack_latency_ns()`     | `u64` | 送信から返信までの最大時間 \[ns]              |
| `mean_ack_latency_ns()`      | `u64` | 送信から返信までの平均時間 \[ns]              |

## ClientConfig

<CodeTabs rust={"ClientConfig {\n    ack_timeout: Duration::from_millis(10),\n    max_inflight: NonZeroUsize::new(DEVICE_QUEUE_FRAMES).unwrap(),\n    max_resync_rounds: NonZeroU32::new(8).unwrap(),\n    require_supported_firmware: false,\n    resynchronize_on_recovery: NonZeroU32::new(3),\n    release_failsafe_on_recovery: NonZeroU32::new(3),\n    exec_lead: None,\n}"} python={"ClientConfig(\n    ack_timeout=Duration.from_millis(10),\n    max_inflight=DEVICE_QUEUE_FRAMES,\n    max_resync_rounds=8,\n    require_supported_firmware=False,\n    resynchronize_on_recovery=3,\n    release_failsafe_on_recovery=3,\n    exec_lead=None,\n)"} csharp={"new ClientConfig\n{\n    AckTimeout = TimeSpan.FromMilliseconds(10),\n    MaxInflight = (uint)Params.DeviceQueueFrames,\n    MaxResyncRounds = 8,\n    RequireSupportedFirmware = false,\n    ResynchronizeOnRecovery = 3,\n    ReleaseFailsafeOnRecovery = 3,\n    ExecLead = null,\n}"} />

| フィールド             | 型                    | デフォルト          | 説明                                                       |
| ---------------------- | --------------------- | ------------------- | ---------------------------------------------------------- |
| `ack_timeout`          | `Duration`            | 10 ms               | 応答待ちのタイムアウト. 過ぎると送信中のフレームは `Timeout` で失敗する. |
| `max_inflight`         | `NonZeroUsize`        | `7`                 | 応答を待たずに送ってよいフレーム数 (stream送信用)           |
| `max_resync_rounds`    | `NonZeroU32`          | `8`                 | デバイスとの足並みを揃え直す試行の回数上限                 |
| `require_supported_firmware` | `bool`          | `false`             | `true`なら接続時にファームウェアがサポートされているか検査する |
| `resynchronize_on_recovery` | `Option<NonZeroU32>` | `Some(3)`       | `Lost` から自動復帰したデバイスへ, 次の送信の前に `Synchronize` を送り直す. 値は試行回数の上限で, `None` なら送らない ([状態監視](/autd3-sdk/0.12.x/guide/state-check/) 参照) |
| `release_failsafe_on_recovery` | `Option<NonZeroU32>` | `Some(3)`    | `Lost` から自動復帰したデバイスへ, 次の送信の前に `ReleaseFailsafe` を送り, フェイルセーフで止まった出力を再開させる. 値は試行回数の上限で, `None` なら送らない ([状態監視](/autd3-sdk/0.12.x/guide/state-check/) 参照) |
| `exec_lead`           | `Option<Duration>`  | `None` | 送信したフレームを全デバイスが同じ時刻に処理し始めるようにする (後述). `None` で各デバイスが届いた順にすぐ処理する |

`max_inflight` は `MAX_INFLIGHT (7)` (Python: `autd3.params.MAX_INFLIGHT`, C#: `Params.MaxInflight`) を超えるとエラーになる.
既定値も `MAX_INFLIGHT` で, これは各デバイスの受信キューのフレーム数 `DEVICE_QUEUE_FRAMES` (Python: `autd3.params.DEVICE_QUEUE_FRAMES`, C#: `Params.DeviceQueueFrames`) に等しい.
`ack_timeout` を 0 にすると, `Client` を開くときにエラー (`InvalidConfig`. Python の `Autd3Error.code` は `INVALID_ARGUMENT`, C# の `Autd3Exception.Code` は `InvalidArgument`) になる.
Python の既定値は Rust と同じで, `None` を渡せるのは型が `Option` の `resynchronize_on_recovery` / `release_failsafe_on_recovery` だけである.

再送処理は行われない. 失敗したコマンドはユーザが送り直す必要がある.

### exec\_lead

デバイスへ送信は順に 1 台ずつ行われるので, 各デバイスにフレームが届く時刻は少しずつずれる.
`exec_lead` を指定すると, 送信の際に「デバイスの現在時刻 + `exec_lead`」 を 1 µs 単位に切り上げた時刻を送信し, 各デバイスはその時刻まで処理を待つ.
これにより, 1 回の送信の内容を全デバイスが同じタイミングで処理し始める.

注意点は以下の通り

* 必ず全デバイスが同じ時刻に処理を始めることを保証はしない
  * 送信の完了が `exec_lead` 以内に終わらなければ, 遅れたデバイスは指定時刻を過ぎてから処理する. この回数は `read_telemetry` の `exec_late` で読める.
  * streaming で送ると, 前のフレームの処理中に次のフレームの指定時刻が来ることがあり, そのフレームは遅れて処理される (`exec_late` にカウントされる).
  * また, 成功したとしてもCPUボード内部の処理の開始が揃うだけであり, FPGAの処理の開始が揃うこと (すなわち, 出力される超音波の位相の更新タイミングが揃うことなど) は保証しない
* 送信完了が`exec_lead` だけ遅れる
* 100 µs 以上, 2^31 µs (約 35.8 分) 未満でなければならない. また, [`UdpOption`](/autd3-sdk/0.12.x/api/basics/transport-option/) の `lost_timeout` 未満でなければならない
* `ack_timeout` (既定 10 ms) は `exec_lead` + 処理時間より長くする

### 処理時刻の上書き

`exec_lead` は全てのフレームに同じ規則で処理時刻を付ける.
特定のフレームだけ別の処理時刻にするには, `send_frame_at` に `ExecAt` を渡して送る.
`send` / `send_streaming` / `send_frame` は `exec_lead` に従う.

<CodeTabs rust={"let at = client.device_time_now()? + Duration::from_millis(5);\nclient.send_frame_at(frame, ExecAt::At(at)).await?.await?.check()?;\n\nlet lead = ExecAt::Lead(Duration::from_millis(1));\nclient.send_frame_at(frame, lead).await?.await?.check()?;\n\nclient.send_frame_at(frame, ExecAt::Immediate).await?.await?.check()?;"} python={"at = client.device_time_now() + Duration.from_millis(5)\n(await (await client.send_frame_at(frame, ExecAt.At(at)))).check()\n\nlead = ExecAt.Lead(Duration.from_millis(1))\n(await (await client.send_frame_at(frame, lead))).check()\n\n(await (await client.send_frame_at(frame, ExecAt.Immediate))).check()"} csharp={"var at = client.DeviceTimeNow() + TimeSpan.FromMilliseconds(5);\n(await await client.SendFrameAsync(frame, ExecAt.At(at))).Check();\n\nvar lead = ExecAt.Lead(TimeSpan.FromMilliseconds(1));\n(await await client.SendFrameAsync(frame, lead)).Check();\n\n(await await client.SendFrameAsync(frame, ExecAt.Immediate)).Check();"} />

| `ExecAt`         | 処理時刻                                                                 |
| ---------------- | ------------------------------------------------------------------------ |
| `Immediate`      | 付けない (`exec_lead` を指定していても, 届いた順にすぐ処理する)          |
| `Lead(lead)`     | デバイスの現在時刻 + `lead` (このフレームだけ `exec_lead` の代わりに使う) |
| `At(sys_time)`   | デバイス時刻 `sys_time` ([SysTime](/autd3-sdk/0.12.x/api/basics/sys-time/) 参照) |

* `Lead` の値の範囲は `exec_lead` と同じ (100 µs 以上, 2^31 µs 未満, `lost_timeout` 未満). 外れると `InvalidPayload` で, そのフレームは送られない
* `At` は現在時刻より 2^31 µs 以上先・2^30 µs (約 17.9 分) 以上前, または `lost_timeout` 以上先だとエラーになる. 過ぎた時刻 (範囲内) は受け付け, デバイスはすぐに処理して `exec_late` に数える
* `ack_timeout` (既定 10 ms) は, 送信から指定時刻までの時間 + 処理時間より長くする
* `Lead` / `At` はデバイスの時刻が分からない (時刻を載せた返信をまだ受けていない) と `DeviceTimeUnknown` で失敗する

## each

`each` はデバイスを引数にするクロージャを受け取り, デバイスごとに異なるコマンドを割り当てる.
Rust では `FnMut(&Device) -> Option<C>`, Python では `Callable[[Device], Command | None]`, C# では `Func<Device, ICommand?>`.
`None` を返したデバイスには何も割り当てない.

<CodeTabs rust={"client\n    .send(each(|device| {\n        Some(if device.idx() % 2 == 0 {\n            Pattern::new(&left, Intensity::MAX)\n        } else {\n            Pattern::new(&right, Intensity::MAX)\n        })\n    }))\n    .await?;"} python={"await client.send(each(lambda device: Pattern(left if device.idx() % 2 == 0 else right, Intensity.MAX)))"} csharp={"await client.SendAsync(Command.Each(device => device.Idx % 2 == 0\n    ? new Pattern(left, Intensity.Max)\n    : new Pattern(right, Intensity.Max)));"} />

Rust ではクロージャの返り値はすべて同じ型でなければならない.
型の異なるコマンドを混在させたい場合は, `Command::boxed` で `BoxedCommand` に揃える.

<CodeTabs rust={"client\n    .send(each(|device| {\n        Some(if device.idx() % 2 == 0 {\n            Pattern::new(&left, Intensity::MAX).boxed()\n        } else {\n            Modulation::new(SamplingConfig::FREQ_4K, &modulation).boxed()\n        })\n    }))\n    .await?;"} />
