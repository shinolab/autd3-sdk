`Clear` は, デバイスのバンク・各種設定を起動直後の状態へ戻すコマンド.
Silencer / Pattern / Modulation などの設定がすべて初期化される.

## API

<CodeTabs rust={"Clear;"} python={"Clear()"} csharp={"new Clear();"} />

## Example

<CodeTabs rust={"use autd3_rs::commands::Clear;\nuse autd3_rs::geometry::{Autd3, Geometry};\nuse autd3_rs::{Client, ClientConfig};\nuse autd3_rs::udp::UdpOption;\nuse autd3_rs_firmware_emulator::udp::UdpEmulator;\n\nlet geometry = Geometry::new(vec![Autd3::default()]);\nlet emulator = UdpEmulator::spawn(geometry.num_devices())?;\nlet option = UdpOption::for_emulator(emulator.interface());\nlet client = Client::open(&geometry, &option, ClientConfig::default()).await?;\n\nclient.send(Clear).await?;\n\nclient.close().await?;"} python={"import asyncio\n\nfrom autd3 import Client, ClientConfig, UdpEmulator\nfrom autd3.commands import Clear\nfrom autd3.geometry import Autd3, Geometry\n\n\nasync def main() -> None:\n    geometry = Geometry([Autd3()])\n    emulator = UdpEmulator(geometry.num_devices())\n    async with await Client.open(geometry, emulator.option(), ClientConfig()) as client:\n        await client.send(Clear())\n\n\nasyncio.run(main())"} csharp={"using System.Threading.Tasks;\nusing AUTD3;\n\nvar geometry = new Geometry(new[] { new Autd3() });\nusing var emulator = new UdpEmulator(geometry.NumDevices);\nawait using var client = await Client.OpenAsync(geometry, emulator.Option(), new ClientConfig());\n\nawait client.SendAsync(new Clear());"} />

## Synchronize / Nop

ペイロードを持たないコマンドとして, ほかに `Synchronize` と `Nop` がある (Rust は `Synchronize` / `Nop`, Python は `Synchronize()` / `Nop()`, C# は `new Synchronize()` / `new Nop()`).

* `Synchronize` は, FPGA が PWM 生成に使う同期クロックを初期化し直し, デバイス間の出力の位相を揃える. `Client` を開くときに `Clear` の後に送られ, `Lost` から自動復帰したデバイスには `ClientConfig` の `resynchronize_on_recovery` が既定で送り直す ([Client](/autd3-sdk/0.12.x/api/basics/client/#clientconfig) 参照).
* `Nop` は何も変更せず, 常に成功を返す.
