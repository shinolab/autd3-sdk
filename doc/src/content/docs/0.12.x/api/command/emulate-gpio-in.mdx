`EmulateGpioIn` は, デバイスの 4 本の [GPIO 入力端子](/autd3-sdk/0.12.x/hardware/gpio/) をソフトウェアからアサートするコマンド.
FPGA が参照する実効値は, 物理端子の入力と `EmulateGpioIn` の論理和になる.
[`TransitionMode::Gpio`](/autd3-sdk/0.12.x/api/command/lowlevel/activate-pattern-bank/) による切り替えを, 外部の配線なしに試すときなどに使う.

## API

<CodeTabs rust={"EmulateGpioIn { values };"} python={"EmulateGpioIn(values)"} csharp={"new EmulateGpioIn(values);"} />

| フィールド | 型          | デフォルト    | 説明                                                     |
| ---------- | ----------- | ------------- | -------------------------------------------------------- |
| `values`   | `[bool; 4]` | すべて `false` | 入力 0..3 のそれぞれをアサートするか (`true` でアサート) |

Python は長さ 4 の `bool` の列, C# は長さ 4 の `bool[]` で渡す.
長さが 4 でないと構築時にエラーになる (Python は `ValueError`, C# は `Autd3Exception` (`InvalidArgument`)). Rust は配列の型で長さが決まる.

## Example
