`WritePatternPhase` は, 強度が全振動子・全 Pattern で共通の場合に使える [`WritePatternBuffer`](/autd3-sdk/0.12.x/api/command/lowlevel/write-pattern-buffer/) の軽量版.

## API

<CodeTabs rust={"WritePatternPhase {\n    bank,\n    index,\n    depth,\n    intensity,\n    patterns,\n};"} python={"WritePatternPhase(\n    bank=bank,\n    index=index,\n    depth=depth,\n    intensity=intensity,\n    patterns=patterns,\n)"} csharp={"new WritePatternPhase(\n    bank: bank,\n    index: index,\n    depth: depth,\n    intensity: intensity,\n    patterns: patterns\n);"} />

| フィールド  | 型                    | 説明                                                   |
| ----------- | --------------------- | ------------------------------------------------------ |
| `bank`      | `PatternBank`         | 書き込み先バンク                                       |
| `index`     | `usize`               | バンク内の書き込み開始インデックス                     |
| `depth`     | `PhaseDepth`          | 位相のビット幅 (下記参照)                              |
| `intensity` | `Intensity`           | 全振動子・全 Pattern に共通の強度                      |
| `patterns`  | `&[Vec<Vec<Phase>>]`  | 書き込む位相の列 (1 個以上 `depth.max_count()` 個以下) |

## PhaseDepth

| バリアント | 1 フレームあたりの Pattern 数 (`max_count()`) | 説明                                       |
| ---------- | --------------------------------------------- | ------------------------------------------ |
| `Bits8`    | 5                                             | 位相を全分解能 (8 bit) で送る (デフォルト) |
| `Bits4`    | 11                                            | 位相を上位 4 bit に量子化して送る          |

## Example
