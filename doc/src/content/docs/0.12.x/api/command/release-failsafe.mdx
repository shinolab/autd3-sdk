`ReleaseFailsafe` は, フェイルセーフ (ホストとの通信途絶・PTP ロック喪失・CPU ウォッチドッグ) で止まった出力を再開させるコマンド.
フェイルセーフの条件と既定値は [SetCpuConfig](/autd3-sdk/0.12.x/api/command/cpu-config/) を参照.

止まる前の出力がそのまま再開する.
フェイルセーフで止まっていないデバイスには何もしない.
発火の条件が成り立ったままのデバイス (PTP のロックを失ったまま等) は, エラー (`ERR_FAILSAFE_CONDITION_ACTIVE`) で拒否し, 止まったままにする.
止まっているかどうかは `read_fpga_state()` が返す `FpgaState` の `is_failsafe_active()` (C#: `IsFailsafeActive`) で確認できる.

[Clear](/autd3-sdk/0.12.x/api/command/clear/) でも解除されるが, すべての状態が既定値に戻る.
`Lost` から自動復帰したデバイスには, `ClientConfig` の `release_failsafe_on_recovery` が既定で `ReleaseFailsafe` を送る ([Client](/autd3-sdk/0.12.x/api/basics/client/#clientconfig) 参照).
