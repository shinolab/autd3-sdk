`Server` は, 実機との接続をクライアントのプロセスから切り離して保持し続ける常駐プロセス.
クライアントは同じホスト上の Server へ接続し, Server がデータを実機へ中継する.

台数が多く, クライアントを開き直すたびに列挙と同期の待ち時間がかかるのが困る場合などに使う.

## 起動

`Server` は GUI コンソール `autd3-console` に同梱されている.

[コンソール](/autd3-sdk/guide/console/) の手順で `autd3-console` を入手して起動し, 上部の「Server」タブを開く.
「Start」を押すと実機を列挙し, 同期が取れた時点でクライアントを受け付ける.
機体が見つからない場合や台数が足りない場合は, 揃うまで再試行を続ける.

| 項目 | 内容 |
| --- | --- |
| Devices | 機体の台数. 0 なら見つかった全台 |
| Interface | 実機をつないだ NIC の名前. 空なら自動で探す |
| Port | クライアントが接続するポート. 既定は 44338 |
| Heartbeat / Reply timeout / Lost timeout / Send rate limit | [`UdpOption`](/autd3-sdk/api/basics/transport-option/) の同名の項目 |

「Advanced options」を開くと, 残りの項目も設定できる.

| 項目 | 内容 |
| --- | --- |
| Response timeout / Enumeration timeout / Sync timeout / Send buffer / Timer resolution | [`UdpOption`](/autd3-sdk/api/basics/transport-option/) の同名の項目 |
| Monitor interval | 機体の状態を読み直す間隔. 既定は 1 s |
| Retry interval | 列挙に失敗してからやり直すまでの間隔. 既定は 1 s |

チェックを外した項目と「default」を選んだ項目は既定値になる.

起動中は, 機体ごとの応答・PTP のロック・同期パルスの状態・ファームウェアの版数・PTP のオフセットが表に出る.

## 接続

クライアントは Server と同じホストで動かす必要がある.
接続先に `UdpOption` の代わりに `ServerLink` を渡すこと.

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| フィールド | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `port` | `u16` | 44338 (`SERVER_PORT`) | Server のポート |
| `timeout` | `Duration` | 1 s | 接続を始めてから Server が受け入れるまでの待ち時間. 0 はエラー |

`SERVER_PORT` は Python では `autd3.params.SERVER_PORT`, C# では `ServerLink.ServerPort`.

それ以外の使い方は実機へ直接つなぐ場合と同じ.
