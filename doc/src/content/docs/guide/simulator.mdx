`Simulator` は, AUTD3 の出力音場をブラウザ上で可視化する音場シミュレータ.
実機がなくても, クライアントが送ったデータから生成される音場を確認できる.

## 起動

`Simulator` は GUI コンソール `autd3-console` に同梱されている.

[コンソール](/autd3-sdk/guide/console/) の手順で `autd3-console` を入手して起動し, 上部の「Simulator」タブを開く.

## 接続

クライアントは Simulator と同じホストで動かす必要がある.

Simulator は既定でポート 44336 で待ち受ける. ポートはコンソールの Simulator タブの「UDP port」で変えられる.

クライアントライブラリは Simulator を特別扱いしない. [`TransportOption`](/autd3-sdk/api/basics/transport-option/) の `iface` に `Addr(..)` で Simulator のアドレス `[::1]:44336` を指定してつなぐ (`Auto` は Simulator を探さない).

<CodeTabs
  rust={'let option = TransportOption {\n    iface: Interface::Addr("[::1]:44336".parse()?),\n    ..Default::default()\n};'}
  python={'option = TransportOption(iface=Interface.Addr("[::1]:44336"))'}
  csharp={'var option = new TransportOption { Iface = Interface.Addr("[::1]:44336") };'}
/>

## ジオメトリ

台数・配置は Simulator の画面 (Geometry タブ) で設定する. クライアントからジオメトリを送る手段は無い. クライアントを開く前に, Geometry タブの台数と配置をクライアントのジオメトリに合わせておく.

Geometry タブには, デバイスがデイジーチェーンの順に並ぶ. n 番目のデバイスがクライアントの `geometry[n]` にあたる.

- 「Add device」で末尾にデバイスを足す (最後のデバイスの +x 方向に 1 台分ずらした位置)
- 「Up」「Down」で順番を入れ替え, 「Remove」で削除する
- 各デバイスの原点 (mm) と姿勢 (ZYZ オイラー角, 度) を入力する
- 「Save to file」で今のジオメトリを JSON ファイル (`geometry.json`) に保存し, 「Load from file」で読み込む. 読めないファイル・不正な内容 (台数が 1〜128 でない, 回転が単位四元数でない など) は読み込まず, 理由を表示する

台数がクライアントのジオメトリと違うと `open` は失敗する. 配置がずれていると, クライアントが計算した位相と表示される音場が食い違う.

台数を変えるとデバイスは作り直される (それまでの状態は消える) ので, クライアントを開き直す. 台数を変えずに配置・姿勢・順番だけを変えた場合は, デバイスの状態はそのままで表示だけが新しい配置に追従する (状態は n 番目という位置に付いたままで, 並べ替えたデバイスには付いていかない).
複数のブラウザタブで開いていても, 編集結果は全タブに反映される.

設定したジオメトリは保存され, 次に Simulator を起動したときに復元される (保存先は OS の設定ディレクトリ配下の `autd3-simulator/geometry.json`. 保存が無ければ原点に 1 台).
