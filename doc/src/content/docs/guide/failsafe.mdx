ホストとの通信が途絶えたときや PTP のロックを失ったときに, 自分で出力を止めるフェイルセーフ機能がある.
どちらも既定では無効で, [SetCpuConfig](/autd3-sdk/api/command/cpu-config/) で有効化できる.

## 通信途絶の failsafe と生存確認

`failsafe_timeout` を指定すると, ホストからの通信がその時間途絶えたデバイスは出力を止める.
既定は `None` (無効) で, ホストのクラッシュやケーブル断で通信が途絶えてもデバイスは超音波を止めない.

`Client` は, 送るものが無い間, 自分からはデバイスへ何も送らない.
そのため `failsafe_timeout` を指定した場合, 出力を保ったまま待つ間は [`send_heartbeat()`](/autd3-sdk/api/basics/client/#api) を周期的に呼ぶ必要がある.
`send_heartbeat()` は `failsafe_timeout` より十分短い周期で呼ぶ必要がある.

failsafe で止まった出力は, 自動では戻らない.
止まっているかどうかは `device_status()` が返す `DeviceStatus` の `failsafe_active` で確認でき, [`ReleaseFailsafe`](/autd3-sdk/api/command/release-failsafe/) を送ると再開する ([Clear](/autd3-sdk/api/command/clear/)でも良いが, その場合, すべての状態が初期化される).
