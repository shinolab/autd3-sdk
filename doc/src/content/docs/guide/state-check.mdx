## 状態の取得

`StateChecker::check` は, 呼び出した時点の状態 `DeviceStatus` を返す.
`DeviceStatus` は以下を持つ.

- `devices`: デバイスごとの状態 (`DeviceState`). 正常なら `OP`, 切断されると `LOST` など.
- `all_op`: 全デバイスが `OP` 状態か.
- `any_lost`: いずれかのデバイスが `LOST` 状態か.
- `recoveries`: 切断から自動で復帰した累計回数 (自動復帰しないので常に 0).

各状態の意味は [接続](/autd3-sdk/api/connection/#状態監視) を参照. 同期パルスが動いていれば `OP`, まだ動いていなければ `SAFE-OP`, 返信が途絶えるか機体が再起動すると `LOST` になり, `LOST` からは自動で復帰しない (開き直す).
