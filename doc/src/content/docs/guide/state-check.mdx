## 状態の取得

`StateChecker::check` は, 呼び出した時点の状態 `DeviceStatus` を返す.
`DeviceStatus` は以下を持つ.

- `devices`: デバイスごとの状態 (`DeviceState`). 正常なら `Ready`, 切断されると `Lost` など.
- `all_ready`: 全デバイスが `Ready` 状態か.
- `any_lost`: いずれかのデバイスが `Lost` 状態か.

各状態の意味は [接続](/autd3-sdk/api/connection/#状態監視) を参照. ID 0 に時刻が合っていて同期パルスが動いていれば `Ready`, 時刻を合わせている途中か同期パルスがまだ動いていなければ `Syncing`, 返信が途絶えるか機体が再起動すると `Lost` になり, `Lost` からは自動で復帰しない (開き直す).

`Lost` のデバイスがある間も, 書き込み (`send` など) は残りのデバイスに対して続く. 一方, 全デバイスぶんの値を返す読み出し (`read_firmware_version` / `read_fpga_state` / `read_telemetry`) は `Error::DeviceLost { device }` で失敗する.
