`Emulator` は, 実機なしで AUTD3 の駆動データを記録し, そこから音場をオフライン計算するツールである.
本体とは別のパッケージで提供される (C# 向けのパッケージは提供していない).

<Install rust="autd3-rs-emulator" python="autd3-emulator" />

## 記録

`Emulator::new` に `Geometry` を渡し, `record` 内部でデータを送信し, `tick` で時間を進めると, 送信データが記録された `Record` が得られる.

<CodeTabs rust={excerpt(sample, "record")} python={excerpt(pySample, "record")} />

`tick` に渡す時間は超音波周期 ( 25 us ) の整数倍でなければならない.

出力データは [Polars](https://pola.rs/) の `DataFrame` である.
詳細は Polars のドキュメントを参照されたい.

## 振動子テーブル

`Emulator::transducer_table` は, 全トランスデューサの一覧を `DataFrame` として返す.
各行が 1 トランスデューサで, デバイスインデックス ( `dev_idx` ), デバイス内のローカルインデックス ( `tr_idx` ), 位置 ( `x/y/z[mm]` ), 法線方向 ( `nx/ny/nz` ) が格納される.
後述の駆動データ・出力信号の各行は, このテーブルの行と 1 対 1 で対応している.

## 音場計算

`Record::sound_field` に観測範囲 ( `Range` ) とオプションを渡すと, 音場計算オブジェクトが得られる.
オプションには `RmsRecordOption` ( RMS 音圧 ) と `InstantRecordOption` ( 瞬時音圧 ) の 2 種類がある.

いずれも `observe_points` で観測点座標を, `next` で指定時間分の音場を得られる.
`skip` で計算せずに時間を進められる.

`observe_points` が返す `DataFrame` の各行が観測点で, 音場の `DataFrame` の各行と対応する.

### 観測範囲

`Range` は観測点の集合を表す.
`RangeXY` のように 2 軸を範囲, 残り 1 軸を固定値で指定する平面のほか, 1 軸のみの線 ( `RangeX` 等 ), 3 軸すべての立方体 ( `RangeXYZ` 等 ) がある.
軸の順序 ( `RangeXY` と `RangeYX` 等 ) は観測点の列挙順を決める.
`resolution` は各軸の刻み幅 ( mm ) である.

### GPU バックエンド (Rust 版のみ)

`gpu` feature を有効にすると, 音場計算を GPU で行える.
有効時のみ各オプションに `gpu: bool` フィールドが生え, `true` で GPU を使う ( 既定は `false` ).

```rust
let mut rms = record.sound_field(
    range,
    RmsRecordOption {
        gpu: true,
        ..Default::default()
    },
)?;
```
