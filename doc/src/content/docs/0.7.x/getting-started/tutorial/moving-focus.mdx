## ソフトウェア制御

AUTD3 において, `Pattern` は送信するたびに上書きされる.
したがって, 次のようなコードを実行すると, 約1秒ごとに焦点の位置が移動する.

<CodeTabs rust={"let mut patterns = geometry.pattern_buffer();\nloop {\n    for sign in [1.0_f32, -1.0] {\n        let target = center + offset((sign * 20.0) * mm, 0.0 * mm, 0.0 * mm);\n        autd3_rs_pattern::focus(\n            &geometry,\n            target,\n            wavelength,\n            &autd3_rs_pattern::FocusOption::default(),\n            &mut patterns,\n        );\n        let mut builder = client.datagram_builder();\n        builder.push(Pattern::new(&patterns));\n        for frame in &builder.build()? {\n            client.send_checked(frame).await?;\n        }\n        tokio::time::sleep(Duration::from_secs(1)).await;\n    }\n}"} python={"patterns = geometry.pattern_buffer()\nwhile True:\n    for sign in (1.0, -1.0):\n        target = center + np.array([sign * 20.0, 0.0, 0.0])\n        pattern.focus(\n            geometry,\n            target,\n            wavelength,\n            pattern.FocusOption(),\n            patterns,\n        )\n        builder = client.datagram_builder()\n        builder.push(Pattern(patterns))\n        for frame in builder.build():\n            await client.send_checked(frame)\n        await asyncio.sleep(1.0)"} csharp={"var patterns = geometry.PatternBuffer();\nwhile (true)\n{\n    foreach (var sign in new[] { 1.0f, -1.0f })\n    {\n        var target = center + new Vector3(sign * 20.0f, 0.0f, 0.0f);\n        Pattern.Focus(\n            geometry,\n            target,\n            wavelength,\n            new FocusOption(),\n            patterns\n        );\n        var builder = client.DatagramBuilder();\n        builder.Push(new Pattern(patterns));\n        foreach (var frame in builder.Build())\n        {\n            await client.SendCheckedAsync(frame);\n        }\n        await Task.Delay(TimeSpan.FromSeconds(1));\n    }\n}"} />

上記のコードだとソフトウェア的にタイミングを制御している.
これの精度は OS や実行環境に依存するため, より精度の高い制御が必要な場合は, `FociStm` / `PatternStm` を使用することをおすすめする.

## FociStmによるハードウェア制御

[`FociStm`](/autd3-sdk/0.7.x/api/command/foci-stm/) を使用して上記と同等の動作を実現するコードは以下の通りである.

<CodeTabs rust={"let points = [\n    ControlPoints::from(center + offset(20.0 * mm, 0.0 * mm, 0.0 * mm)),\n    ControlPoints::from(center + offset(-20.0 * mm, 0.0 * mm, 0.0 * mm)),\n];\nlet mut builder = client.datagram_builder();\nbuilder.push(FociStm::new(0.5 * Hz, &points, FociStmOption::default()));\nfor frame in &builder.build()? {\n    client.send_checked(frame).await?;\n}"} python={"points = [\n    ControlPoints([ControlPoint(center + np.array([20.0, 0.0, 0.0]))]),\n    ControlPoints([ControlPoint(center + np.array([-20.0, 0.0, 0.0]))]),\n]\nbuilder = client.datagram_builder()\nbuilder.push(FociStm(0.5 * Hz, points, FociStmOption()))\nfor frame in builder.build():\n    await client.send_checked(frame)"} csharp={"var points = new[]\n{\n    new ControlPoints(new[] { new ControlPoint(center + new Vector3(20.0f, 0.0f, 0.0f)) }),\n    new ControlPoints(new[] { new ControlPoint(center + new Vector3(-20.0f, 0.0f, 0.0f)) }),\n};\nvar builder = client.DatagramBuilder();\nbuilder.Push(new FociStm(0.5f * Hz, points));\nforeach (var frame in builder.Build())\n{\n    await client.SendCheckedAsync(frame);\n}"} />

`FociStm` / `PatternStm` は AUTD3 デバイス内部でループされるため, ソフトウェアループは必要なく, 送信以降自動的に無限ループする.
また, タイミングは AUTD3 デバイス内蔵のタイマーで制御されるため, 精度が高く, 解像度も最高で 25 µs 単位で指定できる.
ただし, このタイマーの制約上, [出力不可能な周波数](/autd3-sdk/0.7.x/api/basics/sampling-config/#制約)が存在する.

`FociStm` / `PatternStm` の切り替えタイミングは, 1 ループの周波数, または周期で指定する.
すなわち, この場合は 2 つの焦点で 0.5 Hz (2 s) となるので, 各焦点は 1 s 出力される.
なお, [`SamplingConfig`](/autd3-sdk/0.7.x/api/basics/sampling-config/) を使用することで, 1 ループあたりではなく, サンプリング周波数, すなわち 1 焦点あたりの周波数や周期を指定することもできる.

焦点に限らず任意の Pattern を切り替えたい場合は, `FociStm` の代わりに[`PatternStm`](/autd3-sdk/0.7.x/api/command/pattern-stm/) を使う.
