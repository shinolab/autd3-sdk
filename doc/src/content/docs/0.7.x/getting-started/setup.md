AUTD3 を使い始めるための準備を, 以下の順に説明する.

* [ハードウェア](/autd3-sdk/0.7.x/getting-started/setup/hardware/): AUTD3 デバイスと PC を接続する.
* [ファームウェア](/autd3-sdk/0.7.x/getting-started/setup/firmware/): デバイスのファームウェアを対応バージョンへ更新する.
* [ソフトウェア](/autd3-sdk/0.7.x/getting-started/setup/software/): SDK ライブラリを依存に追加する.
* [コンソール](/autd3-sdk/0.7.x/getting-started/setup/console/): GUI ツール autd3-console を入手する.
