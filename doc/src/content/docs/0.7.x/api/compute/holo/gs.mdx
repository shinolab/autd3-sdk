gs (Gerchberg-Saxton 法) は, 振動子側と焦点側の振幅制約を交互に課しながら順伝搬と逆伝搬を反復するアルゴリズム.
naive より焦点間の干渉を抑えられるが, 反復回数に応じて計算量が増える.
アルゴリズムは Marzo らの論文 ([Marzo & Drinkwater, 2019](https://doi.org/10.1073/pnas.1813047115)) に基づく.

## API

<CodeTabs rust={"gs(\n    &NalgebraBackend,\n    &geometry,\n    &foci,\n    wavelength,\n    &option,\n    &mut dst,\n)?;"} python={"gs(geometry, foci, wavelength, option, dst)"} csharp={"Holo.Gs(geometry, foci, wavelength, option, dst);"} />

| 引数         | 型                     | 説明                      |
| ------------ | ---------------------- | ------------------------- |
| `geometry`   | `&Geometry`            | デバイス配置              |
| `foci`       | `&[AmplitudeTarget]`      | 焦点列 (位置と目標振幅)   |
| `wavelength` | `Length`               | 波長                      |
| `option`     | `&GsOption`            | 追加オプション (下記参照) |
| `dst`        | `&mut [[Emission; _]]` | 出力バッファ              |

`option` 以外の引数は [Naive](/autd3-sdk/0.7.x/api/compute/holo/naive/) と同一.

## GsOption

<CodeTabs rust={"GsOption {\n    repeat,\n    constraint,\n    directivity,\n    mask,\n    parallel,\n    ..Default::default()\n}"} python={"GsOption(\n    repeat,\n    constraint,\n    directivity,\n    mask,\n    parallel,\n)"} csharp={"new GsOption(\n    repeat,\n    constraint,\n    directivity,\n    mask,\n    parallel\n)"} />

| フィールド    | 型                   | デフォルト                    |
|---------------|----------------------|---------------------------|
| `repeat`      | `NonZeroUsize`       | `100`                     |
| `constraint`  | `EmissionConstraint` | `Clamp(MIN, MAX)`         |
| `directivity` | `Directivity`        | `Sphere`                  |
| `mask`        | `TransducerMask`     | `AllEnabled`              |
| `parallel`    | `bool`               | `true`                    |

`repeat` は反復回数. 大きくするほど品質は向上するが計算時間も増える.
`constraint` / `directivity` / `mask` の意味は [Holo 概要](/autd3-sdk/0.7.x/api/compute/holo/) を参照.

`parallel` は結果の量子化をホスト側で複数スレッドへ分散するかどうか (GPU バックエンドの場合は無視される).
