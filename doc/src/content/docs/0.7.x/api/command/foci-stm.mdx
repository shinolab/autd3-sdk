`FociStm` は, ハードウェアタイマにより単一, 及び, 多焦点音場を切り替える STM 機能を提供する.
[`PatternStm`](/autd3-sdk/0.7.x/api/command/pattern-stm/) と異なり, 焦点しか扱えないが, 1フレームに複数の焦点情報を乗せされるためフレーム数が少なく, レイテンシが小さい.

## API

<CodeTabs rust={"FociStm::new(freq, &points, option);"} python={"FociStm(freq, points, option)"} csharp={"new FociStm(freq, points, option);"} />

| 引数      | 型                       | 説明                                       |
| --------- | ------------------------ | ------------------------------------------ |
| `freq`    | `impl Into<StmConfig>`   | 再生レート (`Freq` / `Duration` / `SamplingConfig`)  |
| `points`  | `&[ControlPoints<N>]`    | 焦点サンプルの列 (2 サンプル以上)          |
| `option`  | `FociStmOption`          | 音速・ループ・遷移などのオプション         |

`freq` に `Freq` / `Duration` を渡すと「全サンプルを 1 周する周波数/周期」を表す.
サンプリング周波数を指定することもできる.
`Duration` がサンプル数で割り切れない場合はエラーになる (丸めたいときは `Nearest` を使う).

## ControlPoint / ControlPoints

1 サンプルは `ControlPoints<N>` で表される. `N` は同時に出す焦点の数 (最大 8) である.

* `ControlPoint { point, phase_offset }` — 焦点座標 \[mm] と位相オフセット.
* `ControlPoints<N> { points: [ControlPoint; N], intensity }` — `N` 個の焦点と振幅.

## FociStmOption

<CodeTabs rust={"FociStmOption {\n    bank,\n    sound_speed,\n    loop_behavior,\n    transition_mode,\n    ..Default::default()\n}"} python={"FociStmOption(\n    bank,\n    sound_speed,\n    loop_behavior,\n    transition_mode,\n)"} csharp={"new FociStmOption(\n    bank,\n    soundSpeed,\n    loopBehavior,\n    transitionMode\n)"} />

| フィールド        | 型               | デフォルト                 | 説明                                   |
| ----------------- | ---------------- | -------------------------- | -------------------------------------- |
| `bank`            | `PatternBank`    | `PatternBank::B0`          | 書き込み先・再生対象のバンク           |
| `sound_speed`     | `Velocity`       | `340 m/s`                  | 焦点計算に使う音速                     |
| `loop_behavior`   | `LoopBehavior`   | `LoopBehavior::Infinite`   | ループ回数                             |
| `transition_mode` | `TransitionMode` | `TransitionMode::Immediate` | バンク切替時の遷移タイミング           |

`loop_behavior` と `transition_mode` の挙動は[再生制御](/autd3-sdk/0.7.x/api/command/lowlevel/change-pattern-bank/) を参照.

## ヘルパ関数

典型的な軌道を生成するヘルパ関数が用意されている.

### circle

<CodeTabs rust={"circle(center, radius, num_points, normal, intensity, &mut dst);"} python={"circle(center, radius, num_points, normal, intensity, dst)"} csharp={"Stm.Circle(center, radius, numPoints, normal, intensity, dst);"} />

| 引数         | 型                           | 説明                        |
| ------------ | ---------------------------- | --------------------------- |
| `center`     | `Point3<f32>`                | 円の中心 \[mm]               |
| `radius`     | `Length`                     | 円の半径                    |
| `num_points` | `usize`                      | 生成する点の数              |
| `normal`     | `UnitVector3<f32>`           | 円平面の法線 (単位ベクトル) |
| `intensity`  | `Intensity`                  | 各点の振幅                  |
| `dst`        | `&mut Vec<ControlPoints<1>>` | 出力バッファ                |

`normal` を法線とする円周上に等間隔で `num_points` 個の点を並べる.

### line

<CodeTabs rust={"line(start, end, num_points, intensity, &mut dst);"} python={"line(start, end, num_points, intensity, dst)"} csharp={"Stm.Line(start, end, numPoints, intensity, dst);"} />

| 引数         | 型                           | 説明           |
| ------------ | ---------------------------- | -------------- |
| `start`      | `Point3<f32>`                | 始点 \[mm]      |
| `end`        | `Point3<f32>`                | 終点 \[mm]      |
| `num_points` | `usize`                      | 生成する点の数 |
| `intensity`  | `Intensity`                  | 各点の振幅     |
| `dst`        | `&mut Vec<ControlPoints<1>>` | 出力バッファ   |

始点・終点を含む等間隔の直線上に `num_points` 個の点を並べる.

## 等価な低レベルコマンド

`FociStm` は [WriteFociBuffer](/autd3-sdk/0.7.x/api/command/lowlevel/write-foci-buffer/) + [ConfigFociStm](/autd3-sdk/0.7.x/api/command/lowlevel/config-foci-stm/) + [ChangePatternBank](/autd3-sdk/0.7.x/api/command/lowlevel/change-pattern-bank/) の 3 つと等価である. データが 1 フレームに収まる場合は融合して 1 フレームで送られ, 収まらない場合は上記の 3 コマンドに展開される.
以下は `FociStm::new(freq, &points, option)` と等価な組み合わせである.

<CodeTabs rust={"WriteFociBuffer {\n    bank: option.bank,\n    index_offset: 0,\n    points: &points,\n};\nConfigFociStm {\n    bank: option.bank,\n    config: StmConfig::new(freq).into_sampling_config(points.len()),\n    size: points.len(),\n    num_foci: N, // N is the number of foci in the points\n    sound_speed: option.sound_speed,\n    loop_behavior: option.loop_behavior,\n};\nChangePatternBank {\n    bank: option.bank,\n    transition_mode: option.transition_mode,\n};"} python={"WriteFociBuffer(\n    bank=option.bank,\n    index_offset=0,\n    points=points,\n)\nConfigFociStm(\n    bank=option.bank,\n    config=StmConfig(freq).into_sampling_config(len(points)),\n    size=len(points),\n    num_foci=num_foci,\n    sound_speed=option.sound_speed,\n    loop_behavior=option.loop_behavior,\n)\nChangePatternBank(\n    bank=option.bank,\n    transition_mode=option.transition_mode,\n)"} csharp={"new WriteFociBuffer(\n    bank: option.Bank,\n    indexOffset: 0,\n    points: points\n);\nnew ConfigFociStm(\n    bank: option.Bank,\n    config: new StmConfig(freq).IntoSamplingConfig(points.Length),\n    size: (uint)points.Length,\n    numFoci: numFoci,\n    soundSpeed: option.SoundSpeed,\n    loopBehavior: option.LoopBehavior\n);\nnew ChangePatternBank(\n    bank: option.Bank,\n    transitionMode: option.TransitionMode\n);"} />
