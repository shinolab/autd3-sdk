:::note
`Controller` / `Driver` は Rust のみで提供される.
:::

`Controller` と `Driver` は, [`Client`](/autd3-sdk/0.13.x/api/basics/client/) の中身を自分で駆動するためのパーツ.

`Client` は, 返信の受信を行う I/O スレッドを内部に 1 本持つ.
このスレッドの代わりに, 送受信ループを自前のスレッドなどで回したい場合に `Controller` / `Driver` を使う.

## Open

`Controller::open` は `Controller` と `Driver` のタプルを返す.
引数は `Client::open` と同じ.

<CodeTabs rust={"let (controller, driver) = Controller::open(geometry, option)?;\nlet driving = std::thread::spawn(move || driver.run());\n\ncontroller.send(Clear).await?;\n\ncontroller.send(Synchronize).await?;\ncontroller.send(SetSilencer::default()).await?;\ncontroller.close()?;\n\ndriving.join().unwrap()?;"} />

## Driver

`Driver` は以下のメソッドを持つ.

| メソッド         | 返り値                           | 説明                                                             |
| ---------------- | -------------------------------- | ---------------------------------------------------------------- |
| `run(self)`      | `Result<(), Error>`              | `Controller` が閉じるまで `poll` と `wait` を繰り返す. ブロッキング. |
| `poll(&mut self)` | `Result<Option<Instant>, Error>` | 届いている返信と期限の来た処理を済ませ, 次に呼ぶべき期限を返す. ノンブロッキング. |
| `wait(&mut self, deadline)` | `Result<(), Error>`   | 返信が届くか `deadline` になるまでスレッドをブロックする           |

### poll / wait

`run` は以下のループと同じである.
ループの中に自分の処理を挟みたい場合は, `poll` と `wait` を直接呼ぶ.

<CodeTabs rust={"fn drive(mut driver: Driver) -> Result<(), Error> {\n    while let Some(deadline) = driver.poll()? {\n        driver.wait(deadline)?;\n    }\n    Ok(())\n}"} />

`poll` の返り値の意味は以下の通り.

* `Ok(Some(deadline))`: 次に `poll` を呼ぶべき期限
* `Ok(None)`: `Controller` が閉じた (`close` または Drop)
* `Err(..)`: 通信エラー

### 非同期

`Driver` は Unix 系では `AsFd`, Windows では `AsSocket` を実装してある.
以下は tokio の `AsyncFd` を使いシングルスレッドの tokio ランタイム (`current_thread`) で動かす例 (Unix).

<CodeTabs rust={"#[cfg(unix)]\nasync fn drive_on_reactor(mut driver: Driver) -> Result<()> {\n    use std::os::fd::{AsFd, AsRawFd};\n    use tokio::io::Interest;\n    use tokio::io::unix::AsyncFd;\n\n    let socket = unsafe {\n        AsyncFd::register_with_interest(driver.as_fd().as_raw_fd(), Interest::READABLE)?\n    };\n    while let Some(deadline) = driver.poll()? {\n        tokio::select! {\n            readable = socket.readable() => readable?.clear_ready(),\n            () = tokio::time::sleep_until(deadline.into()) => {}\n        }\n    }\n    Ok(())\n}\n\nlet (controller, driver) = Controller::open(geometry, option)?;\nlet driving = tokio::spawn(drive_on_reactor(driver));\n\ncontroller.send(Clear).await?;\n\ncontroller.send(Synchronize).await?;\ncontroller.send(SetSilencer::default()).await?;\ncontroller.close()?;\n\ndriving.await??;"} />

:::caution
シングルスレッドで動かす場合, 以下の間はそのスレッドがブロックされ, 他のタスクも進まない.

* `Controller::open` (デバイスの列挙と同期の待ち)
* ソケットの送信バッファが空くのを待つ間
:::

リアクタを使わない場合は, 短い周期で `poll` を呼ぶ.

<CodeTabs rust={"while driver.poll()?.is_some() {\n    tokio::time::sleep(POLL_INTERVAL).await;\n}"} />
