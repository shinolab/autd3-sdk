単一焦点, 平面波, ベッセルビーム, ラゲール・ガウシアンビーム, エルミート・ガウシアンビームなど, 代表的な音場計算ユーティリティ.

<Install rust="autd3-rs-pattern" python="autd3-pattern" csharp="AUTD3.Pattern" />

## 関数一覧

* [focus](/autd3-sdk/0.13.x/api/compute/pattern/focus/) — 単一焦点
* [plane](/autd3-sdk/0.13.x/api/compute/pattern/plane/) — 平面波
* [bessel](/autd3-sdk/0.13.x/api/compute/pattern/bessel/) — ベッセルビーム
* [laguerre\_gaussian\_phase / laguerre\_gaussian\_intensity](/autd3-sdk/0.13.x/api/compute/pattern/laguerre-gaussian/) — ラゲール・ガウシアンビームの位相・振幅
* [hermite\_gaussian\_phase / hermite\_gaussian\_intensity](/autd3-sdk/0.13.x/api/compute/pattern/hermite-gaussian/) — エルミート・ガウシアンビームの位相・振幅

`focus` / `plane` / `bessel` / `laguerre_gaussian_phase` / `hermite_gaussian_phase` には, 振動子 1 素子分の位相を返す `*_transducer` 版もある (例: `focus_transducer`).
`laguerre_gaussian_intensity` / `hermite_gaussian_intensity` には振動子単位の版は無い.

## 波長

位相計算には波長 <Math tex="\lambda = c / f" /> が必要になる.
音速 <Math tex="c" /> から `autd3_rs_pattern::wavelength(sound_speed)` (Python: `autd3_pattern.wavelength`, C#: `Pattern.Wavelength`) で波長を求められる.
音速 340 m/s (室温約15℃の空気中での音速) では<Math tex="\lambda = 8.5\,\mathrm{mm}" />.
