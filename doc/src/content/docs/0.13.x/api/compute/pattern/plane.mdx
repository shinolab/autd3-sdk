`plane` は指定方向に伝搬する平面波を生成する.

<PatternField kind="plane" />

## API

<CodeTabs rust={"plane(&geometry, direction, wavelength, &mut phases);"} python={"plane(geometry, direction, wavelength, phases)"} csharp={"Pattern.Plane(geometry, direction, wavelength, phases);"} />

| 引数         | 型                     | 説明                            |
| ------------ | ---------------------- | ------------------------------- |
| `geometry`   | `&Geometry`            | デバイス配置                    |
| `direction`  | `UnitVector3<f32>`     | 平面波の伝搬方向 (単位ベクトル) |
| `wavelength` | `Length`               | 波長                            |
| `dst`        | `&mut [Vec<Phase>]` | 出力バッファ                    |

<CodeTabs rust={"use autd3_rs::geometry::{Autd3, Geometry, Vector3};\nuse autd3_rs::units::{m, s};\nuse autd3_rs_pattern::{plane, wavelength};\n\nlet geometry = Geometry::new(vec![Autd3::default()]);\n\nlet mut phases = geometry.phase_buffer();\n\nplane(\n    &geometry,\n    Vector3::z_axis(),\n    wavelength(340.0 * m / s),\n    &mut phases,\n);"} python={"import numpy as np\nfrom autd3.geometry import Autd3, Geometry\nfrom autd3.units import m, s\nfrom autd3_pattern import plane, wavelength\n\ngeometry = Geometry([Autd3()])\n\nphases = geometry.phase_buffer()\n\nplane(\n    geometry,\n    np.array([0.0, 0.0, 1.0]),\n    wavelength(340 * m / s),\n    phases,\n)"} csharp={"using System.Numerics;\nusing AUTD3;\nusing static AUTD3.Units;\n\nvar geometry = new Geometry(new[] { new Autd3() });\n\nvar phases = geometry.PhaseBuffer();\n\nPattern.Plane(\n    geometry,\n    Vector3.UnitZ,\n    Pattern.Wavelength(340.0f * m / s),\n    phases\n);"} />
