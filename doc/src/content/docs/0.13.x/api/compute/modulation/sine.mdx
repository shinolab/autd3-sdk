`sine` は正弦波の振幅変調を生成する.

<ModulationPlot fixed="freq = 200 Hz (clamp = true)" />

## API

<CodeTabs rust={"sine(freq, &option, sampling_config, &mut dst)?;"} python={"sine(freq, option, sampling_config, dst)"} csharp={"Modulation.Sine(freq, option, samplingConfig, dst);"} />

| 引数      | 型             | 説明                                         |
| --------- | -------------- | -------------------------------------------- |
| `freq`    | `Freq` 等      | 変調周波数                                   |
| `option`  | `&SineOption`  | 追加オプション (下記参照)                    |
| `config`  | `SamplingConfig` | サンプリング設定 ([Modulation](/autd3-sdk/0.13.x/api/compute/modulation/#samplingconfig) 参照) |
| `dst`     | `&mut Vec<u8>` | 出力バッファ                                 |

各サンプル <Math tex="i" /> の値は, 振幅 <Math tex="A" />（`amplitude`）, オフセット <Math tex="b" />（`offset`）, 位相 <Math tex="\theta" />（`phase`）に対して次式で与えられる.

<MathBlock tex="m_i = \frac{A}{2}\sin\!\left(2\pi f t_i + \theta\right) + b" />

`freq` は `Freq` (`150 * Hz` や `150.0 * Hz`) で指定する. `150 * Hz` と `150.0 * Hz` は同じ周波数を表す.

## SineOption

<CodeTabs rust={"SineOption {\n    amplitude,\n    offset,\n    phase,\n    clamp,\n    ..Default::default()\n}"} python={"SineOption(\n    amplitude,\n    offset,\n    phase,\n    clamp,\n)"} csharp={"new SineOption\n{\n    Amplitude = amplitude,\n    Offset = offset,\n    Phase = phase,\n    Clamp = clamp,\n}"} />

| フィールド        | 型               | デフォルト              | 説明                                                     |
| ----------------- | ---------------- | ----------------------- | -------------------------------------------------------- |
| `amplitude`       | `u8`             | `0xFF`                  | 正弦波の振幅                                             |
| `offset`          | `u8`             | `0x80`                  | 直流オフセット                                           |
| `phase`           | `Angle`          | `Angle::ZERO`           | 位相                                                     |
| `clamp`           | `bool`           | `false`                 | 範囲外の値を \[0, 255] に clamp するか                        |

`amplitude` と `offset` の組み合わせで波形が \[0, 255] の範囲を外れる場合, `clamp` が `false` だとエラーになる.
範囲内に収まるよう値を選ぶか, `clamp` を `true` にする.

## 制約

[SamplingConfigの制約](/autd3-sdk/0.13.x/api/basics/sampling-config/)により, 指定した周波数が表現可能な周波数でない場合がある.
`freq` は周期内に整数個のサンプルで表せる周波数でなければならず, そうでない場合はエラーになる.
