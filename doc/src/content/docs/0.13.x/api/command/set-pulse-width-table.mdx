`SetPulseWidthTable` は, 強度 (0–255) から PWM のパルス幅への変換テーブルを設定するコマンド.

## API

<CodeTabs rust={"SetPulseWidthTable { table };"} python={"SetPulseWidthTable(table)"} csharp={"new SetPulseWidthTable(table);"} />

| フィールド | 型                      | 説明                                                 |
| ---------- | ----------------------- | ---------------------------------------------------- |
| `table`    | `[PulseWidth; PWE_TABLE_SIZE]` | 強度インデックス (0–255) ごとのパルス幅 (256 要素) |

`PulseWidth` は `PulseWidth::new(u16)` (1 周期 512 刻みのパルス幅) か `PulseWidth::from_duty(f32)` (デューティ比) で作る.

デフォルトのコマンドは arcsin 形状のテーブルを設定する.
これは出力音圧が強度に対して (理論的に) 線形になるようなテーブルであり, デバイスが起動時に持つテーブルと同じである.

<CodeTabs rust={"SetPulseWidthTable::default();"} python={"SetPulseWidthTable()"} csharp={"new SetPulseWidthTable();"} />

`empty_table` は全要素が 0 のテーブルを返す.

<CodeTabs rust={"let table = SetPulseWidthTable::empty_table();"} python={"table = SetPulseWidthTable.empty_table()"} csharp={"var table = SetPulseWidthTable.EmptyTable();"} />
