`SetFpgaConfig` は, FPGA の設定を変更するコマンド.

## API

<CodeTabs rust={"let config = FpgaConfig {\n    sync_phase_lock,\n};\nSetFpgaConfig::new(config);"} python={"config = FpgaConfig(\n    sync_phase_lock=sync_phase_lock,\n)\nSetFpgaConfig(config)"} csharp={"var config = new FpgaConfig\n{\n    SyncPhaseLock = syncPhaseLock,\n};\nnew SetFpgaConfig(config);"} />

### FpgaConfig

| フィールド        | 型     | 既定値 | 説明 |
| ----------------- | ------ | ------ | ---- |
| `sync_phase_lock` | `bool` | `true` | FPGA の動作クロックをデバイス間の同期パルスへ位相ロックする細調整. (既定で有効になっている.) |

## Example

<CodeTabs rust={"use autd3_rs::commands::{Clear, FpgaConfig, SetFpgaConfig, Synchronize};\nuse autd3_rs::geometry::{Autd3, Geometry};\nuse autd3_rs::Client;\nuse autd3_rs::udp::TransportOption;\n\nlet geometry = Geometry::new(vec![Autd3::default()]);\nlet option = TransportOption::default();\nlet client = Client::open(&geometry, &option)?;\nclient.send(Clear).await?;\nclient.send(Synchronize).await?;\n\nclient.send(SetFpgaConfig::new(FpgaConfig {\n    sync_phase_lock: false,\n})).await?;\n\nclient.send(SetFpgaConfig::default()).await?;\n\nclient.close()?;"} python={"import asyncio\n\nfrom autd3 import Client, TransportOption\nfrom autd3.commands import Clear, FpgaConfig, SetFpgaConfig, Synchronize\nfrom autd3.geometry import Autd3, Geometry\n\n\nasync def main() -> None:\n    geometry = Geometry([Autd3()])\n    with Client.open(geometry, TransportOption()) as client:\n        await client.send(Clear())\n        await client.send(Synchronize())\n\n        await client.send(SetFpgaConfig(FpgaConfig(sync_phase_lock=False)))\n\n        await client.send(SetFpgaConfig())\n\n\nasyncio.run(main())"} csharp={"using System.Threading.Tasks;\nusing AUTD3;\n\nvar geometry = new Geometry(new[] { new Autd3() });\nusing var client = Client.Open(geometry, new TransportOption());\nawait client.SendAsync(new Clear());\nawait client.SendAsync(new Synchronize());\n\nawait client.SendAsync(new SetFpgaConfig(new FpgaConfig { SyncPhaseLock = false }));\n\nawait client.SendAsync(new SetFpgaConfig());"} />
