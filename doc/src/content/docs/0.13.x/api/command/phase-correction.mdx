`SetPhaseCorrection` は, 各振動子へ加える位相オフセットを設定するコマンド.
ここで設定したオフセットは以降のすべての出力位相へ加算される.

## API

<CodeTabs rust={"SetPhaseCorrection { phases };"} python={"SetPhaseCorrection(phases)"} csharp={"new SetPhaseCorrection(phases);"} />

| フィールド | 型              | 説明                                                                                     |
| ---------- | --------------- | ---------------------------------------------------------------------------------------- |
| `phases`   | `Vec<Vec<Phase>>` | デバイスごとの位相オフセット表. |

## Example

<CodeTabs rust={"use autd3_rs::commands::{Clear, SetPhaseCorrection, Synchronize};\nuse autd3_rs::geometry::{Autd3, Geometry};\nuse autd3_rs::Client;\nuse autd3_rs::udp::TransportOption;\n\nlet geometry = Geometry::new(vec![Autd3::default()]);\nlet option = TransportOption::default();\nlet client = Client::open(&geometry, &option)?;\nclient.send(Clear).await?;\nclient.send(Synchronize).await?;\n\nlet phases = geometry.phase_buffer();\n\nclient.send(SetPhaseCorrection { phases }).await?;\n\nclient.close()?;"} python={"import asyncio\n\nfrom autd3 import Client, TransportOption\nfrom autd3.commands import Clear, SetPhaseCorrection, Synchronize\nfrom autd3.geometry import Autd3, Geometry\n\n\nasync def main() -> None:\n    geometry = Geometry([Autd3()])\n    with Client.open(geometry, TransportOption()) as client:\n        await client.send(Clear())\n        await client.send(Synchronize())\n\n        phases = geometry.phase_buffer()\n\n        await client.send(SetPhaseCorrection(phases))\n\n\nasyncio.run(main())"} csharp={"using System.Threading.Tasks;\nusing AUTD3;\n\nvar geometry = new Geometry(new[] { new Autd3() });\nusing var client = Client.Open(geometry, new TransportOption());\nawait client.SendAsync(new Clear());\nawait client.SendAsync(new Synchronize());\n\nusing var phases = geometry.PhaseBuffer();\n\nawait client.SendAsync(new SetPhaseCorrection(phases));"} />
