`PatternStm` は, ハードウェアタイマにより任意の音場 (各振動子の位相・振幅) を切り替える STM 機能を提供する.
[FociStm](/autd3-sdk/0.13.x/api/command/foci-stm/) と異なり, 任意の Pattern を扱えるが, 転送データ量が多い (=レイテンシが大きい).

## API

<CodeTabs rust={"PatternStm::new(config, &patterns, intensities, option);"} python={"PatternStm(config, patterns, intensities, option)"} csharp={"new PatternStm(config, patterns, intensities, option);"} />

| 引数       | 型                                    | 説明                                                 |
| ---------- | ------------------------------------- | ---------------------------------------------------- |
| `config`   | `SamplingConfig`                      | サンプル毎のサンプリング設定                         |
| `phases`      | `&[Vec<Vec<Phase>>]`     | 各サンプルの位相の列 (2 サンプル以上)                |
| `intensities` | `impl Into<StmIntensity>` | 全サンプルの振幅 (一様値 / 全 index 共通バッファ / index 毎のバッファ列) |
| `option`   | `PatternStmOption`                    | 位相のビット幅・ループ・遷移などのオプション         |

`config` は 1 サンプルあたりのサンプリング設定である.

`intensities` には以下の3つの型が渡せる.

* `Intensity` : 全デバイス・全振動子・全indexで同じ値を使う場合
* `&[Vec<Intensity>]` : 振動子ごとには異なるが全indexで共通の値を使う場合
* `&[Vec<Vec<Intensity>>]` : 全indexごとに異なる値を使う場合

## PatternStmOption

<CodeTabs rust={"PatternStmOption {\n    bank,\n    phase_depth,\n    loop_behavior,\n    transition_mode,\n    ..Default::default()\n}"} python={"PatternStmOption(\n    bank,\n    phase_depth,\n    loop_behavior,\n    transition_mode,\n)"} csharp={"new PatternStmOption\n{\n    Bank = bank,\n    PhaseDepth = phaseDepth,\n    LoopBehavior = loopBehavior,\n    TransitionMode = transitionMode,\n}"} />

| フィールド        | 型               | デフォルト                           | 説明                         |
| ----------------- | ---------------- | ------------------------------------ | ---------------------------- |
| `bank`            | `PatternBank`    | `PatternBank::B0`                    | 書き込み先・再生対象のバンク |
| `phase_depth`     | `PhaseDepth`     | `PhaseDepth::Bits8`                  | 位相のビット幅               |
| `loop_behavior`   | `LoopBehavior`   | `LoopBehavior::Infinite`             | ループ回数                   |
| `transition_mode` | `TransitionMode` | `TransitionMode::Immediate`          | バンク切替時の遷移タイミング |

`loop_behavior` と `transition_mode` の挙動は[再生制御](/autd3-sdk/0.13.x/api/command/lowlevel/activate-pattern-bank/) を参照.

## 転送形式

| `intensities`                                 | `PhaseDepth::Bits8`                          | `PhaseDepth::Bits4`                          |
| --------------------------------------------- | -------------------------------------------- | -------------------------------------------- |
| `Intensity`                                   | `WritePatternPhase` (5 index/フレーム)       | `WritePatternPhase` (11 index/フレーム)      |
| `&[Vec<Intensity>]` / `&[Vec<Vec<Intensity>>]` | `WritePatternBuffer` (2 index/フレーム)      | エラー                                       |

`Bits4` は位相を上位 4 bit に量子化する.

## 等価な低レベルコマンド

`PatternStm` は内部で [WritePatternPhase](/autd3-sdk/0.13.x/api/command/lowlevel/write-pattern-phase/) または [WritePatternBuffer](/autd3-sdk/0.13.x/api/command/lowlevel/write-pattern-buffer/) + [ConfigPattern](/autd3-sdk/0.13.x/api/command/lowlevel/config-pattern/) + [ActivatePatternBank](/autd3-sdk/0.13.x/api/command/lowlevel/activate-pattern-bank/) の 3 つへ展開される.
以下は `intensities` が一様値のときの `PatternStm::new(config, &phases, intensities, option)` と等価な組み合わせである.
`intensities` が振動子ごとの値のときは `WritePatternPhase` の代わりに `WritePatternBuffer` が 2 index ずつ使われる.

<CodeTabs rust={"let max_count = option.phase_depth.max_count();\nfor (k, chunk) in patterns.chunks(max_count).enumerate() {\n    WritePatternPhase {\n        bank: option.bank,\n        start_index: k * max_count,\n        depth: option.phase_depth,\n        intensity: intensities,\n        patterns: chunk,\n    };\n}\nConfigPattern {\n    bank: option.bank,\n    config,\n    size: patterns.len(),\n    loop_behavior: option.loop_behavior,\n};\nActivatePatternBank {\n    bank: option.bank,\n    transition_mode: option.transition_mode,\n};"} python={"max_count = option.phase_depth.max_count()\nfor start_index in range(0, len(patterns), max_count):\n    WritePatternPhase(\n        bank=option.bank,\n        start_index=start_index,\n        depth=option.phase_depth,\n        intensity=intensities,\n        patterns=patterns[start_index : start_index + max_count],\n    )\nConfigPattern(\n    bank=option.bank,\n    config=config,\n    size=len(patterns),\n    loop_behavior=option.loop_behavior,\n)\nActivatePatternBank(\n    bank=option.bank,\n    transition_mode=option.transition_mode,\n)"} csharp={"var maxCount = option.PhaseDepth.MaxCount();\nfor (var startIndex = 0; startIndex < patterns.Length; startIndex += maxCount)\n{\n    new WritePatternPhase(\n        bank: option.Bank,\n        startIndex: (ushort)startIndex,\n        depth: option.PhaseDepth,\n        intensity: intensities,\n        patterns: patterns[startIndex..Math.Min(startIndex + maxCount, patterns.Length)]\n    );\n}\nnew ConfigPattern(\n    bank: option.Bank,\n    config: config,\n    size: (uint)patterns.Length,\n    loopBehavior: option.LoopBehavior\n);\nnew ActivatePatternBank(\n    bank: option.Bank,\n    transitionMode: option.TransitionMode\n);"} />
