`WritePatternBuffer` は, 指定したバンクの `start_index` から連続するインデックスへ Pattern (各振動子の位相と振幅) を書き込む低レベルコマンド.
1 フレームに書ける Pattern は `WritePatternBuffer::MAX_LEN` (2).
それより多く書くときは分けて送る.

## API

<CodeTabs rust={"WritePatternBuffer::new(bank, start_index, patterns, intensities);"} python={"WritePatternBuffer(\n    bank=bank,\n    start_index=start_index,\n    patterns=patterns,\n    intensities=intensities,\n)"} csharp={"new WritePatternBuffer(\n    bank: bank,\n    startIndex: startIndex,\n    patterns: patterns,\n    intensities: intensities\n);"} />

| フィールド  | 型                               | 説明                             |
| ----------- | -------------------------------- | -------------------------------- |
| `bank`      | `PatternBank`                    | 書き込み先バンク                 |
| `start_index` | `usize`                        | バンク内の書き込み先の先頭インデックス |
| `patterns`    | `&[Vec<Vec<Phase>>]`           | インデックスごとの, デバイスごとの位相 |
| `intensities` | `StmIntensity`                 | 振幅 ([PatternStm](/autd3-sdk/0.13.x/api/command/pattern-stm/) と同じ.) |

## Example

以下は `WritePatternBuffer` → `ConfigPattern` → `ActivatePatternBank` で 1 つの Pattern を再生する例 (高レベルの [Pattern](/autd3-sdk/0.13.x/api/command/pattern/) と等価).
