`WriteFociBuffer` は, Foci STM 用の焦点列をバンクへ書き込む低レベルコマンド.

## API

<CodeTabs rust={"WriteFociBuffer {\n    bank,\n    start_index,\n    points,\n};"} python={"WriteFociBuffer(\n    bank=bank,\n    start_index=start_index,\n    points=points,\n)"} csharp={"new WriteFociBuffer(\n    bank: bank,\n    startIndex: startIndex,\n    points: points\n);"} />

| フィールド     | 型                    | 説明                               |
| -------------- | --------------------- | ---------------------------------- |
| `bank`         | `PatternBank`         | 書き込み先バンク                   |
| `start_index` | `usize`               | バンク内の書き込み開始インデックス |
| `points`       | `&[ControlPoints]`    | 焦点サンプルの列                   |

`ControlPoints` は焦点 (`ControlPoint`) の列と振幅を持つ 1 サンプル. 焦点数は全サンプルで揃える.
詳細は [FociStm](/autd3-sdk/0.13.x/api/command/foci-stm/#controlpoint--controlpoints) を参照.

`WriteFociBuffer` は1 フレームに収まる分しか書けない.
上限 (`ControlPoints` の数) は焦点数で変わり, `WriteFociBuffer::max_len(num_foci)`で, 超えると送信時にエラーになる.

## Example

`WriteFociBuffer` → `ConfigFociStm` → `ActivatePatternBank` で焦点列を Foci STM として再生する例 (高レベルの [FociStm](/autd3-sdk/0.13.x/api/command/foci-stm/) と等価). 200 点は 1 フレームに収まらないので分割して書き込む.
