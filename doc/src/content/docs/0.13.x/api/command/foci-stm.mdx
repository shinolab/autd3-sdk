`FociStm` は, ハードウェアタイマにより単一, 及び, 多焦点音場を切り替える STM 機能を提供する.
[`PatternStm`](/autd3-sdk/0.13.x/api/command/pattern-stm/) と異なり, 焦点しか扱えないが, 転送データ量が少なく, レイテンシが小さい.

## API

<CodeTabs rust={"FociStm::new(config, &points, option);"} python={"FociStm(config, points, option)"} csharp={"new FociStm(config, points, option);"} />

| 引数      | 型                       | 説明                                       |
| --------- | ------------------------ | ------------------------------------------ |
| `config`  | `SamplingConfig`         | サンプル毎のサンプリング設定                        |
| `points`  | `&[ControlPoints]`       | 焦点サンプルの列 (2 サンプル以上)          |
| `option`  | `FociStmOption`          | 音速・ループ・遷移などのオプション         |

`config` は 1 サンプルあたりのサンプリング設定である. 「全サンプルを 1 周する周波数」から決めたいときは, 周波数にサンプル数を掛けて `SamplingConfig` を作る (例: 200 サンプルを 1 Hz で回すなら 200 Hz).

## ControlPoint / ControlPoints

1 サンプルは `ControlPoints` で表される. `points` の長さが同時に出す焦点の数 (1 以上 8 以下) で, 全サンプルで揃っていなければならない (揃っていないと送信時にエラーになる).

* `ControlPoint { point, phase_offset }` — 焦点座標 \[mm] と位相オフセット.
* `ControlPoints { points: Vec<ControlPoint>, intensity }` — 焦点の列と振幅.

## FociStmOption

<CodeTabs rust={"FociStmOption {\n    bank,\n    sound_speed,\n    loop_behavior,\n    transition_mode,\n    ..Default::default()\n}"} python={"FociStmOption(\n    bank,\n    sound_speed,\n    loop_behavior,\n    transition_mode,\n)"} csharp={"new FociStmOption\n{\n    Bank = bank,\n    SoundSpeed = soundSpeed,\n    LoopBehavior = loopBehavior,\n    TransitionMode = transitionMode,\n}"} />

| フィールド        | 型               | デフォルト                 | 説明                                   |
| ----------------- | ---------------- | -------------------------- | -------------------------------------- |
| `bank`            | `PatternBank`    | `PatternBank::B0`          | 書き込み先・再生対象のバンク           |
| `sound_speed`     | `Velocity`       | `340 m/s`                  | 焦点計算に使う音速                     |
| `loop_behavior`   | `LoopBehavior`   | `LoopBehavior::Infinite`   | ループ回数                             |
| `transition_mode` | `TransitionMode` | `TransitionMode::Immediate` | バンク切替時の遷移タイミング           |

`loop_behavior` と `transition_mode` の挙動は[再生制御](/autd3-sdk/0.13.x/api/command/lowlevel/activate-pattern-bank/) を参照.

## 等価な低レベルコマンド

`FociStm` は [WriteFociBuffer](/autd3-sdk/0.13.x/api/command/lowlevel/write-foci-buffer/) + [ConfigFociStm](/autd3-sdk/0.13.x/api/command/lowlevel/config-foci-stm/) + [ActivatePatternBank](/autd3-sdk/0.13.x/api/command/lowlevel/activate-pattern-bank/) の 3 つと等価である.
以下は `FociStm::new(config, &points, option)` と等価な組み合わせである.

<CodeTabs rust={"let max_len = WriteFociBuffer::max_len(num_foci);\nfor (i, chunk) in points.chunks(max_len).enumerate() {\n    WriteFociBuffer {\n        bank: option.bank,\n        start_index: i * max_len,\n        points: chunk,\n    };\n}\nConfigFociStm {\n    bank: option.bank,\n    config,\n    size: points.len(),\n    num_foci,\n    sound_speed: option.sound_speed,\n    loop_behavior: option.loop_behavior,\n};\nActivatePatternBank {\n    bank: option.bank,\n    transition_mode: option.transition_mode,\n};"} python={"max_len = WriteFociBuffer.max_len(num_foci)\nfor start_index in range(0, len(points), max_len):\n    WriteFociBuffer(\n        bank=option.bank,\n        start_index=start_index,\n        points=points[start_index : start_index + max_len],\n    )\nConfigFociStm(\n    bank=option.bank,\n    config=config,\n    size=len(points),\n    num_foci=num_foci,\n    sound_speed=option.sound_speed,\n    loop_behavior=option.loop_behavior,\n)\nActivatePatternBank(\n    bank=option.bank,\n    transition_mode=option.transition_mode,\n)"} csharp={"var maxLen = WriteFociBuffer.MaxLen(numFoci);\nfor (var startIndex = 0; startIndex < points.Length; startIndex += maxLen)\n{\n    new WriteFociBuffer(\n        bank: option.Bank,\n        startIndex: (uint)startIndex,\n        points: points[startIndex..Math.Min(startIndex + maxLen, points.Length)]\n    );\n}\nnew ConfigFociStm(\n    bank: option.Bank,\n    config: config,\n    size: (uint)points.Length,\n    numFoci: numFoci,\n    soundSpeed: option.SoundSpeed,\n    loopBehavior: option.LoopBehavior\n);\nnew ActivatePatternBank(\n    bank: option.Bank,\n    transitionMode: option.TransitionMode\n);"} />
