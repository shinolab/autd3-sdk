`ReleaseFailsafe` は, フェイルセーフ (ホストとの通信途絶・PTP ロック喪失・CPU ウォッチドッグ) で止まった出力を再開させるコマンド.
フェイルセーフの条件と既定値は [SetCpuConfig](/autd3-sdk/0.14.x/api/command/cpu-config/) を参照.

止まる前の出力がそのまま再開する.
フェイルセーフで止まっていないデバイスには何もしない.
発火の条件が成り立ったままのデバイス (PTP のロックを失ったまま等) は, エラー (`ERR_FAILSAFE_CONDITION_ACTIVE`) で拒否し, 止まったままにする.
止まっているかどうかは返信 (`Response`) の `device_status()` が返す `DeviceStatus` の `failsafe_active` で確認できる ([状態監視](/autd3-sdk/0.14.x/guide/state-check/) 参照).

[Clear](/autd3-sdk/0.14.x/api/command/clear/) でも解除されるが, すべての状態が既定値に戻る.
