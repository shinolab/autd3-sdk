`SetFpgaConfig` は, FPGA の設定を変更するコマンド.

## API

<CodeTabs rust={"let config = FpgaConfig {\n    sync_phase_lock,\n    sync_kp,\n    sync_ki,\n    sync_kf,\n};\nSetFpgaConfig::new(config);"} python={"config = FpgaConfig(\n    sync_phase_lock=sync_phase_lock,\n    sync_kp=sync_kp,\n    sync_ki=sync_ki,\n    sync_kf=sync_kf,\n)\nSetFpgaConfig(config)"} csharp={"var config = new FpgaConfig\n{\n    SyncPhaseLock = syncPhaseLock,\n    SyncKp = syncKp,\n    SyncKi = syncKi,\n    SyncKf = syncKf,\n};\nnew SetFpgaConfig(config);"} />

### FpgaConfig

| フィールド        | 型     | 既定値 | 説明 |
| ----------------- | ------ | ------ | ---- |
| `sync_phase_lock` | `bool` | `true` | FPGA の動作クロックをデバイス間の同期パルスへ位相ロックする細調整. (既定で有効になっている.) |
| `sync_kp`         | `u16`  | `64`   | 細調整の比例ゲイン. |
| `sync_ki`         | `u16`  | `1024` | 細調整の積分ゲイン. |
| `sync_kf`         | `u16`  | `4096` | 細調整に入る前の周波数推定の積分ゲイン. |
