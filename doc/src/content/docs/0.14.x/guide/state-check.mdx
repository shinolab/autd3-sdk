[`Client`](/autd3-sdk/0.14.x/api/basics/client/) の `read_state` の返り値を見ることで, デバイスとの通信が正常に動いているかどうかを監視できる.

## 状態の取得

`Response` の `device_status` は, その返信の時点の各デバイスの状態 `DeviceStatus` の配列を返す.

`DeviceStatus` は以下を持つ.

* `state`: デバイスの状態 (`DeviceState`).
* `ptp_locked`: PTP がロックしているか.
* `failsafe_active`: フェイルセーフで出力を止めていて, まだ解除されていないか

全デバイスが `Ready` か, といった集約は返り値から作る (下の例を参照).
`ptp_locked` と `failsafe_active` はその返信の値である.

`DeviceState`の意味は以下の通り.

| 状態     | 意味                                                                     |
| -------- | ------------------------------------------------------------------------ |
| `Ready`   | 返信があり, 時刻が同期されている                                        |
| `Syncing` | 返信はあるが, 時刻を合わせている途中                                    |

以下は, 一定間隔で生存確認を送って `device_status` を見て, 状態が変化したときだけ出力する例.
