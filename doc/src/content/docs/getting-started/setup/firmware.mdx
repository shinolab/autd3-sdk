AUTD3 デバイスを正しく動作させるには, SDK に対応したバージョンの CPU / FPGA ファームウェアが書き込まれている必要がある.

:::note
このバージョンの SDK は, Firmware v0.10.x をサポートする.
:::

ファームウェアの更新には, GUI コンソール autd3-console の **Firmware** タブを使う.

:::caution
ファームウェアのバージョンが SDK と一致しない場合, 正常な動作は保証されない.
:::

入手方法は [コンソール](/autd3-sdk/guide/console/) を参照.

## Ethernet ケーブルを使用した OTA

CPU と FPGA の両方に v0.10.0 以降のファームウェアが載っている場合, Ethernet ケーブルのみでアップデートできる.
v0.9.x 以前 (EtherCAT 版) の場合は, 下記の JTAG 経由のアップデートが必要. [ファームウェア v0.9.x からの移行](/autd3-sdk/getting-started/migration/) も参照すること.

:::caution
OTA では EtherCAT 版 (v0.9.x 以前) のファームウェアに戻せない.
EtherCAT 版に戻す場合は JTAG で書き込む.
:::

### 事前準備

[ホストのネットワーク設定](/autd3-sdk/getting-started/setup/network/) を済ませておくこと.

### 手順

1. AUTD3 と PC を Ethernet ケーブルで接続し, 電源を入れる
1. autd3-console を起動し, **Firmware** タブを開く
1. **Version** と **Target** (`Both` / `FPGA` / `CPU`) を選ぶ. 通常は `Both` を使う (CPU だけを更新すると FPGA と版数が食い違い, SDK が接続を拒否する)
1. **Method** が OTA (既定) になっていることを確認する
1. 必要なら **Interface** と **Advanced UDP options** を設定する (デフォルトのままで良い)
1. **Flash** を押す. 進捗はパネル下部のログに表示される. CPU は数十秒, FPGA は 1 台あたり約 90 秒かかる
1. ログに `Ok!` が出れば完了. 電源の入れ直しは不要 (CPU の更新後, デバイスは再起動して列挙からやり直される)

**更新中に電源を切らないこと**.
失敗した場合は電源を再投入してからやり直すこと.

### 一部のデバイスが旧ファームウェアに戻った場合

CPU の新しいファームウェアは, 再起動後にツールが確定するまで「試行」として動く.
確定前にもう一度リセットされたデバイス (瞬断など) は, 更新前のファームウェアに戻る.
ツールは確定の前に各デバイスが試行中のファームウェアで動いているかを確認し, 1 台でも戻っていれば, どのデバイスも確定せずに次のようなエラーで終了する.

```text
Error: not every device runs the trial image after the reboot: device 1 (confirmed image, CPU firmware 0.10.0) fell back to the previous image. No device was confirmed, ...
```

`device N` は Ethernet の接続順 (PC に近い方から 0) の番号で, 括弧内はそのデバイスが報告した状態と CPU ファームウェアの版数である.
この時点では, 新しいファームウェアで動いているデバイスも未確定なので, 次のリセットで更新前のファームウェアに戻る. 版数が混在したまま確定されることはない.

対処は, 全デバイスの電源と配線を確認したうえで, **同じ手順でもう一度更新する**ことである.
更新をやめる場合は全デバイスの電源を入れ直せば, 全台が更新前のファームウェアに揃う.

## JTAG を使用したアップデート

### 事前準備

ファームウェアの書き込みには, 以下の外部ツールが必要である.
いずれも実行ファイルが `PATH` 上にある必要がある (Windows ではインストール先を自動検出する).

- **FPGA 書き込み**: [Vivado](https://www.xilinx.com/products/design-tools/vivado.html) (`vivado` / `vivado_lab`) と, 接続用の [XILINX Platform Cable](https://www.xilinx.com/products/boards-and-kits/hw-usb-ii-g.html).

:::note
FPGA 書き込みのみが目的であれば, **Vivado Lab Edition** の使用を強く推奨する.
標準版 (ML Edition) はインストールに 60 GB 以上を要するが, Lab Edition は 6 GB 程度で済む.
:::

- **CPU 書き込み**: [J-Link Software](https://www.segger.com/downloads/jlink/) (`JLink` / `JLinkExe`) と, [J-Link 9-Pin Cortex-M Adapter](https://www.segger-pocjapan.com/j-link-9-pin-cortex-m-adapter) を介した [J-Link Plus](https://www.segger.com/products/debug-probes/j-link/models/j-link-plus/) プローブ.

:::note
古い J-Link デバイス (例: J-Link Plus V10 以前) を使用する場合, J-Link Software のインストール時に "**Install legacy USB Driver for J-Link**" にチェックを入れること.
詳細は [Segger Wiki](https://wiki.segger.com/J-Link_Model_Overview) を参照.
:::

### 書き込み手順

<Figure src="img/hardware/cable.jpg" alt="ファームウェアアップデート用ケーブルの接続先" />

1. AUTD3の電源を切る
1. 上記ケーブルを接続する. 接続先は上図の通り.
1. AUTD3 の電源を入れる
1. autd3-console を起動し, **Firmware** タブを開く.
1. **Version** から書き込むバージョンを選択する
1. **Target** で書き込む対象を選ぶ (`Both` / `FPGA` / `CPU`).
1. **Method** で `JTAG` を選ぶ
1. **Flash** を押す. 進捗はパネル下部のログに表示される. 書き込みには数分を要する.
1. 書き込み完了後, AUTD3 の電源を入れ直すと新しいファームウェアが反映される.
