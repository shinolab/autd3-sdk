ここでは, 一つのデバイスを駆動する方法について説明する.

## 事前準備

本チュートリアルでは, ホストの NIC から [UDP](/autd3-sdk/api/basics/transport-option/) で直接デバイスにつなぐ.
あらかじめ [ホストのネットワーク設定](/autd3-sdk/getting-started/setup/network/) (ファイアウォールの受信許可など) を済ませておくこと.

以下は, 1台のAUTD3デバイスでアレイの中心から150 mm直上に焦点を生成し, 200 Hzの正弦波AMかける例である.

<Fragment slot="rust" >
まずは適当なプロジェクトを作成し, `autd3-rs`ライブラリを依存関係に追加する.
焦点計算やAM変調のために, `autd3-rs-pattern`と`autd3-rs-modulation`も依存関係に追加する.
また, 適当な非同期ランタイムが必要なので `tokio` を追加する.

```
cargo new --bin autd3-sample && cd autd3-sample
cargo add autd3-rs
cargo add autd3-rs-pattern
cargo add autd3-rs-modulation
cargo add tokio --features full
```

Ctrl+C を押すと終了する.
`close` (C# は `using`, Python は `with` の終わり) は接続を閉じるだけで出力を止めないので, 閉じる前に振幅 0 の `Pattern` を送って出力を止めている ([Client](/autd3-sdk/api/basics/client/#api) 参照).
