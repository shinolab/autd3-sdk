`ConfigFociStm` は, Foci STM バンクの再生パラメータを設定する低レベルコマンド.
設定は書き込まれるだけで, 再生には [ActivatePatternBank](/autd3-sdk/0.10.x/api/command/lowlevel/activate-pattern-bank/) を送った時点で反映される.
再生中のバンクの設定を変える場合も, 同じバンクを指す `ActivatePatternBank` を続けて送る.

## API

<CodeTabs rust={"ConfigFociStm {\n    bank,\n    config,\n    size,\n    num_foci,\n    sound_speed,\n    loop_behavior,\n};"} python={"ConfigFociStm(\n    bank=bank,\n    config=config,\n    size=size,\n    num_foci=num_foci,\n    sound_speed=sound_speed,\n    loop_behavior=loop_behavior,\n)"} csharp={"new ConfigFociStm(\n    bank: bank,\n    config: config,\n    size: size,\n    numFoci: numFoci,\n    soundSpeed: soundSpeed,\n    loopBehavior: loopBehavior\n);"} />

| フィールド      | 型               | 説明                                               |
| --------------- | ---------------- | -------------------------------------------------- |
| `bank`          | `PatternBank`    | 対象バンク                                         |
| `config`        | `SamplingConfig` | 再生サンプリング周波数                             |
| `size`          | `usize`          | STM サンプル数                                     |
| `num_foci`      | `u8`             | 1 サンプルあたりの焦点数 (`ControlPoints<N>` の N) |
| `sound_speed`   | `Velocity`       | 焦点計算に使う音速                                 |
| `loop_behavior` | `LoopBehavior`   | 再生ループ回数 (`Infinite` / `Finite`)             |

`loop_behavior` と遷移の反映タイミングは [ActivatePatternBank](/autd3-sdk/0.10.x/api/command/lowlevel/activate-pattern-bank/) を参照.

`size` の下限は 2.
単一焦点を静的に出したい場合は STM ではなく [Pattern](/autd3-sdk/0.10.x/api/command/pattern/) を使う.
