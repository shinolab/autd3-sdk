`Pattern` は, 各振動子の位相と振幅をデバイスへ送るコマンド.
位相と振幅は別々のバッファで渡す.

## API

<CodeTabs>
  <Fragment slot="rust">
    <Code code={"Pattern::new(&phases, intensities);\n\nPattern::with_bank(bank, &phases, intensities);\n\nPattern {\n    bank,\n    phases: &phases,\n    intensities: intensities.into(),\n    transition_mode,\n};"} lang="rust" />

    `Pattern::new` は書き込み先バンクを `PatternBank::B0` とする.
    別バンクへ書く場合は `Pattern::with_bank(bank, phases, intensities)` を使う.
  </Fragment>

  <Fragment slot="python">
    <Code code={"Pattern(phases, intensities)\n\nPattern(phases, intensities, bank=bank)\n\nPattern(\n    phases,\n    intensities,\n    bank=bank,\n    transition_mode=transition_mode,\n)"} lang="python" />

    `Pattern` は書き込み先バンクをデフォルトで `PatternBank.B0` とする.
    別バンクへ書く場合は `Pattern(phases, intensities, bank=bank)` を使う.
  </Fragment>

  <Fragment slot="csharp">
    <Code code={"new Pattern(phases, intensities);\n\nnew Pattern(bank, phases, intensities);\n\nnew Pattern(\n    bank: bank,\n    phases: phases,\n    intensities: intensities,\n    transitionMode: transitionMode\n);"} lang="csharp" />

    `new Pattern(phases, intensities)` は書き込み先バンクを `PatternBank.B0` とする.
    別バンクへ書く場合は `new Pattern(bank, phases, intensities)` を使う.
  </Fragment>
</CodeTabs>

| フィールド        | 型                               | デフォルト                      | 説明                             |
| ----------------- | -------------------------------- | --------------------------- | -------------------------------- |
| `bank`            | `PatternBank`                    | `PatternBank::B0`           | 書き込み先・再生対象のバンク     |
| `phases`          | `&[Vec<Phase>]`     | —                           | デバイスごとの位相               |
| `intensities`     | `PatternIntensity`  | —                           | 振幅 (`Intensity` の一様値, または `&[Vec<Intensity>]` のデバイスごとのバッファ) |
| `transition_mode` | `TransitionMode`                 | `TransitionMode::Immediate` | バンク切替時の遷移挙動           |

patternの計算には幾つかの[ヘルパ関数](/autd3-sdk/0.10.x/api/compute/pattern/)が用意されている.

## 等価な低レベルコマンド

`Pattern` は [WritePatternBuffer](/autd3-sdk/0.10.x/api/command/lowlevel/write-pattern-buffer/) + [ConfigPattern](/autd3-sdk/0.10.x/api/command/lowlevel/config-pattern/) + [ActivatePatternBank](/autd3-sdk/0.10.x/api/command/lowlevel/activate-pattern-bank/) の 3 つと等価であり, この順に 3 フレームへ展開して送られる.
以下は `Pattern { bank, phases, intensities }` と等価な組み合わせである.

`transition_mode` に `TransitionMode::Later` を指定した場合は `WritePatternBuffer` + `ConfigPattern` の 2 フレームだけを送る (`ActivatePatternBank` を送らない).
詳細は [ActivatePatternBank](/autd3-sdk/0.10.x/api/command/lowlevel/activate-pattern-bank/) の `TransitionMode` を参照.

<CodeTabs rust={"WritePatternBuffer::new(bank, 0, phases, intensities);\nConfigPattern {\n    bank,\n    config: SamplingConfig::new(NonZeroU16::MAX),\n    size: 1,\n    loop_behavior: LoopBehavior::Infinite,\n};\nActivatePatternBank {\n    bank,\n    transition_mode,\n};"} python={"WritePatternBuffer(\n    bank=bank,\n    index=0,\n    phases=phases,\n    intensities=intensities,\n)\nConfigPattern(\n    bank=bank,\n    config=SamplingConfig(0xFFFF),\n    size=1,\n    loop_behavior=LoopBehavior.Infinite,\n)\nActivatePatternBank(\n    bank=bank,\n    transition_mode=transition_mode,\n)"} csharp={"new WritePatternBuffer(\n    bank: bank,\n    index: 0,\n    phases: phases,\n    intensities: intensities\n);\nnew ConfigPattern(\n    bank: bank,\n    config: new SamplingConfig(ushort.MaxValue),\n    size: 1,\n    loopBehavior: LoopBehavior.Infinite\n);\nnew ActivatePatternBank(\n    bank: bank,\n    transitionMode: transitionMode\n);"} />
