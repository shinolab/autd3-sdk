`Geometry` は AUTD3 デバイスの物理配置 (位置・姿勢) を表現する.

<CodeTabs>
<Fragment slot="rust">
<Code code={excerpt(sample, "api")} lang="rust" />

`Autd3::new(origin, rotation)` は原点位置 (`Point3`) と姿勢 (`UnitQuaternion`) から 1 台のデバイスを構築する.
原点を `Point3::origin()`, 姿勢を `UnitQuaternion::identity()` とする `Autd3::default()` もある.
</Fragment>
<Fragment slot="python">
<Code code={excerpt(pySample, "api")} lang="python" />

`Autd3([x, y, z], rotation)` は原点位置と姿勢から 1 台のデバイスを構築する.
どちらも省略でき, 原点の既定は `[0, 0, 0]`, 姿勢の既定は単位クォータニオン `[1, 0, 0, 0]` である (`Autd3()` は Rust の `Autd3::default()` と同じ).

姿勢には以下の 3 形式を渡せる.

<Code code={excerpt(pySample, "rotation")} lang="python" />

- クォータニオン: **scalar-first** `[w, i, j, k]`
- `EulerAngles`: intrinsic なオイラー角
- scipy の `Rotation`
</Fragment>
<Fragment slot="csharp">
<Code code={excerpt(csSample, "api")} lang="csharp" />

`new Autd3(origin, rotation)` は原点位置 (`Vector3`) と姿勢 (`Quaternion`) から 1 台のデバイスを構築する.
姿勢を省略した `new Autd3(origin)` もある (`Quaternion.Identity` を使う).
`new Autd3()` (と `default(Autd3)`) は Rust の `Autd3::default()` と同じく原点・`Quaternion.Identity` になる.
</Fragment>
</CodeTabs>

`Geometry::new` に複数台を渡すと, 先頭から順にデバイス番号 (`idx`) が割り振られる.

Rust は姿勢を `UnitQuaternion` で受けるので単位長が型で保証される.
Python / C# はクォータニオンのノルムを検査し, 1 との差が `ROTATION_NORM_TOLERANCE` (1e-3, C#: `Autd3.RotationNormTolerance`) を超えるとエラーにする (Python は `Autd3` の構築時に `ValueError`, C# は `Geometry` の構築時に `Autd3Exception` (`InvalidArgument`)).

## API

配置全体の情報取得と, 各 `Device` へのアクセスを提供する.

<CodeTabs rust={excerpt(sample, "access")} python={excerpt(pySample, "access")} csharp={excerpt(csSample, "access")} />

| メソッド             | 返り値                             | 説明                                  |
| -------------------- | ---------------------------------- | ------------------------------------- |
| `num_devices()`      | `usize`                            | デバイス台数                          |
| `num_transducers()`  | `usize`                            | 全デバイスの振動子総数                |
| `is_empty()`         | `bool`                             | デバイスが 1 台も無いか               |
| `center()`           | `Point3<f32>`                      | アレイ全体の中心座標                  |
| `phase_buffer()`     | `Vec<Vec<Phase>>`     | Pattern 計算用の位相バッファを確保 (初期値 0)    |
| `intensity_buffer()` | `Vec<Vec<Intensity>>` | Pattern 計算用の振幅バッファを確保 (初期値最大) |
| `output_mask_buffer()` | `Vec<Vec<bool>>`    | `SetOutputMask` 用の出力マスクバッファを確保 (初期値 `true`) |
| `iter()` / `&geometry` | `Iterator<Item = &Device>`       | 各 `Device` を走査                    |
| `geometry[i]`        | `&Device`                          | `i` 番目の `Device` を取得            |
| `to_json()`          | `Result<String, LayoutError>`      | 配置を JSON 文字列にする              |
| `from_json(&str)`    | `Result<Geometry, LayoutError>`    | JSON 文字列から`Geometry`を生成          |

範囲外の `geometry[i]` は, Rust では panic, Python では `IndexError` (負の `i` も), C# では `ArgumentOutOfRangeException` になる.

## Device

1 台のデバイスを表す.
`geometry[i]` または `&geometry` の走査で得る.
各振動子の位置や, デバイスの姿勢を取得できる. 振動子の法線方向はデバイス内で共通で, `axial_direction()` が返す.

<CodeTabs rust={excerpt(sample, "device")} python={excerpt(pySample, "device")} csharp={excerpt(csSample, "device")} />

| メソッド             | 返り値                  | 説明                                          |
| -------------------- | ----------------------- | --------------------------------------------- |
| `idx()`              | `usize`                 | `Geometry` 内でのデバイス番号                 |
| `num_transducers()`  | `usize`                 | 振動子数                                      |
| `is_empty()`         | `bool`                  | 振動子が 1 つも無いか                         |
| `center()`           | `Point3<f32>`           | デバイス中心座標                              |
| `rotation()`         | `UnitQuaternion<f32>`   | デバイスの姿勢 (回転)                         |
| `x_direction()`      | `UnitVector3<f32>`      | ローカル x 軸方向                             |
| `y_direction()`      | `UnitVector3<f32>`      | ローカル y 軸方向                             |
| `axial_direction()`  | `UnitVector3<f32>`      | 軸方向 (超音波の放射方向)                     |
| `positions()`        | `&[Point3<f32>]`        | 全振動子の位置                                |
| `position(i)`        | `Point3<f32>`           | `i` 番目の振動子の位置                        |
| `to_local(p)`        | `Point3<f32>`           | グローバル座標の点 `p` をデバイスのローカル座標 (0 番目の振動子が原点) に変換 |

Python では座標・方向・姿勢はすべて `float32` の numpy 配列で返る (`Geometry.center()` や `Autd3.origin` / `Autd3.rotation` も同じ).
姿勢は `[w, x, y, z]` の順のクォータニオン.

## 座標ヘルパ

座標を組み立てるヘルパがある.
引数の型が `Length` になっており, `150 * mm` のように単位を指定することができる ([単位と値型](/autd3-sdk/api/basics/units/) 参照).

| 関数                | 返り値 (Rust)   | 説明                                         |
| ------------------- | --------------- | -------------------------------------------- |
| `point(x, y, z)`    | `Point3<f32>`   | 絶対座標の点                                 |
| `offset(x, y, z)`   | `Vector3<f32>`  | 相対変位ベクトル                             |
