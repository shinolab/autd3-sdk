## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| フィールド            | 型          | 既定値  | 説明                                                                                          |
| --------------------- | ----------- | ------- | --------------------------------------------------------------------------------------------- |
| `iface`               | `Interface` | `Auto`  | 接続先                                                                                        |
| `open_timeout`        | `Duration`  | 40 s    | open 全体 (デバイスの列挙と, 全台がデバイス間の同期を終えるまでの待ち) の上限                     |
| `lost_timeout`        | `Duration`  | 100 ms  | この時間返信が無いデバイスを `Lost` とする                                                     |
| `ack_timeout`         | `Duration`  | 10 ms   | 応答待ちのタイムアウト. 応答待ちの先頭のフレームの応答がこの時間揃わなければ, 送信中のフレームはすべて `Timeout` で失敗する ([Client](/autd3-sdk/api/basics/client/#応答待ちのタイムアウト) 参照) |
| `send_buffer_bytes`         | `Option<NonZeroUsize>` | 8192 | ソケットの送信バッファの大きさ [B]. `None` で OS の既定のままにする |
| `sync_on_open`        | `bool`      | `true`  | `false` なら open でデバイス間の同期を待たない (ファームウェア更新などの保守用. Rust のみ) |

基本的に `iface` 以外を変更することは推奨しない.
生存確認は `TransportOption` では設定せず, ユーザーが `Client` の [`send_heartbeat()`](/autd3-sdk/api/basics/client/#生存確認) を呼んで送る.

Python の既定値は Rust と同じ具体値で, 型が `Option` の項目だけ `None` (無効) を渡せる. それ以外の項目に `None` を渡すと `TypeError` になる.
C# では型が `Option` の項目を `null` にすると無効になる.
`open_timeout` / `lost_timeout` / `ack_timeout` は検証しない. 0 にするとその待ちがすぐに時間切れになる (`lost_timeout` が 0 だと, 最初の送信の後に全デバイスが `Lost` になる).
`send_buffer_bytes` の `0` は, Python では `TransportOption` を作るときに `ValueError`, C# では `Client` を開くときに `Autd3Exception` (`InvalidArgument`) になる (Rust は `NonZeroUsize` の型で `0` を渡せない).

:::caution[Windows のタイマ分解能]
ライブラリは Windows のタイマ分解能 (`timeBeginPeriod`) を変更しない.
既定の分解能 (典型的には 15.6 ms) では, 返信の待ち (ソケットの受信タイムアウト) がその粒度に丸められ, `ack_timeout` や `lost_timeout` の判定が遅れることがある.
必要であれば, ユーザーがプロセスで `timeBeginPeriod(1)` を呼ぶ.
:::

## Interface

<CodeTabs rust={excerpt(sample, "iface")} python={excerpt(pySample, "iface")} csharp={excerpt(csSample, "iface")} />

| 値          | 接続先                                                                                                  |
| ----------- | ------------------------------------------------------------------------------------------------------- |
| `Auto`      | デバイスが最初に応答したネットワークインタフェース. インタフェース番号の小さい順に探す                  |
| `Name(..)`  | 名前で指定したネットワークインタフェースにつながっている実機                                            |
| `Addr(..)`  | 指定した IPv6 アドレスとポート. [Simulator](/autd3-sdk/guide/simulator/) へは `[::1]:44336` でつなぐ    |
