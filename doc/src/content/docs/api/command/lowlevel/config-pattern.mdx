`ConfigPattern` は, Pattern バンクの再生パラメータを設定する低レベルコマンド.
設定は書き込まれるだけで, 再生には [ActivatePatternBank](/autd3-sdk/api/command/lowlevel/activate-pattern-bank/) を送った時点で反映される.
再生中のバンクの設定を変える場合も, 同じバンクを指す `ActivatePatternBank` を続けて送る.

## API

<CodeTabs rust={excerpt(sample, "config")} python={excerpt(pySample, "config")} csharp={excerpt(csSample, "config")} />

| フィールド  | 型                | 説明                                              |
| ----------- | ----------------- | ------------------------------------------------- |
| `bank`      | `PatternBank`     | 対象バンク                                        |
| `config`    | `SamplingConfig`  | 再生サンプリング周波数                            |
| `size`      | `usize`           | バンク内のサンプル数. 静的 Pattern は `1`         |
| `loop_behavior` | `LoopBehavior` | 再生ループ回数 (`Infinite` / `Finite`)           |


`loop_behavior` は, [ActivatePatternBank](/autd3-sdk/api/command/lowlevel/activate-pattern-bank/) で現在と異なるバンクへ切り替えたときのみ作用する.

`size = 1` (静的 Pattern) は `loop_behavior = Infinite` のときのみ有効.
有限ループを使う場合は `size` を 2 以上にする.
