`Pattern` / `Modulation` などの複合コマンドは, 以下の低レベルコマンドの組み合わせと等価である.
複合コマンドは送信時にこれらの低レベルコマンドへ展開される.

| 種別         | Pattern 系                                                                 | Modulation 系                                                                    |
| ------------ | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| バッファ書込 | [WritePatternBuffer](/autd3-sdk/api/command/lowlevel/write-pattern-buffer/) | [WriteModulationBuffer](/autd3-sdk/api/command/lowlevel/write-modulation-buffer/) |
| バンク設定   | [ConfigPattern](/autd3-sdk/api/command/lowlevel/config-pattern/)           | [ConfigModulation](/autd3-sdk/api/command/lowlevel/config-modulation/)           |
| バンク切替   | [ActivatePatternBank](/autd3-sdk/api/command/lowlevel/activate-pattern-bank/)   | [ActivateModulationBank](/autd3-sdk/api/command/lowlevel/activate-modulation-bank/)   |

Foci STM 用の焦点列を書く [WriteFociBuffer](/autd3-sdk/api/command/lowlevel/write-foci-buffer/) とその設定 [ConfigFociStm](/autd3-sdk/api/command/lowlevel/config-foci-stm/) もある.

Pattern バッファへの書き込みには, 位相のみを送り 1 フレームに複数 Pattern を書き込む [WritePatternPhase](/autd3-sdk/api/command/lowlevel/write-pattern-phase/) もある.
