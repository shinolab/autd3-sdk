`ConfigFociStm` は, Foci STM バンクの再生パラメータを設定する低レベルコマンド.
設定は書き込まれるだけで, 有効化には [ActivatePatternBank](/autd3-sdk/api/command/lowlevel/activate-pattern-bank/) を送る.

## API

<CodeTabs rust={excerpt(sample, "config")} python={excerpt(pySample, "config")} csharp={excerpt(csSample, "config")} />

| フィールド      | 型               | 説明                                               |
| --------------- | ---------------- | -------------------------------------------------- |
| `bank`          | `PatternBank`    | 対象バンク                                         |
| `config`        | `SamplingConfig` | 再生サンプリング周波数                             |
| `size`          | `usize`          | STM サンプル数                                     |
| `num_foci`      | `u8`             | 1 サンプルあたりの焦点数 (`ControlPoints` の `points` の長さ) |
| `sound_speed`   | `Velocity`       | 焦点計算に使う音速                                 |
| `loop_behavior` | `LoopBehavior`   | 再生ループ回数 (`Infinite` / `Finite`)             |

`size` の下限は 2.
