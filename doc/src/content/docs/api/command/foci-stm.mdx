`FociStm` は, ハードウェアタイマにより単一, 及び, 多焦点音場を切り替える STM 機能を提供する.
[`PatternStm`](/autd3-sdk/api/command/pattern-stm/) と異なり, 焦点しか扱えないが, 転送データ量が少なく, レイテンシが小さい. 

## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| 引数      | 型                       | 説明                                       |
| --------- | ------------------------ | ------------------------------------------ |
| `config`  | `SamplingConfig`         | サンプル毎のサンプリング設定                        |
| `points`  | `&[ControlPoints<N>]`    | 焦点サンプルの列 (2 サンプル以上)          |
| `option`  | `FociStmOption`          | 音速・ループ・遷移などのオプション         |

`config` は 1 サンプルあたりのサンプリング設定である. 「全サンプルを 1 周する周波数」から決めたいときは, 周波数にサンプル数を掛けて `SamplingConfig` を作る (例: 200 サンプルを 1 Hz で回すなら 200 Hz).

## ControlPoint / ControlPoints

1 サンプルは `ControlPoints<N>` で表される. `N` は同時に出す焦点の数 (最大 8) である. 

- `ControlPoint { point, phase_offset }` — 焦点座標 [mm] と位相オフセット. 
- `ControlPoints<N> { points: [ControlPoint; N], intensity }` — `N` 個の焦点と振幅. 

`ControlPoint::new(point, phase_offset)` / `ControlPoints::new(points, intensity)` の引数はすべて必須 (Python / C# も同じ).
Rust では `From` で座標から変換でき, 位相オフセットは `Phase::ZERO`, 振幅は `Intensity::MAX` になる (`ControlPoint::from(p)`, `ControlPoints::from(p)` / `ControlPoints::from(cp)` / `ControlPoints::from([p0, p1])`).
C# では同じ変換を explicit 変換 `(ControlPoint)p` / `(ControlPoints)p` / `(ControlPoints)cp` / `(ControlPoints)points` で書く.
Python にはこの短い書き方が無いので, `ControlPoints([ControlPoint(p, Phase.ZERO)], Intensity.MAX)` のように明示する.

## FociStmOption

<CodeTabs rust={excerpt(sample, "option")} python={excerpt(pySample, "option")} csharp={excerpt(csSample, "option")} />

| フィールド        | 型               | デフォルト                 | 説明                                   |
| ----------------- | ---------------- | -------------------------- | -------------------------------------- |
| `bank`            | `PatternBank`    | `PatternBank::B0`          | 書き込み先・再生対象のバンク           |
| `sound_speed`     | `Velocity`       | `340 m/s`                  | 焦点計算に使う音速                     |
| `loop_behavior`   | `LoopBehavior`   | `LoopBehavior::Infinite`   | ループ回数                             |
| `transition_mode` | `TransitionMode` | `TransitionMode::Immediate` | バンク切替時の遷移タイミング           |

`loop_behavior` と `transition_mode` の挙動は[再生制御](/autd3-sdk/api/command/lowlevel/activate-pattern-bank/) を参照.

## 等価な低レベルコマンド

`FociStm` は [WriteFociBuffer](/autd3-sdk/api/command/lowlevel/write-foci-buffer/) + [ConfigFociStm](/autd3-sdk/api/command/lowlevel/config-foci-stm/) + [ActivatePatternBank](/autd3-sdk/api/command/lowlevel/activate-pattern-bank/) の 3 つと等価であり, この順に展開して送られる.
`WriteFociBuffer` は 1 フレーム分しか書けないので, 1 フレームに収まらない焦点列は `start_index` をずらした複数の `WriteFociBuffer` に分割される.
