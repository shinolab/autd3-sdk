### FpgaConfig

| フィールド        | 型     | 既定値 | 説明 |
| ----------------- | ------ | ------ | ---- |
| `sync_phase_lock` | `bool` | `true` | FPGA の動作クロックをデバイス間の同期パルスへ位相ロックする細調整. (既定で有効になっている.) |
