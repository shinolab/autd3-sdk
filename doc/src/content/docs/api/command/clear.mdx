`Clear` は, デバイスのバンク・各種設定を起動直後の状態へ戻すコマンド.
Silencer / Pattern / Modulation などの設定がすべて初期化される.

## Synchronize / Nop

ペイロードを持たないコマンドとして, ほかに `Synchronize` と `Nop` がある (Rust は `Synchronize` / `Nop`, Python は `Synchronize()` / `Nop()`, C# は `new Synchronize()` / `new Nop()`).

- `Synchronize` は, FPGA が PWM 生成に使う同期クロックを初期化し直し, デバイス間の出力の位相を揃える. `Client` を開くときに `Clear` の後に送られ, `Lost` から自動復帰したデバイスには `ClientConfig` の `resynchronize_on_recovery` が既定で送り直す ([Client](/autd3-sdk/api/basics/client/#clientconfig) 参照).
- `Nop` は何も変更せず, 常に成功を返す.
