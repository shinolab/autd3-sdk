`RemoteLink` は, AUTD3 デバイスに接続された別ホストへ TCP 接続して送受信する Link 実装. 
AUTD3 を操作したいマシンと実機を配線したマシンが異なる場合に使う.

<Install rust="autd3-rs-link-remote" python="autd3-link-remote" csharp="AUTD3.Link.Remote" />

サーバとクライアントの 2 プロセスで構成する.

- `RemoteServer`: 実機に配線されたホストで動かす. 実機リンクを駆動し, フレームを TCP で中継する. 
- `RemoteLink`: 操作側のホストで動かす. 

サーバ側のホストには, 実機を駆動する Link のパッケージ ([EtherCrab](/autd3-sdk/api/link/ethercrab/) 等) も併せて追加する.

[`Simulator`](/autd3-sdk/guide/simulator/) への接続も`RemoteLink`で行う.

## API

### RemoteServer

`RemoteServer::open` で実機リンクを開き, TCP の待ち受けを開始する.

<CodeTabs rust={excerpt(server, "api")} />

| 引数   | 型             | 説明                                                       |
| ------ | -------------- | ---------------------------------------------------------- |
| `bind` | `SocketAddr`   | サーバが待ち受ける TCP アドレス                            |
| `link` | `impl IntoLink` | 中継する実機リンクの Option               |

`open` は内部でEtherCATスレッドを起動し, クライアントの接続有無によらずEtherCATはを駆動し続ける.
`serve` はクライアントの接続を待ち受け, フレームの中継を開始する.
