`Controller` / `Driver` は Rust のみで提供される.
:::

`Controller` と `Driver` は, [`Client`](/autd3-sdk/api/basics/client/) の中身を自分で駆動するためのパーツ.

`Client` は, 返信の受信を行う I/O スレッドを内部に 1 本持つ.
このスレッドの代わりに, 送受信ループを自前のスレッドなどで回したい場合に `Controller` / `Driver` を使う.

## Open

`Controller::open` は `Controller` と `Driver` のタプルを返す.
引数は `Client::open` と同じ.

<CodeTabs rust={excerpt(sample, "run")} />

`Controller::open` は `Client::open` と同じく同期関数で, デバイスの列挙と I/O の準備だけを行い, デバイスへフレームを送らない.
`Driver` を回し始めたら, そのままコマンドを送ってよい.
`Clear` と `Synchronize` も送らないので, 初期状態から始める場合は自分で送る.
コマンドの完了は返信を待つので, `Driver` を回す前に送ると完了しない.

## Driver

`Driver` は以下のメソッドを持つ.

| メソッド         | 返り値                           | 説明                                                             |
| ---------------- | -------------------------------- | ---------------------------------------------------------------- |
| `run(self)`      | `Result<(), Error>`              | `Controller` が閉じるまで `poll` と `wait` を繰り返す. ブロッキング. |
| `poll(&mut self)` | `Result<Option<Instant>, Error>` | 届いている返信と期限の来た処理を済ませ, 次に呼ぶべき期限を返す. ノンブロッキング. |
| `wait(&mut self, deadline)` | `Result<(), Error>`   | 返信が届くか `deadline` になるまでスレッドをブロックする           |

### poll / wait

`run` は以下のループと同じである.
ループの中に自分の処理を挟みたい場合は, `poll` と `wait` を直接呼ぶ.

<CodeTabs rust={excerpt(sample, "poll")} />

`poll` の返り値の意味は以下の通り.

- `Ok(Some(deadline))`: 次に `poll` を呼ぶべき期限. 期限より前でも, 返信が届いたら呼ぶこと. `wait` はこのどちらかまで待つ.
- `Ok(None)`: `Controller` が閉じた (`close` または Drop). ループを抜ける.
- `Err(..)`: 通信エラー. 送信中のコマンドと以後の送信は同じ原因のエラーで失敗する.

## 注意点

- `Controller` を先に破棄すると, `close` と同じく `Driver` の `poll` は `Ok(None)` を返す. どちらでもデバイスの出力は止まらないので, 出力を止めるには破棄や `close` の前に振幅 0 の [Pattern](/autd3-sdk/api/command/pattern/) を送るなどすること.
- `Driver` を先に破棄すると, 送信中のコマンドと以後の送信は `Error::Closed` で失敗する.
- `Driver` を`poll` しない限り, `Controller` の非同期メソッドは完了しない.
