振動子毎に, どのパターンの位相・振幅を出力するかを選ぶ.
振動子の振り分けは `TransducerGroups` でキー (enum など) を割り当てて決める. すべての振動子がいずれかのキーに属する.

合成には 2 つの API がある.

- `group_compute` — キー毎にキーと `TransducerMask` を受け取って計算し, 合成する.
- `group` — 計算済みのバッファをキーから選んで合成する. 計算結果を使い回したい場合やグループ毎に並列に計算したい場合に使う.

:::note
デバイス単位で切り替えるだけなら, これらではなく [`each`](/autd3-sdk/api/basics/client/#each) でデバイス毎にコマンドを送ればよい.
:::

## group_compute

<CodeTabs rust={excerpt(sample, "compute")} python={excerpt(pySample, "compute")} csharp={excerpt(csSample, "compute")} />

| 引数       | 型                                                                   | 説明                                             |
| ---------- | -------------------------------------------------------------------- | ------------------------------------------------ |
| `geometry` | `&Geometry`                                                          | ジオメトリ                                       |
| `groups`   | `&TransducerGroups<K>`                                               | 振動子毎のキー                                   |
| `compute`     | `FnMut(K, TransducerMask, &mut [Vec<Phase>], &mut [Vec<Intensity>]) -> Result<(), E>` | キーとマスクを受け取り, 作業バッファ (位相・振幅) へ計算する |
| `phases`      | `&mut [Vec<Phase>]`                                                                    | 位相の出力バッファ                                           |
| `intensities` | `&mut [Vec<Intensity>]`                                                                | 振幅の出力バッファ                                           |

`compute` はキー毎に 1 回 (キーの初出順) 呼ばれ, 計算結果のうちそのキーの振動子分だけが `phases` / `intensities` に書き込まれる.
作業バッファはキー毎に位相 0・最大振幅で初期化される.

## group

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| 引数       | 型                                          | 説明                                   |
| ---------- | ------------------------------------------- | -------------------------------------- |
| `geometry` | `&Geometry`                                 | ジオメトリ                             |
| `groups`   | `&TransducerGroups<K>`                      | 振動子毎のキー                         |
| `source`   | `FnMut(K) -> impl AsRef<[Vec<T>]>`          | キーから出力元バッファを返す           |
| `dst`      | `&mut [Vec<T>]`                             | 出力バッファ                           |

`T` は `Phase` または `Intensity` で, 位相・振幅それぞれのバッファに対して呼ぶ.

Python の `source` はキーから出力元バッファへの Mapping (`{key: buffer}`) で渡す.
キーが欠けていると `KeyError`, 出力元と `dst` のバッファの型 (`PhaseBuffer` / `IntensityBuffer`) が違うと `TypeError`, `dst` が出力元に含まれていると `ValueError` になる.
C# の `source` は `Func<TKey, PhaseBuffer>` または `Func<TKey, IntensityBuffer>`.

1 台分だけを合成する `group_device(device, groups, source, dst)` もある (C#: `Pattern.GroupDevice`).
`dst` はそのデバイス 1 台分のバッファで, Rust は `&mut [T]`, Python は長さがそのデバイスの振動子数の `uint8` の numpy 配列, C# は `Phase[]` / `Intensity[]`.

## TransducerGroups

`TransducerGroups::new(&geometry, |device, tr| ...)` がデバイスと振動子インデックスからキーを返し, 振動子毎のキーを保持する.
どのグループにも属さない振動子は作れない. 一部の振動子を無出力にするには, そのためのキーを割り当てて振幅 `Intensity::MIN` を書く (Python でキー関数が `None` を返すと `ValueError`).
キーは Rust では `Copy + Eq` な型, C# では `null` でない任意の型 (`enum` や `string` など), Python ではハッシュ可能な値.
`mask(key)` でキー `key` の振動子だけを有効にした [Holo](/autd3-sdk/api/compute/holo/) 用の `TransducerMask`を取得できる. どの振動子にも割り当てられていないキーでは Rust と Python は `None`, C# は `null` を返す.
