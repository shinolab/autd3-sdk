位相バッファ・振幅バッファ全体を一括で書き換える.
`focus` などのパターン関数は位相バッファだけを書くので, 振幅は `set_intensity` で設定する.

`phase_buffer` / `intensity_buffer` で確保したバッファの初期値は位相 0・最大振幅である.
C# では `new Intensity[n]` の要素は振幅 0 で初期化されることに注意

## set_intensity

振幅バッファの全振動子の振幅を設定する.
`Intensity::MIN` を渡すと無出力になる.

| 引数        | 型                     | 説明         |
| ----------- | ---------------------- | ------------ |
| `intensity` | `Intensity`            | 振幅         |
| `phase`     | `Phase`                | 位相         |
| `dst`       | `&mut [Vec<Intensity>]` / `&mut [Vec<Phase>]` | 対象バッファ (`set_intensity` は振幅, `set_phase` / `add_phase` は位相) |
