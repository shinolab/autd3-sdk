`vortex` は音響渦 (acoustic vortex) を生成する. 詳細は([Marzo et al., 2015](https://doi.org/10.1038/ncomms9661))を参照.

<PatternField kind="vortex" />

位相は焦点位相 <Math tex="\phi_i" /> にトポロジカルチャージ <Math tex="m" /> 倍の方位角を足したものになる.

<MathBlock tex="\phi_i^\mathrm{vortex} = \phi_i + m \theta_i, \quad \theta_i = \mathrm{atan2}((\bp_i - \boldsymbol{t}) \cdot \bv, (\bp_i - \boldsymbol{t}) \cdot \bu)" />

<Math tex="m = 0" /> は `focus` と等価.

## API

<CodeTabs rust={excerpt(sample, "api")} python={excerpt(pySample, "api")} csharp={excerpt(csSample, "api")} />

| 引数         | 型                     | 説明                                 |
| ------------ | ---------------------- | ------------------------------------ |
| `geometry`   | `&Geometry`            | デバイス配置                         |
| `target`     | `Point3<f32>`          | 渦の中心の座標 [mm]                  |
| `axis`       | `UnitVector3<f32>`     | `target` を通る渦の軸 (単位ベクトル) |
| `order`      | `i32`                  | トポロジカルチャージ (負値で逆回り)  |
| `wavelength` | `Length`               | 波長                                 |
| `option`     | `&VortexOption`        | 追加オプション (下記参照)            |
| `dst`        | `&mut [[Emission; _]]` | 出力バッファ                         |

## VortexOption

<CodeTabs rust={excerpt(sample, "option")} python={excerpt(pySample, "option")} csharp={excerpt(csSample, "option")} />

| フィールド     | 型          | デフォルト       | 説明                         |
| -------------- | ----------- | ---------------- | ---------------------------- |
| `intensity`    | `Intensity` | `Intensity::MAX` | 全振動子の振幅               |
| `phase_offset` | `Phase`     | `Phase::ZERO`    | 全振動子へ一律に加算する位相 |
