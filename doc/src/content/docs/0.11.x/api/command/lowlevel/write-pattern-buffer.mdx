`WritePatternBuffer` は, 指定したバンク・インデックスへ Pattern (各振動子の位相と振幅) を書き込む低レベルコマンド.

## API

<CodeTabs rust={"WritePatternBuffer::new(bank, index, phases, intensities);"} python={"WritePatternBuffer(\n    bank=bank,\n    index=index,\n    phases=phases,\n    intensities=intensities,\n)"} csharp={"new WritePatternBuffer(\n    bank: bank,\n    index: index,\n    phases: phases,\n    intensities: intensities\n);"} />

| フィールド  | 型                               | 説明                             |
| ----------- | -------------------------------- | -------------------------------- |
| `bank`      | `PatternBank`                    | 書き込み先バンク                 |
| `index`     | `u16`                            | バンク内の書き込み先インデックス |
| `phases`      | `&[Vec<Phase>]`     | デバイスごとの位相               |
| `intensities` | `PatternIntensity`  | 振幅 (`Intensity` の一様値, または `&[Vec<Intensity>]` のデバイスごとのバッファ) |

## Example
