`ActivatePatternBank` は, 再生対象の Pattern バンクを有効化する低レベルコマンド.

## API

<CodeTabs rust={"ActivatePatternBank {\n    bank,\n    transition_mode,\n};"} python={"ActivatePatternBank(\n    bank=bank,\n    transition_mode=transition_mode,\n)"} csharp={"new ActivatePatternBank(\n    bank: bank,\n    transitionMode: transitionMode\n);"} />

| フィールド        | 型               | 説明                     |
| ----------------- | ---------------- | ------------------------ |
| `bank`            | `PatternBank`    | 切り替え先バンク         |
| `transition_mode` | `TransitionMode` | 切り替え時の挙動         |

## TransitionMode

|            |              |
| -------------------- | --------------------------        |
| `Immediate`          | 即時                              |
| `SyncIdx`            | 次に再生インデックスが0になった時 |
| `SysTime(SysTime)`   | 指定した デバイス時刻             |
| `Gpio(GpioIn)`       | 指定 GPIO 入力ピンのトリガ        |
| `Ext`                | 拡張モード (バンク内の再生が終わると次のバンクに自動で切り替え) |
| `Later`              | 遷移しない (バンクへの書き込みだけを行う) |

`SysTime` は指定時刻が近すぎると FPGA が遷移を取りこぼす可能性があるため, 「現在時刻 + マージン」より前の指定を `MISS_TRANSITION_TIME` エラーで拒否する.
マージンはデフォルトで 10 ms であり, [SetCpuConfig](/autd3-sdk/0.11.x/api/command/cpu-config/) の `sys_time_transition_margin` で変更できる.

`Later` は「バンクへ書き込むだけで遷移しない」ことを表す.
`Modulation` / `FociStm` / `PatternStm` の `transition_mode` に指定すると, 末尾のバンク切り替えを送らず書き込みと設定だけを行う.
遷移コマンドである `ActivateModulationBank` / `ActivatePatternBank` 自身に指定した場合はエンコード時エラーになる.

`Gpio(GpioIn)` の詳細は [GPIO ピン](/autd3-sdk/0.11.x/hardware/gpio/) を参照.

同一バンクへの切り替えでは, `TransitionMode` や `LoopBehavior` の設定は機能しない.
バンク運用の詳細は [バンクの切り替え チュートリアル](/autd3-sdk/0.11.x/getting-started/tutorial/bank/) を参照.
