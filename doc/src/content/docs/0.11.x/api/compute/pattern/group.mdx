振動子毎に, どのパターンの emission を出力するかを選ぶ.
振動子の振り分けは `TransducerGroups` でキー (enum など) を割り当てて決める. すべての振動子がいずれかのキーに属する.

合成には 2 つの API がある.

* `group_compute` — キー毎にキーと `TransducerMask` を受け取って計算し, 合成する.
* `group` — 計算済みのバッファをキーから選んで合成する. 計算結果を使い回したい場合やグループ毎に並列に計算したい場合に使う.

:::note
デバイス単位で切り替えるだけなら, これらではなく [`each`](/autd3-sdk/0.11.x/api/basics/client/#each) でデバイス毎にコマンドを送ればよい.
:::

## group\_compute

<CodeTabs rust={"#[derive(Clone, Copy, PartialEq, Eq)]\nenum Side {\n    Left,\n    Right,\n}\n\ngroup_compute(\n    &geometry,\n    &groups,\n    |side, mask, phases, intensities| match side {\n        Side::Left => gspat(\n            &NalgebraBackend,\n            &geometry,\n            &foci,\n            wavelength,\n            &GspatOption {\n                mask,\n                ..Default::default()\n            },\n            phases,\n            intensities,\n        ),\n        Side::Right => {\n            focus(&geometry, target, wavelength, phases);\n            Ok(())\n        }\n    },\n    &mut phases,\n    &mut intensities,\n)?;"} python={"class Side(Enum):\n    LEFT = auto()\n    RIGHT = auto()\n\ndef compute(side: Side, mask: TransducerMask, phases: PhaseBuffer, intensities: IntensityBuffer) -> None:\n    if side is Side.LEFT:\n        gspat(geometry, foci, wavelength, GspatOption(mask=mask), phases, intensities)\n    else:\n        focus(geometry, target, wavelength, phases)\n\n\ngroup_compute(geometry, groups, compute, phases, intensities)"} csharp={"internal enum Side\n{\n    Left,\n    Right,\n}\n\nPattern.GroupCompute(geometry, groups, (side, mask, p, i) =>\n{\n    if (side == Side.Left)\n    {\n        Holo.Gspat(geometry, foci, wavelength, new GspatOption { Mask = mask }, p, i);\n    }\n    else\n    {\n        Pattern.Focus(geometry, target, wavelength, p);\n    }\n}, phases, intensities);"} />

| 引数       | 型                                                                   | 説明                                             |
| ---------- | -------------------------------------------------------------------- | ------------------------------------------------ |
| `geometry` | `&Geometry`                                                          | ジオメトリ                                       |
| `groups`   | `&TransducerGroups<K>`                                               | 振動子毎のキー                                   |
| `compute`     | `FnMut(K, TransducerMask, &mut [Vec<Phase>], &mut [Vec<Intensity>]) -> Result<(), E>` | キーとマスクを受け取り, 作業バッファ (位相・振幅) へ計算する |
| `phases`      | `&mut [Vec<Phase>]`                                                                    | 位相の出力バッファ                                           |
| `intensities` | `&mut [Vec<Intensity>]`                                                                | 振幅の出力バッファ                                           |

`compute` はキー毎に 1 回 (キーの初出順) 呼ばれ, 計算結果のうちそのキーの振動子分だけが `phases` / `intensities` に書き込まれる.
作業バッファはキー毎に位相 0・最大振幅で初期化される.

## group

<CodeTabs rust={"#[derive(Clone, Copy, PartialEq, Eq)]\nenum Side {\n    Left,\n    Right,\n}\n\nlet groups = TransducerGroups::new(&geometry, |device, tr| {\n    if device.position(tr).x < center.x {\n        Side::Left\n    } else {\n        Side::Right\n    }\n});\ngroup(\n    &geometry,\n    &groups,\n    |side| match side {\n        Side::Left => &left,\n        Side::Right => &right,\n    },\n    &mut dst,\n);"} python={"class Side(Enum):\n    LEFT = auto()\n    RIGHT = auto()\n\ngroups = TransducerGroups(\n    geometry,\n    lambda device, tr: Side.LEFT if device.position(tr)[0] < center[0] else Side.RIGHT,\n)\ngroup(geometry, groups, {Side.LEFT: left, Side.RIGHT: right}, dst)"} csharp={"internal enum Side\n{\n    Left,\n    Right,\n}\n\nvar groups = new TransducerGroups<Side>(geometry, (device, tr) => device.Position(tr).X < center.X ? | 引数       | 型                                          | 説明                                   |
| ---------- | ------------------------------------------- | -------------------------------------- |
| `geometry` | `&Geometry`                                 | ジオメトリ                             |
| `groups`   | `&TransducerGroups<K>`                      | 振動子毎のキー                         |
| `source`   | `FnMut(K) -> impl AsRef<[Vec<T>]>`          | キーから出力元バッファを返す           |

`T` は `Phase` または `Intensity` で, 位相・振幅それぞれのバッファに対して呼ぶ.

## TransducerGroups

`TransducerGroups::new(&geometry, |device, tr| ...)` がデバイスと振動子インデックスからキーを返し, 振動子毎のキーを保持する.
どのグループにも属さない振動子は作れない. 一部の振動子を無出力にするには, そのためのキーを割り当てて振幅 `Intensity::MIN` を書く (Python でキー関数が `None` を返すと `ValueError`).
キーは Rust では `Copy + Eq` な型, C# では `null` でない任意の型 (`enum` や `string` など), Python ではハッシュ可能な値.
`mask(key)` でキー `key` の振動子だけを有効にした [Holo](/autd3-sdk/0.11.x/api/compute/holo/) 用の `TransducerMask`を取得できる. どの振動子にも割り当てられていないキーでは Rust は `None`, C# は `null` を返し, Python は `KeyError` を送出する.
