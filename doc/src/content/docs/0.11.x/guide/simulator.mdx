`Simulator` は, AUTD3 の出力音場をブラウザ上で可視化する音場シミュレータ.
実機がなくても, クライアントが送ったデータから生成される音場を確認できる.

## 起動

`Simulator` は GUI コンソール `autd3-console` に同梱されている.

[コンソール](/autd3-sdk/0.11.x/guide/console/) の手順で `autd3-console` を入手して起動し, 上部の「Simulator」タブを開く.

## 接続

クライアントは Simulator と同じホストで動かす必要がある.

既定の [`UdpOption`](/autd3-sdk/0.11.x/api/basics/transport-option/) (`iface` が `Auto`) は, Simulator が動いていれば Simulator に, 動いていなければ実機につながる.
アドレスを指定する必要はない.
Simulator にしかつなぎたくない場合は, `iface` に `Simulator` を指定すること.
Simulator を動かしたまま実機につなぐ場合は, `iface` に `Name(..)` で NIC を指定する.
