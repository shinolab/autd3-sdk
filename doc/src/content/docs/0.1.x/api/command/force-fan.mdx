`ForceFan` は, 冷却ファンを強制的に On にするコマンド.

:::caution
強制的にOffにすることはできない.
:::

## API

<CodeTabs rust={"ForceFan { value };"} python={"ForceFan(value)"} csharp={"new ForceFan(value);"} />

| フィールド | 型     | 説明                                      |
| ---------- | ------ | ----------------------------------------- |
| `value`    | `bool` | `true` でファンを強制起動                 |
