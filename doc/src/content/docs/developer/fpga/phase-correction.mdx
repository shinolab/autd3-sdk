import Math from "@components/Math.astro";

| Name           | In/Out | Width | Description              |
| -------------- | ------ | ----- | ------------------------ |
| CLK            | In     | 1     | メインクロック           |
| DIN_VALID      | In     | 1     | 位相データ有効フラグ     |
| PHASE_IN       | In     | 8     | 位相入力                 |
| PHASE_OUT      | Out    | 8     | 位相出力                 |
| PHASE_CORR_BUS | In     | -     | 位相補正データメモリバス |

このモジュールでは, 位相データに振動子毎の固定の位相を加算する.
主に振動子の個体差の補正や, `FociSTM` に何らかの位相を加えるために使用される.

補正値は振動子毎に <Math tex="\SI{8}{bit}" /> で, BRAM (`BRAM_PHASE_CORR`, 読み出し側 <Math tex="\SI{8}{bit}" /> × 256 語, そのうち 249 語を使用) に格納される.

このモジュールは `Modulation` モジュール内でインスタンス化されており, `Modulation` による強度データの変調と並列に動作する.
出力のタイミングを強度データと揃えるため, 入出力に遅延段が挿入されている.
データ有効フラグは `Modulation` モジュール側のものを共用するため, このモジュールは `DOUT_VALID` を持たない.
