この SDK は旧 autd3 SDK とは非互換であり, 通信プロトコルも新規に設計されている.
そのため, 通常の `Client` は旧世代ファームウェアを積んだデバイスを駆動できない.

`LegacyClient` は, 旧世代ファームウェア **v12.1.0** の実機を駆動するための互換クライアントである.

:::caution
対応するのは v12.1.0 (CPU version major = `0xA5`) のみ.
ファームウェアを更新できるのであれば, 現行の `Client` を使うこと.
:::

## 有効化

Rust では, `autd3-rs` の feature `legacy` で有効になる (既定では無効).

```toml
autd3-rs = { version = "0.4", features = ["legacy"] }
```

Python と C# のバインディングは追加の設定は不要である.
それぞれ `autd3.LegacyClient`, `AUTD3.Legacy` 名前空間として利用できる.

## 使い方

ユーザーコードの形は現行 SDK と同じである.
`Client` を `LegacyClient` に, `ClientConfig` を `LegacyClientConfig` に置き換えるだけでよい.
[Link](/autd3-sdk/0.6.x/api/link/) はすべて現行のものをそのまま使える.

<CodeTabs rust={"let client = LegacyClient::open(\n    &geometry,\n    EchocatLinkOption::default(),\n    LegacyClientConfig::default(),\n)\n.await?;"} python={"client = await LegacyClient.open(\n    geometry,\n    echocat.EchocatLinkOption(),\n    LegacyClientConfig(),\n)"} csharp={"using var client = await LegacyClient.OpenAsync(\n    geometry,\n    new EchocatLinkOption(),\n    new LegacyClientConfig()\n);"} />

`LegacyClientConfig` が持つのは `timeout_cycles` (既定 2000) と RT スレッドのチューニング (`rt_priority` / `rt_policy` / `rt_affinity`) のみ.
後者は現行 `ClientConfig` と同じ型・同じ既定値である (Windows は TimeCritical, それ以外は無指定).

ファームウェアバージョンの読み出しも現行と同じ.

<CodeTabs rust={"for (i, version) in client.read_firmware_version().await?.iter().enumerate() {\n    println!(\"device[{i}] firmware version: {version}\");\n}"} python={"for i, version in enumerate(await client.read_firmware_version()):\n    print(f\"device[{i}] firmware version: {version}\")"} csharp={"var versions = await client.ReadFirmwareVersionAsync();\nfor (var i = 0; i < versions.Count; i++)\n{\n    Console.WriteLine($\"device[{i}] firmware version: {versions[i]}\");\n}"} />

コマンドの組み立ても同じである (型が `DatagramBuilder` ではなく `LegacyDatagramBuilder` になる).
[Emission パターン](/autd3-sdk/0.6.x/api/compute/pattern/focus/)・[AM 波形](/autd3-sdk/0.6.x/api/compute/modulation/sine/)の計算ヘルパも共通である.

<CodeTabs rust={"let mut builder = client.datagram_builder();\nbuilder\n    .push(SetSilencer::default())\n    .push(Pattern::new(&emissions))\n    .push(Modulation::new(SamplingConfig::FREQ_4K, &modulation));\nlet frames = builder.build()?;\nfor frame in &frames {\n    client.send_checked(frame).await?;\n}"} python={"builder = client.datagram_builder()\nbuilder.push(SetSilencer())\nbuilder.push(Pattern(emissions))\nbuilder.push(Modulation(SamplingConfig.FREQ_4K, mod_buf))\nframes = builder.build()\nfor i in range(len(frames)):\n    await client.send_checked(frames[i])"} csharp={"using var builder = client.DatagramBuilder();\nbuilder\n    .Push(new SetSilencer())\n    .Push(new Pattern(emissions))\n    .Push(new Modulation(SamplingConfig.Freq4k, modulation));\nusing var frames = builder.Build();\nforeach (var frame in frames)\n{\n    await client.SendCheckedAsync(frame);\n}"} />

デバイス毎にコマンドを割り当てる [`push_each`](/autd3-sdk/0.6.x/api/basics/datagram-builder/) も同じように使える.

終了処理も同様である.

<CodeTabs rust={"client.stop().await?;\nclient.close().await?;"} python={"await client.stop()\nawait client.close()"} csharp={"await client.StopAsync();\nawait client.CloseAsync();"} />

## 現行 `Client` との違い

| 項目             | `Client`                             | `LegacyClient`                                |
| ---------------- | ------------------------------------ | --------------------------------------------- |
| 送信モデル       | パイプライン / stop-and-wait         | stop-and-wait のみ |
| エラー詳細の読み出し | `read_error_detail()`            | 非対応 (エラーは ack のコードのみ)            |
| Telemetry カウンタの読み出し | `read_telemetry()`       | 非対応                                        |

旧ファームウェアでは, 現行のパイプライン送信は使えない.
したがってスループットは現行より大きく劣る.

### パターンバンクの切り替え

`ChangePatternBank` の代わりに, レガシー固有の `LegacyChangePatternBank` を使う.
切り替え先の内容に応じて `pattern` / `foci_stm` / `pattern_stm` を選ぶ.

<CodeTabs rust={"let mut builder = client.datagram_builder();\nbuilder.push(Pattern::with_bank(PatternBank::B1, &emissions));\nfor frame in &builder.build()? {\n    client.send_checked(frame).await?;\n}\n\nlet mut builder = client.datagram_builder();\nbuilder.push(LegacyChangePatternBank::pattern(PatternBank::B0));\nfor frame in &builder.build()? {\n    client.send_checked(frame).await?;\n}"} python={"builder = client.datagram_builder()\nbuilder.push(Pattern(emissions, PatternBank.B1))\nframes = builder.build()\nfor i in range(len(frames)):\n    await client.send_checked(frames[i])\n\nbuilder = client.datagram_builder()\nbuilder.push(LegacyChangePatternBank.pattern(PatternBank.B0))\nframes = builder.build()\nfor i in range(len(frames)):\n    await client.send_checked(frames[i])"} csharp={"using (var bankBuilder = client.DatagramBuilder())\n{\n    bankBuilder.Push(new Pattern(PatternBank.B1, emissions));\n    using var bankFrames = bankBuilder.Build();\n    foreach (var frame in bankFrames)\n    {\n        await client.SendCheckedAsync(frame);\n    }\n}\n\nusing (var bankBuilder = client.DatagramBuilder())\n{\n    bankBuilder.Push(LegacyChangePatternBank.Pattern(PatternBank.B0));\n    using var bankFrames = bankBuilder.Build();\n    foreach (var frame in bankFrames)\n    {\n        await client.SendCheckedAsync(frame);\n    }\n}"} />
