`Modulation` は, AM 波形データ (`&[u8]`) をデバイスへ送るコマンド.

## API

<CodeTabs>
  <Fragment slot="rust">
    <Code code={"Modulation::new(config, &data);\n\nModulation::with_bank(bank, config, &data);\n\nModulation {\n    bank,\n    config,\n    data: &data,\n    loop_behavior,\n    transition_mode,\n};"} lang="rust" />

    `Modulation::new` は書き込み先バンクを `ModulationBank::B0`, ループを `Infinite`, 遷移を `Immediate` とする.
    別バンクへ書く場合は `Modulation::with_bank(bank, config, data)` を使う.
    ループ回数や遷移タイミングも変えたい場合は, フィールドを直接指定して構築する.
  </Fragment>

  <Fragment slot="python">
    <Code code={"Modulation(config, data)\n\nModulation(\n    bank=bank,\n    config=config,\n    data=data,\n    loop_behavior=loop_behavior,\n    transition_mode=transition_mode,\n)"} lang="python" />

    `Modulation` は書き込み先バンクをデフォルトで `ModulationBank.B0`, ループを `Infinite`, 遷移を `Immediate` とする.
    別バンク・ループ回数・遷移タイミングを指定したい場合は, `bank` / `loop_behavior` / `transition_mode` 引数を渡す.
  </Fragment>

  <Fragment slot="csharp">
    <Code code={"new Modulation(config, data);\n\nnew Modulation(bank, config, data);\n\nnew Modulation(\n    bank: bank,\n    config: config,\n    data: data,\n    loopBehavior: loopBehavior,\n    transitionMode: transitionMode\n);"} lang="csharp" />

    `new Modulation(config, data)` は書き込み先バンクを `ModulationBank.B0`, ループを `Infinite`, 遷移を `Immediate` とする.
    別バンクへ書く場合は `new Modulation(bank, config, data)` を使う.
    ループ回数や遷移タイミングも変えたい場合は, `loopBehavior` / `transitionMode` 引数を渡す.
  </Fragment>
</CodeTabs>

| フィールド        | 型               | デフォルト                  | 説明                         |
| ----------------- | ---------------- | --------------------------- | ---------------------------- |
| `bank`            | `ModulationBank` | `ModulationBank::B0`        | 書き込み先・再生対象のバンク |
| `config`          | `SamplingConfig` | —                           | 再生サンプリング周波数       |
| `data`            | `&[u8]`          | —                           | AM 波形サンプル列 (2 サンプル以上)   |
| `loop_behavior`   | `LoopBehavior`   | `LoopBehavior::Infinite`    | 再生ループ回数               |
| `transition_mode` | `TransitionMode` | `TransitionMode::Immediate` | バンク切替時の遷移挙動       |

`config` は [`SamplingConfig`](/autd3-sdk/0.6.x/api/basics/sampling-config/) で指定する.
`data` は `modulation_buffer()` で確保したバッファへ書き込む.
`loop_behavior` / `transition_mode` の挙動は [ChangeModulationBank](/autd3-sdk/0.6.x/api/command/lowlevel/change-modulation-bank/) を参照.

modulation の計算には幾つかの[ヘルパ関数](/autd3-sdk/0.6.x/api/compute/modulation/)が用意されている.

## 等価な低レベルコマンド

`Modulation` は [WriteModulationBuffer](/autd3-sdk/0.6.x/api/command/lowlevel/write-modulation-buffer/) + [ConfigModulation](/autd3-sdk/0.6.x/api/command/lowlevel/config-modulation/) + [ChangeModulationBank](/autd3-sdk/0.6.x/api/command/lowlevel/change-modulation-bank/) の 3 つと等価である. データが 1 フレームに収まる場合は融合して 1 フレームで送られ, 収まらない場合は上記の 3 コマンドに展開される.
以下は `Modulation { bank, config, data, loop_behavior, transition_mode }` と等価な組み合わせである

<CodeTabs rust={"WriteModulationBuffer {\n    bank,\n    offset: 0,\n    data: &data,\n};\nConfigModulation {\n    bank,\n    config,\n    size: data.len(),\n    loop_behavior,\n};\nChangeModulationBank {\n    bank,\n    transition_mode,\n};"} python={"WriteModulationBuffer(\n    bank=bank,\n    offset=0,\n    data=data,\n)\nConfigModulation(\n    bank=bank,\n    config=config,\n    size=len(data),\n    loop_behavior=loop_behavior,\n)\nChangeModulationBank(\n    bank=bank,\n    transition_mode=transition_mode,\n)"} csharp={"new WriteModulationBuffer(\n    bank: bank,\n    offset: 0,\n    data: data\n);\nnew ConfigModulation(\n    bank: bank,\n    config: config,\n    size: (uint)data.Length,\n    loopBehavior: loopBehavior\n);\nnew ChangeModulationBank(\n    bank: bank,\n    transitionMode: transitionMode\n);"} />
