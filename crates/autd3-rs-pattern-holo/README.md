# autd3-rs-pattern-holo

Multi-focus hologram optimization for [AUTD3](https://hapislab.org/en/airborne-ultrasound-tactile-display): Naive, GS, and GSPAT.

Use with [`autd3-rs`](https://crates.io/crates/autd3-rs). A GPU (`wgpu`) linear-algebra backend is available as [`autd3-rs-pattern-holo-wgpu`](https://crates.io/crates/autd3-rs-pattern-holo-wgpu).

## Feature flags

| Feature | Default | Description |
|---------|---------|-------------|
| `parallel` | yes | Parallelise the optimizers with [rayon](https://crates.io/crates/rayon) |
