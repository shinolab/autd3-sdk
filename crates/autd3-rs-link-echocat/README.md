# autd3-rs-link-echocat

`Link` implementation for [`autd3-rs`](https://crates.io/crates/autd3-rs) backed by *echocat*, an EtherCAT main device written for [AUTD3](https://hapislab.org/en/airborne-ultrasound-tactile-display).

MIT licensed and dependency-free on the EtherCAT side, so this is the default transport for AUTD3 devices.
