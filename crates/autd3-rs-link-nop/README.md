# autd3-rs-link-nop

Hardware-free `Link` for [`autd3-rs`](https://crates.io/crates/autd3-rs), backed by [`autd3-rs-firmware-emulator`](https://crates.io/crates/autd3-rs-firmware-emulator).

Frames go to an emulated device instead of the bus, so examples, tests, and documentation samples run without an AUTD3 connected.
