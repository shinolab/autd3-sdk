# autd3-rs-link-twincat

`Link` implementation for [`autd3-rs`](https://crates.io/crates/autd3-rs) backed by TwinCAT3 via the ADS protocol.

Windows only; TwinCAT3 must be installed and configured for the AUTD3 devices.
