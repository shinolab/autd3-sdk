# autd3-rs-modulation

Amplitude-modulation waveforms for [AUTD3](https://hapislab.org/en/airborne-ultrasound-tactile-display): sine, square, static, and the helpers to write them into a modulation buffer.

Use with [`autd3-rs`](https://crates.io/crates/autd3-rs).
